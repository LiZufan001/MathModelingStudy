# CPMCM 已核验一等奖作品索引

本目录的目标不是“搜到一个 PDF 就算国一”，而是先证明作品确实属于对应年份 CPMCM 的**全国一等奖**或更高层级（如数模之星/华为专项奖中的一等奖团队），再收录作品信息。

## 范围硬约束

**这里只收录中国研究生数学建模竞赛（CPMCM，“华为杯”）的研究生组全国一等奖及更高层级作品。**

- 不收全国大学生数学建模竞赛（CUMCM，本科生国赛）论文。
- 不收美赛 MCM/ICM、亚太赛、MathorCup 等其他赛事论文到本目录。
- 任何候选论文在进入“国一”集合前，必须能同时确认：**赛事 = CPMCM、年份正确、题号正确、奖项 = 全国一等奖或更高层级**。
- 仅出现“优秀论文”“国赛论文”等模糊标签，不足以证明其属于研究生 CPMCM 国一。
- 发现来源如果混有本科数模资料，必须按赛事身份重新核验，不能直接继承来源目录标签。

## 独立核验规则

**第三方仓库、README、博客或网盘只能作为“发现来源”，不能作为赛事身份的最终证据。**

每批候选至少按下面顺序独立复核：

1. 先到中国研究生创新实践系列大赛 / 中国研究生数学建模竞赛官方页面，确认该年份确实对应“第 N 届中国研究生数学建模竞赛”，并核对官方评审/最终获奖公告。
2. 用官方公告中的一等奖总数、题号、队伍编号格式等，对抓取到的获奖名单做一致性检查。
3. 再把论文参赛编号与研究生竞赛一等奖队伍编号做精确匹配；不能只凭“优秀论文”目录名判断。
4. 对训练精选样本，再用学校官网、学院官网或赛事官方报道交叉核验队员、学校、题目和奖项层级。
5. 如果官方数据与第三方整理发生冲突，以官方数据为准，并修正本仓库的机器审计结果。
