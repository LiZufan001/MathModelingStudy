由于 Chaitin / graph coloring / spill 都属于经典编译器技术，后续反查不再把这些普通关键词当成强指纹。

## 3. 极罕见写作残留：`0922(2).pdf`

A1 p.41 在评价 Q2 时残留一句：

> `在0922(2).pdf 中展现出鲜明创新性`

这显然更像赛期草稿文件名，而不是论文应出现的正式引用。

身份价值：

- `0922` 很可能对应比赛开始后的日期型草稿命名；
- `(2)` 可能是 Windows / 浏览器重复下载或多版本文件名后缀；
- 若某公开网盘目录、Git 提交、博客截图、附件列表中出现同名赛期文件，其身份价值会远高于泛算法关键词。

本轮反查结果：

- GitHub 全局搜索 `0922(2).pdf`，与 2025 A题相关的命中仍只回到当前第三方深读仓；
- Web 精确搜索出现的其它同名文件均为无关文档；
- 暂时没有找到第二个比赛来源。

因此该残留继续保留为 **高辨识度、但当前无外部命中的文件级指纹**。
