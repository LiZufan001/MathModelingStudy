> **本页只用于证据工程与检索优先级，不改变 `C / T+ / F+ / M` 状态。**

## 0. 结论先行

本轮跨题验证得到一个重要修正：

> **不能把“优秀论文选中的论文 = 官方表最前几行/严格高名次论文”作为 A1/A2 的硬剪枝规则。**

原因是 B 题已经出现明确的高价值反例：

- B1 候选《MIMO-OFDM 链路速率预测问题的建模研究》与北京交通大学张乐童团队官方题名完全一致，当前 `T+`；该队 `B25100040034` 是官方 B 表 **row1**。
- B2 候选《无线通信系统链路速率建模》与山东师范大学牟庆喆、孙成艳、范玉鑫团队官方题名完全一致，当前同样 `T+`；但该队 `B25104450011` 是官方 B 表 **row22**。

因此，在当前证据口径下，B2 足以阻止我们把“候选包只挑官方表前排”用于硬排除。

但另一方面，当前高相关候选又确实表现出一定的**前排行富集**：

- A3 → A row1（`F+`）
- A4 → A row2（`F+`）
- B1 → B row1（`T+`）
- B2 → B row22（`T+`，反例）
- C4 → C row2（`T+?`，近题名）
- D1 → D row4（`T+`，仅“与/及”一字差）

也就是当前 6 个高相关绑定中有 5 个落在 row1–4，但样本很小、绑定等级并不一致，而且官方并未说明 Excel 行号等于严格题内名次。

**正确用法：**把 row3/row4 当成 A1/A2 的“软优先级加分”，而不是把 row5/6/8 直接排除。

## 2. B 题为什么改变了 A1/A2 的剪枝策略

此前最诱人的推断是：

1. A3/A4 分别强相关于 A row1/row2；
2. B1 又精确落到 B row1；
3. 如果后续 C/D 也集中在最前几行，那么匿名候选包可能就是从各题最高排位论文中抽取；
4. 进而 A1/A2 可能主要对应 A row3/row4。

B2=row22 说明第 3 步至少不能作为硬规则成立。

尤其需要注意：B2 的证据并不是普通“方向相似”，而是候选题名与山东师范大学官方报道题名完全一致。因此即使尚缺 PDF 封面，这已经足以让我们在搜索工程上停止把“官方行序”当作排除条件。

因此 A1/A2 第一搜索池继续保留：

- BIT row3 `A25100070050`
- HFUT row4 `A25103590022`
- 牡丹江师范 row5 `A25102330006`
- ZJU row6 `A25103350026`
- HDU row8 `A25103360089`

其中 BIT/HFUT 仍然优先，但理由主要是**独立的方法/科研/竞赛背景证据**，而不是“row3/row4 一定比 row5/6/8 更可能被优秀论文包选中”。
