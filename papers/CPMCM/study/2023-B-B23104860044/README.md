# 0. 指导老师先给结论

这篇论文真正值得学习的地方，不是“用了 SVD、ADMM、广义逆”这些名词，而是作者一直围绕同一个工程目标展开：

> **把 DFT 的精确矩阵乘法，重写成一串更容易做成硬件的稀疏、有限取值矩阵，并在误差与乘法器复杂度之间做折中。**

五问的主线实际上很统一：

```text
FFT / butterfly structure
        ↓
Q1：只约束稀疏性
        ↓
BSVD：蝶形拆解 + SVD + 稀疏投影
        ↓
Q2：只约束有限整数取值
        ↓
集中量化 / 分布量化
        ↓
Q3：稀疏 + 量化同时存在
        ↓
S→Q 与 Q→S 两种投影顺序
        ↓
Q4：目标矩阵是 Kronecker product
        ↓
利用混合积性质先拆结构再优化
        ↓
Q5：还要 RMSE ≤ 0.1
        ↓
追加“纠错因子” X，迭代提高逼近精度
```

这种“**先找结构，再设计约束投影，再用新增因子修正残差**”的思路非常有训练价值。

但这也是五篇里最需要进行数学审计的一篇。对原题、组委会赛中通知、103 页论文、正文公式和 MATLAB 附录交叉核验后，可以明确区分：

## 值得学

- 从 radix-2 butterfly 出发缩小搜索空间，而不是直接搜索任意整数矩阵；
- 把“稀疏”和“量化”看成两个不同投影，并比较执行顺序；
- Q4 使用 Kronecker mixed-product property 做结构化降维；
- Q5 用广义逆得到连续域最佳右修正因子，再将其投影回可实现矩阵集合；
- 作者敢于在 Q5 明确承认没有达到 `RMSE < 0.1`，没有伪造完成度。

## 不能照抄

- 论文代码采用的 RMSE evaluator 与题面公式不一致；
- `β` 的更新并不是该最小二乘问题的解析最优解；
- 所谓 ADMM 在公开实现里实际上没有标准 ADMM 的对偶变量更新，主要是贪心硬稀疏；
- 对 DFT block 做 SVD 时所有奇异值相等，论文用“奇异值体现列向量重要性”解释稀疏选择并不成立；
- 硬件复杂度统计程序与官方 `C=qL` 的定义并不一致，存在明显少算；
- Q3 摘要、表格和结果分析中的 S-Q / Q-S 数字互相冲突；
- Q5 最终没有满足题目要求的精度门槛。

所以本篇最正确的学习方式是：

> **学它怎样把一个巨大离散搜索问题变成结构化算法；同时用官方 evaluator、解析尺度参数和严格复杂度账本重新兜底。**

# 1. 先还原官方问题

给定 N 维 DFT 矩阵 `F_N`，设计

\[
\mathcal A=\{A_1,A_2,\ldots,A_K\}
\]

使矩阵连乘逼近 DFT。

原始题面发布时目标为

\[
J_{old}=\frac1N\left\|\beta F_N-A_1A_2\cdots A_K\right\|_F^2.
\]

这里确实存在一个退化：若 β 可以自由趋于 0，同时把各 `A_k` 也做成零矩阵，目标会趋于零。

## 1.1 重要：作者移动 β 的位置是官方允许的

2023 年 9 月 24 日，竞赛专家委员会发布《B题修改目标函数的通知》，允许把 β 从 `F` 前移动到近似矩阵 `A` 前，因此新目标变为：

\[
\boxed{
J(A,\beta)=\frac1N
\left\|F_N-\beta A_1A_2\cdots A_K\right\|_F^2
}
\]

官方还允许原目标函数的结果保留，并建议新旧结果进行比较。

官方通知：

`https://cpipc.acge.org.cn/cw/contestNews/list/4/5`

因此，**“β 换边”本身不能作为对本论文的扣分项**。

真正需要审计的是：论文后续程序是否严格按照这个更新后的公式计算。

# 2. 两类硬约束

## 2.1 稀疏约束

每个因子矩阵每行最多 2 个非零元素：

\[
\|A_k[i,:]\|_0\le2.
\]

它非常符合 butterfly / sparse linear transform 的硬件实现逻辑。

## 2.2 量化约束

矩阵实部和虚部必须来自：

\[
P_q=\{0,\pm1,\pm2,\ldots,\pm2^{q-1}\}.
\]

即

\[
A_k[l,m]=x+jy,\qquad x,y\in P_q.
\]

题面定义硬件复杂度：

\[
\boxed{C=qL}
\]

其中 `L` 是非平凡复乘次数。

官方明确规定，与以下系数相乘不计入复乘：

\[
0,\ \pm1,\ \pm j,\ \pm1\pm j.
\]

这个定义非常重要，因为论文的复杂度统计程序恰恰在这里出现了明显口径问题。

# 3. 问题一：BSVD 到底在做什么

作者先使用 radix-2 FFT 的蝶形结构，把 DFT 写成：

\[
F_N=W R P,
\]

其中：

- `W`：由单位阵和 twiddle diagonal 组成的 butterfly factor；
- `P`：奇偶重排矩阵；
- `R`：本质上是两个 `F_{N/2}` 的 block diagonal。

由于 `W`、`P` 已经天然稀疏，作者把主要优化自由度集中到 `R`。

接着：

\[
R=USV^H.
\]

因此：

\[
F_N=WUSV^HP.
\]

作者再把 `U,V` 每行压缩到最多两个非零元素，得到：

\[
\hat F_N=W\hat U S\hat V^H P.
\]

并通过合并：

\[
A_1=W,\qquad
A_2=\hat U,\qquad
A_3=S\hat V^HP,
\]

把 `K` 压缩到 3。

作者将它称为 **Butterfly Singular Value Decomposition, BSVD**。

## 3.1 这个结构为什么有价值

如果直接优化：

\[
A_1,\ldots,A_K
\]

搜索空间几乎不可控。

BSVD 先固定：

```text
butterfly topology
permutation topology
```

只让部分矩阵承担逼近自由度。

这是一种很值得迁移的思想：

> **先用问题结构规定“允许搜索的架构”，再优化架构里的参数。**

它比“随机初始化 K 个整数矩阵然后元启发式搜索”成熟很多。

# 4. 但这里有一个很深的数学问题：DFT block 的 SVD 没有重要性排序

论文在结果分析中解释：

> S 中的奇异值反映 U/V 列向量的重要程度，因此可辅助有选择地稀疏。

对于一般矩阵，这个说法有道理。

**但对这里的 `R` 不成立。**

未归一化 DFT 满足：

\[
F_m^H F_m=mI.
\]

所以所有奇异值都是：

\[
\sigma_1=\cdots=\sigma_m=\sqrt m.
\]

而作者的：

\[
R=\operatorname{diag}(F_{N/2},F_{N/2})
\]

因此同样有：

\[
\boxed{S=\sqrt{N/2}\,I}
\]

——全部奇异值相等。

这带来两个后果。

### 后果 1：不存在“前几个奇异方向更重要”

这里没有低秩谱衰减。

### 后果 2：SVD 基底不是唯一的

当奇异值完全退化时，可以在奇异子空间内做任意 unitary rotation：

\[
U\to UQ,\qquad V\to VQ
\]

而 `R` 不变。

于是后面对 `U,V` 做硬稀疏的结果会依赖数值库选择出来的某一个 SVD 基底。

这解释了为什么：

> **SVD 可以作为一个分解工具，但不能在这里被解释成“按奇异值筛重要信息”。**

如果我们重做，应优先寻找**具有稀疏友好性的 unitary basis**，而不是依赖默认 `svd()` 在完全重复奇异值下给出的任意基底。

# 5. “ADMM”与实际实现之间有距离

正文引入辅助变量 `Y_U,Y_V`，写出了类似 augmented objective 的形式，并称采用 ADMM。

但真正的算法 1 和 MATLAB `svd_sparser()` 实现主要做的是：

1. 分别尝试把 `U` 某个元素置零；
2. 测试对最终矩阵误差的影响；
3. 每一行保留“删掉后损失最大”的两个元素；
4. 再对 `V` 做同样操作。

这更准确地说是：

> **importance-based hard thresholding / greedy row sparsification**

而不是标准 ADMM。

标准 ADMM 至少应该明确：

- primal variable；
- split variable；
- dual variable；
- augmented Lagrangian penalty；
- primal / dual residual；
- dual update。

公开附录中没有形成这套迭代闭环。

所以比赛写作中，更严谨的表述应该是：

> “采用交替优化思想构造问题，并用贪心硬阈值实现稀疏投影。”

而不是直接把实现称为 ADMM。

# 6. β 的优化并没有真正做到最优

代码大量使用：

```matlab
beta = norm(F,'fro') / norm(F_hat,'fro');
```

但对官方更新后的目标：

\[
\min_{\beta\in\mathbb R}
\|F-\beta H\|_F^2
\]

令：

\[
H=A_1\cdots A_K,
\]

真正的解析最优解是：

\[
\boxed{
\beta^*=\frac{\operatorname{Re}\langle H,F\rangle_F}
{\|H\|_F^2}
}
\]

其中：

\[
\langle H,F\rangle_F=\operatorname{tr}(H^HF).
\]

作者的范数比：

\[
\frac{\|F\|_F}{\|H\|_F}
\]

只是把两个矩阵的总能量调整到相同量级，**并不能保证最小 Frobenius error**。

这是一个很典型的比赛教训：

> **只要某个连续参数能够解析消元，就不要用经验更新式。**

# 7. 最严重的 evaluator 问题：论文代码少了平方

官方赛中修改后的目标仍然是：

\[
\boxed{
J=\frac1N\|F_N-\beta\hat F_N\|_F^2
}
\]

论文第 1 章公式 (1.1) 也写的是平方 Frobenius norm。

但算法和 MATLAB 代码实际反复计算：

```matlab
1/n * sqrt(norm(F_actual-beta*F_hat,'fro').^2)
```

即：

\[
\boxed{
d=\frac1N\|F_N-\beta\hat F_N\|_F
}
\]

而不是官方：

\[
\frac1N\|\cdot\|_F^2.
\]

两者关系为：

\[
\boxed{J=N d^2}.
\]

因此论文表中的所有 `d(A,β)` 数值不能直接当成官方 RMSE 指标。

例如论文 Q2 集中量化在 `N=32` 报：

\[
d=0.1588.
\]

对应官方平方指标应为：

\[
J=32\times0.1588^2\approx0.807.
\]

这不是一个小数点问题，而是**优化目标和验收门槛整体改变**。

特别对问题五，论文按：

\[
d\le0.1
\]

迭代。

但真正官方门槛是：

\[
J\le0.1.
\]

换成论文的 `d` 口径，应满足：

\[
\boxed{d\le\sqrt{0.1/N}}.
\]

例如：

| N | 官方 `J≤0.1` 对应的论文 d 上限 |
|---:|---:|
| 8 | 0.1118 |
| 16 | 0.0791 |
| 32 | 0.0559 |

所以在 N=16、32 时，代码使用 `d≤0.1` 实际还是一个**更宽松**的停止条件。

而论文最终连这个更宽松目标也没有达到。

# 8. 问题一结果：思路有价值，但“最小误差”不宜这样表述

论文 Q1 报告：

| N | d（论文代码口径） | C_BSVD | C_B |
|---:|---:|---:|---:|
| 2 | 0 | 0 | 0 |
| 4 | 0 | 0 | 0 |
| 8 | 0.7163 | 192 | 0 |
| 16 | 1.0154 | 1312 | 512 |
| 32 | 1.1039 | 3168 | 4096 |
| 64 | 1.2103 | 6784 | 22528 |
| 128 | 1.2684 | 14272 | 106496 |

作者强调 N 大时 BSVD 复杂度增长慢于普通蝶形方案。

这体现了一个真实的 Pareto 思路：

```text
允许误差
  ↓
降低系数/乘法器成本
```

但应注意：

1. Q1 只要求每行最多两个非零；
2. radix-2 FFT 本身就存在满足这一稀疏条件的**精确 factorization**；
3. 因此真正问题不是“能不能满足稀疏约束”，而是：

\[
\text{在 exact FFT 与 approximate factorization 之间找 Pareto frontier。}
\]

作者固定 BSVD 架构后得到的是一个可行启发式点，不是数学上证明的：

> “最小误差”或“最低硬件复杂度”。

正式写作更建议用：

> “本文算法获得的误差/复杂度”

而不是“最小”。

# 9. 硬件复杂度统计存在更根本的问题

论文提出所谓 Boolean complexity algorithm。

其思路是把“需要复乘”的系数标为 1，然后计算：

```matlab
Comlogical_1 = logical_1 * logical_2;
Comlogical_2 = Comlogical_1 * logical_3;
C = q*(nnz(Comlogical_1)+nnz(Comlogical_2));
```

并且 `myLogicalize()` 里首先写：

```matlab
Logical1(k,j)=~isreal(A(k,j));
```

这产生两个明显问题。

## 9.1 所有实数系数都被视为免费

官方只规定以下系数免费：

\[
0,\pm1,\pm j,\pm1\pm j.
\]

但 `~isreal()` 会把：

\[
2,4,-2,-4,\ldots
\]

全部标成 0，即“不需要乘法器”。

这不符合官方定义。

## 9.2 `nnz(B_1B_2)` 不是复乘次数

矩阵乘法输出位置非零个数，与实际执行了多少 scalar multiplication 不是同一个量。

例如两个全非平凡 `2×2` 矩阵相乘：

- scalar multiplication：8 次；
- product matrix 非零位置：最多 4 个。

`nnz(B_1B_2)` 只能得到 4，直接少一半。

如果是把 factor matrices 顺次作用到输入向量，则自然的硬件账本应该逐 stage 统计：

\[
L=\sum_k\#\{A_k[i,j]\notin\mathcal E\},
\]

其中：

\[
\mathcal E=\{0,\pm1,\pm j,\pm1\pm j\}.
\]

若要做 factor fusion，必须明确新的电路图，再重新数乘法器。

因此本文所有 `C` 数值都应视为：

> **论文自定义 complexity estimator 的结果，而不是已经严格核验的官方硬件复杂度。**

# 10. 问题二：集中量化 vs 分布量化

## 10.1 集中量化

直接对整个 DFT 矩阵元素做有限集合投影：

\[
F_N\to Q(F_N).
\]

论文得到：

| N | d（论文口径） |
|---:|---:|
| 2 | 0 |
| 4 | 0 |
| 8 | 0.1359 |
| 16 | 0.1617 |
| 32 | 0.1588 |

优点是误差比较低。

## 10.2 分布量化

先 BSVD：

\[
F_N=WUSV^HP,
\]

再分别量化 `W/U/V` 等因子。

误差整体更高，但作者报告的 complexity 更低。

这体现了一个很有价值的工程原则：

> **量化“最终矩阵”与量化“中间 factor”不是同一问题。**

前者更接近原矩阵，通常精度好；后者更容易产生大量简单系数，可能更适合硬件。

我们以后遇到压缩/量化问题，要同时比较：

```text
post-factorization quantization
vs
end-to-end quantization
```

而不是默认一种方式。

# 11. 问题三：S→Q 与 Q→S 的思想非常值得保留

作者提出两条 pipeline：

### S-Q

\[
F\to S(F)\to Q(S(F)).
\]

### Q-S

\[
F\to Q(F)\to S(Q(F)).
\]

这相当于比较两个非交换投影：

\[
Q(S(X))\neq S(Q(X)).
\]

这是本篇最值得迁移的数学思想之一。

现实中也经常有：

```text
先剪枝再量化
vs
先量化再剪枝
```

```text
先降维再正则
vs
先正则再降维
```

```text
先异常剔除再标准化
vs
先标准化再异常剔除
```

**非线性/离散投影顺序会改变最后结果。**

# 13. 问题四：Kronecker 结构是本篇另一个真正漂亮的地方

题目给：

\[
F=F_4\otimes F_8.
\]

作者比较三种方式：

1. 先做 Kronecker，再对整个矩阵稀疏/量化；
2. 分别处理 `F4,F8`，再 Kronecker；
3. **先对 `F4,F8` 做结构分解，再利用 mixed-product property 合并同类 factor。**

关键恒等式：

\[
(A\otimes B)(C\otimes D)=AC\otimes BD.
\]

于是可以把：

\[
F_4=W_4U_4S_4V_4^HP_4,
\]

\[
F_8=W_8U_8S_8V_8^HP_8
\]

转成：

\[
F_4\otimes F_8
=(W_4\otimes W_8)
(U_4\otimes U_8)
(S_4\otimes S_8)
(V_4^H\otimes V_8^H)
(P_4\otimes P_8).
\]

再分别对这些 factor 处理。

论文方案三报告：

\[
d=0.974153,\qquad C=36.
\]

虽然复杂度数值受前述 evaluator 影响，但**利用 Kronecker 结构避免把问题暴力扩成 32×32 黑箱矩阵**的思想非常正确。

# 14. 问题五：GIG 是一个很值得二次发展的想法

设已有近似：

\[
H\approx F.
\]

作者希望在右边追加一个因子：

\[
HX\approx F.
\]

如果暂时忽略整数与稀疏约束，最小二乘解为：

\[
X^*=(\beta H)^+F.
\]

然后将 `X*`：

1. 归一化；
2. 量化；
3. 稀疏；
4. 加到 factor chain 后面。

不断重复：

```text
current approximation H
       ↓
pseudoinverse correction X*
       ↓
project X* to feasible hardware set
       ↓
H ← H X
       ↓
re-evaluate
```

作者称为 **Generalized Inverse Generation (GIG)**。

从现代优化视角看，它其实很像：

> **multiplicative residual correction + projection onto feasible set**。

这是一个很有迁移价值的模式。

# 15. 但问题五没有真正完成题目要求

题目要求：

\[
RMSE\le0.1.
\]

作者在 9.4 节明确写：

> “我们的结果可能很难满足精度 RMSE<0.1 的要求。”

也就是说，第五问的核心约束并未达到。

而且前面已经说明：程序用的还是：

\[
d=\frac1N\|E\|_F,
\]

不是官方：

\[
J=\frac1N\|E\|_F^2.
\]

因此 Q5 不应写成“已求得满足精度要求的最优方案”，正确结论应是：

> **提出了可持续降低误差的修正策略，但当前实现未能满足官方目标门槛。**

这个承认虽然意味着问题没有完全解决，却比伪造成功更符合竞赛诚信。

# 17. 如果我是指导老师，会要求这支队赛中补什么

## 第一优先级：锁死 evaluator

```python
def official_loss(F, H, beta):
    E = F - beta * H
    return np.linalg.norm(E, 'fro')**2 / F.shape[0]
```

## 第二优先级：解析求 β

```python
beta = np.real(np.vdot(H, F)) / np.linalg.norm(H, 'fro')**2
```

## 第三优先级：正确 complexity ledger

明确逐个 factor 的非平凡系数数量。

## 第四优先级：做 exact FFT baseline

至少报告：

| method | official loss | C | K |
|---|---:|---:|---:|
| exact radix-2 FFT | 0 | | log2 N |
| BSVD | | | 3 |
| quantized BSVD | | | |

然后展示 Pareto frontier。

## 第五优先级：不要把 greedy 叫 ADMM

如果要用 ADMM，就真正实现 dual update；否则就诚实叫 greedy projected sparsification。

## 第六优先级：Q5 必须有 feasibility statement

如果没达到：

```text
best achieved official RMSE = ...
constraint target = 0.1
feasible = NO
```

不要把“误差下降”与“满足约束”混在一起。

# 18. 本篇最值得带到 2026 比赛的 10 条经验

1. **矩阵题先找 factorization structure，再优化系数。**
2. **存在多种约束投影时，一定测试操作顺序。**
3. **看到 Kronecker / block / Toeplitz / circulant，不要先展开大矩阵。**
4. **连续尺度参数能解析消元就解析消元。**
5. **官方 evaluator 必须逐字符对题面实现。**
6. **Big-O、运算次数、乘法器数、位宽复杂度是四本不同的账。**
7. **SVD 前先看 spectrum；平谱矩阵不能讲“头部奇异值更重要”。**
8. **算法命名必须与实际代码一致。**
9. **复杂度—误差是 Pareto 问题，不要只给一个启发式点。**
10. **没满足硬门槛就明确写 infeasible / not reached。**
