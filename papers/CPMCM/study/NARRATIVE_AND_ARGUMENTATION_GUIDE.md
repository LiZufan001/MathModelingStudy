# 华为杯论文叙事与科学论证指南｜原文、解释、建议三层分开

> 本文件已经按一次重要的方法论纠偏重写。此前我们擅长的是**模型重构与技术审计**，但曾把指导老师式的二次概括误说成优秀论文作者的真实叙事风格。这个错误必须彻底切开。  
> 原文专项研究见 [`ORIGINAL_PAPER_NARRATIVE_STUDY.md`](ORIGINAL_PAPER_NARRATIVE_STUDY.md)。  
> 从现在开始，所有论文叙事学习都明确标记三层：`ORIGINAL`、`INTERPRETATION`、`RECOMMENDED`。

---

# 0. 三层证据纪律

## ORIGINAL｜作者实际怎么写

只能来自：

- 可核验的原论文 PDF；
- 摘要、问题分析、模型引入、问间过渡、结果分析、模型评价等原文段落；
- 必要时结合原页视觉核验。

只回答：

> 作者实际怎样提出困难、引出方法、组织结果和连接各问？

## INTERPRETATION｜我们如何理解其深层结构

例如我们可以把某篇论文抽象成：

```text
state → evaluator → optimizer
```

或者：

```text
measurement → state → forecast → decision
```

这类抽象非常有用，但必须明确：

> **这是我们的模型重构，不是作者原话。**

## RECOMMENDED｜我们正赛怎样写得更科学

优秀论文同样会有过度宣称、验证不足、结果版本漂移等问题。因此：

> **原文可学习，不等于原文每句话都应照抄。**

正赛建议必须综合：题面、原文、技术审计和我们自己的实验事实。

# 1. 一次实证纠偏：国一论文并不普遍使用“不是 A，而是 B”

我们重新对仓库中 9 篇 exact-match 国一 PDF 做原文语料抽取，其中 8 篇能够可靠解码，2021 A 因嵌入字体编码严重乱码，不纳入措辞结论。

总文本约 63.7 万字符。完整结构：

```text
不是 ... 而是 ...
```

只匹配到 **1 次**，而且只是 2024 E 对“堵塞”概念的字面澄清，并非用来制造研究洞察的修辞。

相反，粗粒度统计中更常见的是：

| 连接动作 | 约次数 |
|---|---:|
| `因此` | 214 |
| `根据` | 208 |
| `由于` | 101 |
| `同时` | 101 |
| `为了` | 98 |
| `从而` | 77 |
| `针对` | 74 |
| `说明` | 72 |
| `进一步` | 61 |
| `最后` | 46 |
| `首先` | 43 |
| `结合` | 39 |

这个统计不用于评价文采，只说明一个事实：

> **这些论文的真实研究语言主要是依据、原因、目的、递进、比较和结果，而不是大量对比式口号。**

因此，以后不要把我们的“教学金句”误当成一等奖论文的语言模板。

# 2. ORIGINAL PATTERN 1｜摘要先完成“题目—方案—结果”对应

多个原文摘要最稳定的组织形式是：

```text
背景 / 总体任务
↓
针对问题一：方法 + 关键结果
↓
针对问题二：方法 + 关键结果
↓
……
↓
总体结论
```

2020 F、2020 C、2023 B、2024 F 都非常明显。

## INTERPRETATION

摘要首先承担的是**任务覆盖证明**：评委能迅速知道每问有没有答、怎么答、得到什么。

## RECOMMENDED

保留逐问对应，但每问最好包含四项：

```text
任务
→ 一个关键判断
→ 方法
→ 最有辨识度的结果/证据
```

不要在摘要里塞大量算法原理，也不要写正文没有真正验证过的“高泛化、强鲁棒、全局最优”。

---

# 3. ORIGINAL PATTERN 2｜方法通常由题目事实或数据现象推出

优秀段落最值得学的是**方法出现之前有原因**。

## 2023 B 的原始研究动作

非零元素乘法消耗乘法器：

```text
非零元素越多
→ 乘法器越多
→ 希望 Ak 更稀疏
→ 稀疏性进入模型
```

Q3 同时有稀疏和量化：

```text
两种操作都会改变矩阵
→ 顺序可能影响结果
→ 比较 S-Q 与 Q-S
```

## 2020 C 的原始研究动作

作者先指出每轮只有 2/12 个 P300 正事件：

```text
正类≈16.7%
→ 全预测负类也可得到≈84%表面准确率
→ 原训练集类别严重失衡
→ 再引出抽样平衡
```

Q3 则先指出：

```text
人工标签难获得
+ 无标签数据容易获得
→ 半监督学习场景
```

## 2022 B 的原始研究动作

现实生产先给出矛盾：批次过小降低材料利用率，批次过大增加交付风险；再由三阶段切割和大量相同边长 item，引出 `2-items → stack → stripe`。

## INTERPRETATION

可迁移原则是：

> **先出现足以约束方法选择的事实，再出现方法。**

## RECOMMENDED

任何重要算法前先问：

```text
题意、数据、机理或 baseline 中，哪一个事实迫使我们这样做？
```

如果没有明确答案，不要用“为了提高精度”代替理由。

# 4. ORIGINAL PATTERN 3｜问间衔接多靠“条件变化与模块复用”

原论文通常不会先发明一个宏大的统一口号，而是很朴素地说明：下一问与前一问相比多了什么、少了什么、复用了什么。

## 2020 F

原文直接写：

```text
问题三与问题二相比，多了要确定初始油量的任务
```

于是 Q3 分为“初始油量分配 + 问题二供油策略搜索”。

Q4 又说明与 Q2 的两方面不同，并综合使用 Q1 质心公式和 Q2 供油策略模型。

## 2022 C

Q2 取消 Q1 中两个强制优先规则，作者先指出自由度增加，再修改进/出车策略。

## 2022 B

Q2 明确沿用 Q1 排样模型，只把订单分批作为新的上游决策。

## 2024 F

Q2 使用 Q1 卫星状态；Q3 在 Q2 基础上增加时延因素。

## INTERPRETATION

真正的“全文统一”经常来自：

- 状态变量复用；
- evaluator 复用；
- 约束增删；
- 上一问成为下一问子模块；
- 上一问暴露的不足成为下一问研究对象。

## RECOMMENDED

每完成一问，都记录：

```text
本问新得到什么对象？
下一问复用哪一部分？
下一问相对本问新增/删除什么条件？
```

如果这些问题答得清楚，论文自然会连续，不需要赛后硬编一个“大主题”。

# 5. ORIGINAL PATTERN 4｜高价值失败结果会推动重新建模

## 2024 B

作者先把 `(MCS,NSS)` 直接做多分类，结果几乎全部预测为同一类别。正文随后明确写：这种模型无法使用，于是重新观察 PHY Rate 与组合之间的映射关系，再改变预测对象。

这是非常有价值的真实研究过程：

```text
失败
→ 观察失败形态
→ 修改问题表示
→ 再建模
```

## 2020 C

“全预测负类也有 84%”不是被删掉的坏结果，而是支持调整样本策略的证据。

## 2023 B

Q5 明确承认大量测试后仍难满足 `RMSE < 0.1`，只保留“广义逆修正能降低误差”这个较弱但有证据的结论。

## INTERPRETATION

失败实验只有在**改变研究判断**时才有论文价值。

## RECOMMENDED

实验日志增加：

```yaml
observation:
interpretation:
next_decision:
```

论文保留真正改变路线的失败，不保留无意义的调参流水账。

# 6. ORIGINAL PATTERN 5｜结果分析通常从“观察”走向“解释”

## 2023 B

结果段大量采用：

```text
由图/表观察到……
进一步发现……
出现这种现象的原因是……
因此……
```

尤其适合解释精度—复杂度权衡。

## 2024 E

作者会分低密度、高密度和拥堵状态解释不同交通流模型为何表现不同，而不只报告一个 `R²`。

## 2020 F

“过长的持续供油时间会导致质心失衡”这一观察，直接用于缩小后续合理参数区间。

## INTERPRETATION

结果的价值不是“数字已经算出来”，而是：

> **数字有没有改变我们对问题的认识。**

## RECOMMENDED

每个核心结果至少回答：

```text
看到了什么？
为什么可能这样？
它支持/否定了哪个判断？
下一步因此做什么？
```

# 7. ORIGINAL PATTERN 6｜原文也会过度宣称，不能整句照搬

全国一等奖说明论文整体优秀，不说明每个措辞都严格匹配证据。

我们已经看到：

- 2024 B 在验证协议并不严格时就写“良好的泛化能力”；
- 2024 F 把内部反算自洽写得接近“有力证明准确性”；
- 2024 E 把依赖容量提升假设的情景模拟写成较强的实际效果结论；
- 2020 F 模型评价有“效果优秀、效率极高”一类自我评价。

## INTERPRETATION

原文措辞本身也属于审计对象。

## RECOMMENDED

结论强度跟随证据等级：

```text
内部自洽
→ 内部一致

严格验证集优于 baseline
→ 当前协议下表现更好

外部对象/独立时间通过
→ 可以谈一定泛化

假设 + 仿真
→ “在该假设下，模型预测……”
```

少用“充分证明、显著优越、具有很强泛化能力”等无边界词。

# 8. ORIGINAL / INTERPRETATION / RECOMMENDED 示例

以 2024 B 的直接多分类失败为例：

## ORIGINAL

作者观察到模型的 loss/accuracy 停滞，且所有样本几乎都预测成同一 `(MCS,NSS)` 类别，于是判断该直接分类模型不可用，重新观察 PHY Rate 与 `(MCS,NSS)` 的映射。

## INTERPRETATION

这是：

```text
failure-driven reframing
```

即失败证据推动了**预测目标重构**。

## RECOMMENDED

如果我们正赛遇到类似情况，应再补：

- majority baseline；
- confusion matrix；
- group-aware split；
- 类别频率；

确认不是泄漏/不平衡造成假象后，再把“重新定义预测对象”写成研究决策。

# 9. 我们自己的分析框架 OJME-B 应该放在正确位置

主手册中的：

\[
Observation\rightarrow Judgment\rightarrow Model\rightarrow Evidence\rightarrow Boundary
\]

是**我们用于审视研究链完整性的框架**。

它不是：

- 国一论文统一章节模板；
- 作者常用原句；
- 必须机械套用的五段式作文。

它的用途是检查：

```text
方法有没有事实来源？
结论有没有证据来源？
证据强度和结论强度是否匹配？
```

真正写论文时，可以采用更自然的题目语言。

# 10. 正赛推荐表达：让事实推出判断

## 不推荐

> 本题不是普通二维排样问题，而是具有三阶段工艺结构的大规模组合优化问题。

这句话作为教学总结很高效，但放在正文里容易显得先下结论。

## 推荐

> 三阶段齐头切要求同一阶段保持统一切割方向，并限制最终 item 的组合关系。若直接以单个 item 的二维位置为决策变量，搜索空间随 item 数量迅速增长。基于该工艺结构，本文先构造 stack，并进一步组成 stripe 和 plate，以降低排样搜索维数。

这里完成的是：

```text
事实
→ 困难
→ 判断
→ 方法
```

评委不需要先相信我们的口号，可以自己沿逻辑走到同一结论。

# 11. 可直接借鉴的“语言功能”，不是固定句子

## 给依据

- 根据题目给出的……
- 由数据可观察到……
- 考虑到……
- 由于……

## 引出建模动作

- 因此……
- 据此……
- 为此……
- 为了……

## 建立递进

- 在问题一的基础上……
- 相比于前一问，本问新增/取消……
- 结合前述结果……
- 进一步……

## 分析证据

- 由图/表可观察到……
- 结果表明……
- 进一步发现……
- 出现该现象的可能原因是……

## 控制边界

- 在上述假设下……
- 在当前数据与验证协议下……
- 该结果支持……
- 尚不足以说明……

目标是复用这些**论证功能**，不是复制原句。

# 12. 摘要怎样写：先保覆盖，再保研究逻辑

建议整体顺序：

```text
背景 + 本题关键困难
↓
总研究路线
↓
每问：任务 → 判断/方法 → 关键结果
↓
最重要的总体认识或应用意义
```

一个简单测试：把摘要中的算法专有名词暂时遮掉。

如果还能看懂：

- 每问研究什么；
- 为什么这样推进；
- 得到了什么；

说明摘要的研究主线足够清楚。

# 13. 每一问正文的推荐组织

这不是强制章节模板，而是写作检查表：

1. 题目和数据给了哪些关键事实；
2. 这些事实造成什么具体困难；
3. 我们因此做了什么抽象/简化/定义；
4. 数学模型怎样表达它；
5. 算法怎样求解已经定义好的模型；
6. 结果怎样检验原判断；
7. 本问向下一问留下什么状态/模型/问题。

真正重要的是因果关系连续，不是七个小标题必须全部出现。

# 14. 今后学习论文的固定五遍法

## Pass 1｜题意与研究主线

回答作者研究了什么，各问如何连接。

## Pass 2｜技术模型与结果

还原公式、算法、数据、代码、结果。

## Pass 3｜科学审计

检查 evaluator、约束、验证、单位、泄漏、复现、结论边界。

## Pass 4｜原文叙事

只研究原 PDF：

- 摘要如何压缩；
- 问题分析如何引出模型；
- 公式前后如何解释；
- 问间如何过渡；
- 失败如何处理；
- 结果如何转成结论；
- 局限如何表达。

## Pass 5｜三层产出

```text
ORIGINAL
作者实际怎么研究、怎么写

INTERPRETATION
我们抽象出的建模逻辑

RECOMMENDED
结合审计后我们比赛怎样做得更好
```

以后只有完成这五层，才算“既学做题，也学论文”。

# 15. 最终写作原则

从原文重新学习以后，最稳定的结论并不是某个固定句式，而是：

\[
\boxed{
\text{事实先于判断}
\rightarrow
\text{判断先于方法}
\rightarrow
\text{结果服务于检验}
\rightarrow
\text{结论服从于证据}
}
\]

优秀论文的叙事感主要来自：

> **方法出现得有原因，结果出现后有解释，各问之间有接口。**

这比刻意写“本质、核心、不是……而是……”更值得我们学习。
