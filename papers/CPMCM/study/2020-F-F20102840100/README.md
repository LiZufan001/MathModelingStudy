# 0. 指导老师先给结论

这篇最值得训练的，不是“贪心 + 差分进化”几个算法名，而是它构造了一条非常完整的比赛主线：

> **先把飞行器油箱内燃油质心这个物理/几何核心问题做准，再把它封装成后续所有优化问题都能调用的状态评价器；随后逐问增加供油策略、初始油量和姿态变化。**

四问之间不是四套互不相干的模型，而是逐层复用：

```text
问题一：给定油量与俯仰角
        ↓
建立“单油箱燃油质心”解析计算器
        ↓
建立“整机质心”计算器

问题二：给定初始油量 + 理想质心轨迹
        ↓

问题三：初始油量也未知
        ↓

问题四：俯仰角随时间变化、目标回到空机质心
        ↓

```

**这条“基础机理模块 → 控制优化 → 设计变量 → 多场景复用”的论文骨架，是它最像顶级竞赛论文的地方。**

但按今天更严格的评审标准看，这篇也绝不是无瑕疵：

- 官方允许“供油超过发动机需求并排出多余燃油”，作者在问题二以后却主动限制为**恰好满足需求**；

# 1. 原题到底要求什么：先把官方约束和作者假设分开

根据仓库中的原始赛题包，官方核心条件包括：

1. 6 个固定矩形油箱，油箱边与飞行器坐标轴平行；
2. 空机质心为 `(0,0,0)`，空机质量已给定；
3. 每个油箱有最大供油速度，**一次连续供油时间不得少于 60 s**；
4. 2、3、4、5 号油箱可向发动机供油；1、6 号分别作为 2、5 号油箱的备用油箱，不能直接供发动机；
5. 最多 2 个油箱同时给发动机供油，整个系统最多 3 个油箱同时供油；
6. 给发动机的总供油速度至少满足需求；**允许超过需求，多余燃油可以排出飞行器**；
7. 问题一/四还涉及飞行器俯仰角变化下的燃油自由液面与质心。

这六条是**官方约束**。

而论文为了把问题压缩到比赛时间内可算，又增加了若干自己的求解限制，例如：

- 每次供油采用统一的时间块 `T`；
- 多主油箱同时供油时，只枚举若干固定比例；
- 实际求解中把总发动机供油限制为恰好等于需求，不利用官方允许的额外放油自由度；
- 备用油箱补给关系进一步用固定比例近似。

这两类东西必须分开。

**指导老师视角：**允许做合理简化，但必须回答“为什么不会错过关键好解”。  
**评审老师视角：**若额外假设直接缩小原问题可行域，就不能再把得到的结果表述成原问题的严格全局最优。

# 2. 问题一：整篇论文真正的地基——油箱燃油质心解析模型

## 2.1 难点不是整机加权，而是“倾斜矩形油箱里的液体质心”

整机质心本身并不复杂。若空机质量为 `M`，空机质心为原点，第 `k` 个油箱中燃油质量为 `m_k`，燃油质心为

\[
\mathbf r_k=(x_k,y_k,z_k),
\]

则整机质心是

\[
\mathbf r_c=
\frac{\sum_k m_k\mathbf r_k}
     {M+\sum_k m_k}.
\]

真正困难的是：飞行器俯仰后，燃油自由液面保持水平，但油箱本身随飞行器旋转，所以燃油在油箱截面中的形状会随：

- 俯仰角；
- 剩余油量；
- 油箱长、高尺寸

发生变化。

作者没有直接数值积分，而是把问题化成二维截面几何。

## 2.2 为什么可以从三维降到二维

矩形油箱沿 `y` 方向截面不随位置变化，燃油自由液面在该方向上也是均匀延伸，因此可先在 `x-z` 截面上求面积质心，再恢复到三维坐标。

论文根据液面与矩形油箱边界的相交关系，把截面分成多种几何形态，包括：

- 矩形；
- 三角形；
- 两类梯形；
- 五边形等。

不同填充量与俯仰角对应不同临界条件。作者进一步推导了多个解析质心表达式。

这一步是整篇论文最扎实、最值得学的地方之一。

### 指导老师会强调什么

不要一上来就写：

```python
for every tiny volume element:
    numerical_integral(...)
```

若几何结构简单，先寻找：

> **对称性 / 降维 / 分区 / 面积差 / 组合质心公式**

解析公式一旦推出来：

- 速度快；
- 没有积分步长误差；
- 物理意义清楚；
- 后续优化器要调用几万次时优势巨大。

这正是“机理模型先做好”对后续优化算法的价值。

# 3. 问题一的验证：好，但还可以更强

论文做了几类验证：

- 与附件中的已知质心信息做对照；
- 检查整机 `x/y/z` 三个方向质心随时间是否连续；
- 检查 6 个油箱各自燃油质心轨迹是否连续；
- 给出飞行结束时质心等数值结果。

这说明作者至少没有把“推导完公式”当成结束，而是检查了结果物理上是否平滑。

### 评审老师会认可

这是典型的：

> **解析模型 → 数值实现 → 可视化 → 已知点核验**

闭环。

### 但还不够

连续并不等于正确。一个错误公式也可能生成连续曲线。

如果今天我们做这题，我会要求再加一个独立验证：

随机抽取若干 `(油量, 俯仰角)`，用高精度数值积分/网格积分求一次燃油质心，和解析公式逐点比较：

\[
\varepsilon=\|\mathbf r_{analytic}-\mathbf r_{numeric}\|.
\]

报告最大误差、平均误差。

这样评委看到的就不只是“曲线很好看”，而是：

> **解析模型已经被独立数值方法交叉验证。**

# 4. 问题二：从物理模型进入动态供油优化

问题二给定理想质心轨迹，要求设计供油策略，使真实质心轨迹尽量贴合理想轨迹。

作者把目标写成一个典型的 minimax 形式：

\[
\min_u \max_t
\left\|
\mathbf r_c(t;u)-\mathbf r^*(t)
\right\|_2.
\]

这点选择很好，因为题目关心的是全过程中**最坏时刻**的偏差，而不是平均误差。

若只最小化

\[
\sum_t \|r_c(t)-r^*(t)\|^2,
\]

可能出现“大多数时刻很好、某一个时刻严重跑偏”的方案。

因此：

> **题目写“最大偏差尽可能小”时，要首先想到 minimax / infinity norm，而不是默认均方误差。**

# 5. 原问题为什么难：连续控制 + 离散开关 + 最短持续时间

真正完整的控制变量至少包括：

- 哪些油箱此刻开启；
- 每个开启油箱的流量；
- 开启以后至少持续 60 s；
- 主油箱/备用油箱之间的转移；
- 油量库存状态；
- 同时供油数量限制；
- 发动机需求；
- 允许额外排油；
- 最坏时刻质心偏差。

所以这不是一个普通连续优化，而更接近：

> **混合离散-连续、带时间耦合与最小开机时间约束的动态 minimax 控制问题。**

论文把它称作“单目标二次混合优化问题”，这个说法不够严谨。因为燃油质心中的 `z` 分量随油量本身可出现二次关系，再叠加欧氏范数、最大值、离散供油组合以及时间状态转移，完整问题并不能简单归为标准 MIQP。

这是一个论文术语上的可改进点。

# 6. 作者真正的关键选择：主动压缩策略空间

如果每秒都从所有合法供油组合中选动作，作者估计组合爆炸极其严重。因此他们没有直接全局搜索整个 7200 s 控制序列，而是引入：

1. **时间分块**：一次策略保持 `T` 秒；
2. **合法组合预枚举**：构造满足供油数量约束的油箱组合；
3. **离散比例**：两个主油箱同时供油时，只枚举若干比例；
4. **滚动贪心**：每一个时间块里选当前块最有利的组合，执行后更新油量，再处理下一个块。

论文枚举出 34 类供油组合，并在比例网格上寻找当前块的最佳动作。

于是一个超大动态优化问题被压缩成：

```text
for each block:
    enumerate legal tank combination
    enumerate flow split ratio
    simulate this block
    evaluate max centroid deviation in block
    choose local best action
    update fuel state
```

这就是整篇论文第二个非常值得学的东西：

> **当完整控制序列搜不动时，先设计一个低维“策略类”，而不是硬上全局元启发式。**

# 7. 为什么滚动贪心在比赛里是合理选择，但论文不能把它说得太满

从比赛工程角度，它有明显优势：

- 每一步都保持可行；
- 能不断用最新油量状态重新决策；
- 单次决策空间有限；
- 计算时间可控；
- 很容易生成完整 7200 s 结果表；
- 能直接调用问题一的质心函数。

因此指导老师会说：**这是一个很实用的 baseline。**

但评审老师会继续问：

> 为什么每一块局部最好，就能保证整条轨迹足够好？

答案是：不能保证。

由于当前多放掉一点 2 号油箱的油，可能影响 2000 s 后的可控性，因此这是带状态耦合的动态问题。一步贪心没有严格的 Bellman 最优性保证。

所以更严谨的措辞应该是：

> “构造一种高效可行的滚动启发式，并通过实验表明其结果较好。”

而不是把它描述成原问题的严格全局最优。

# 8. 问题二的一个重大建模取舍：作者放弃了官方允许的“额外排油”

官方条件明确允许：

\[
\sum_{i\in engine}u_i(t)\ge d(t),
\]

若供油超过发动机需求，多余燃油可排出飞行器。

而论文实际求解基本采用：

\[
\sum_{i\in engine}u_i(t)=d(t).
\]

这样做当然能显著减少控制自由度，也能保证总油耗恰好等于发动机需求。

我用原始附件重新求和，得到问题二发动机总需求：

\[
6441.524211750931\ \text{kg},
\]

论文结果中主油箱总供油量为约

\[
6441.52421\ \text{kg},
\]

两者高度一致。

这是**数据一致性验证的优点**。

但是从优化理论看，这个等式是作者新增的限制，不是题目原约束。

额外排油可能在某些时刻有价值：主动从远离目标质心的一侧多排一些燃油，也许能换取更小的最大质心偏差。

因此论文解更准确的定位应是：

> **原问题一个受限策略子空间中的高质量可行解。**

如果我们正式比赛采用这种缩减，必须补一段实验：开放少量可控放油自由度，比较目标是否还能继续改善，从而说明这一简化的代价。

# 9. T 的选择：作者有做敏感性，但正文与代码存在冲突

论文考察了多个分段长度 `T`，最终问题二选择：

\[
T=85\text{s}.
\]

这种“扫超参数再选结果”的思路是对的。

但正文写过：`T` 应为 7200 的因数。

实际上：

\[
7200\bmod85=60,
\]

所以 85 不是 7200 的因数。

而附录代码中原本用于检查整除的条件被注释掉了。

类似地，问题四最终选：

\[
T=67\text{s},
\]

同样：

\[
7200\bmod67=31.
\]

### 这对评审意味着什么

这不是“结果一定错了”，因为代码可以按完整块 + 尾块的方式处理；但正文必须和实现口径一致。

如果说“必须整除”，代码就必须 enforce；如果允许最后一个短尾块，就应该在论文明确写：

```text
前若干段长度为 T，最后不足 T 的时间单独处理。
```

这是典型的**假设—算法—代码三者一致性检查**。

# 10. 问题二结果：可行性验证比最优性验证扎实

论文最终报告问题二最大质心偏差约：

\[
0.089183\text{ m},

最大偏差出现于约 `t=4982 s`。

同时检查了：

- 各油箱供油速率；
- 主油箱总供油是否满足发动机需求；

这能证明策略基本满足题目物理约束。

没有足够证据回答：

> 0.089183 到底离“能做到的最好值”有多远？

- 简单规则 baseline；

这样才能把“能跑出一个很好看的结果”升级到“我们有证据说明这个启发式确实强”。

# 11. 问题三：把“初始油量”也变成设计变量

问题三相比问题二多了一层：初始各油箱油量不再固定，而且最终至少保留 1 m³ 燃油。

作者采用两阶段方法：

## 第一阶段

给定一个总初始油量，通过**差分进化（Differential Evolution, DE）**在各油箱容量约束下分配初始燃油，使初始质心尽量合理。

## 第二阶段

把得到的初始油量放进前面问题二的滚动供油算法，得到全过程最大偏差。

然后改变总初始油量，比较结果。

这是一个很典型的：

> **外层设计变量 + 内层动态控制器**

结构。

# 12. 问题三的亮点与关键不足

## 12.1 亮点：维数拆开了

若一口气联合优化：

- 6 个初始油量；
- 7200 s 的供油组合；
- 每段供油流量

搜索空间会非常夸张。

作者先处理初始配置，再复用问题二控制器，是一种比赛时间内务实的 decomposition。

## 12.2 但两阶段并不等价于联合最优

“初始时刻的质心最接近目标”不一定意味着：

> “7200 s 全程最大偏差最小”。

有些初始配置第一秒稍差，但后续 7000 s 更容易控制，反而全过程更优。

因此如果今天重做，更合理的是：

\[
\min_{M(0)}J\bigl(M(0),\pi^*(M(0))\bigr),
\]

其中内层 `π` 是供油控制器，外层 DE/贝叶斯优化直接以**全过程最大偏差**作为适应度，而不是先只优化初始时刻。

# 13. 问题三的“拟合”其实证据偏弱

论文对初始总油量给出的结果大致是五个采样点：

| 相对最低允许量 | 全程最大偏差 / m |
|---|---:|
| +0 | 0.230492 |
| +0.5 m³ | **0.172049** |
| +1.0 m³ | 0.246351 |
| +1.5 m³ | 0.268438 |
| +2.0 m³ | 0.279779 |

作者据此选择第二个点。

这里论文使用了“拟合”一类表述，但并没有展示：

- 拟合函数；
- 拟合误差；
- 连续最小点；
- 更密集采样。

所以严格说，只能得出：

> **在所测试的 5 个总油量候选中，+0.5 m³ 最好。**

不能据此证明连续变量意义下的最优总初始油量。

# 15. 差分进化本身用得合理，但复现信息不够

问题三选择 DE 是合理的：

- 连续变量；
- 有上下界；
- 目标复杂、可能不可微；
- 维度不算特别高。

但论文对 DE 的介绍偏教科书化，而真正决定可复现性的参数没有充分交代：

- 种群规模；
- 变异因子 F；
- 交叉概率 CR；
- 迭代代数；
- 边界修复方式；
- 随机种子；
- 是否多次重复；
- 最终收敛曲线。

附录中也没有完整给出这部分可直接复现的实现。

### 指导老师要求

竞赛论文不要把篇幅花在“DE 是什么”的通用介绍上，却省掉自己的实际配置。

应该写：

```text
population = ...
F = ...
CR = ...
generations = ...
repeat = ...
seed = ...
```

并附收敛曲线与多次运行均值/方差。

# 17. Q4 的尾段问题：数据上可能没伤到结果，但算法设计仍应修

若每段固定 `T=67 s`：

\[
7200\bmod67=31.
\]

附录代码的循环条件按字面存在最后一小段未按同样逻辑处理的风险。

这次原始数据有一个特殊情况：问题四最后约 51 s：

- 发动机需求为 0；
- 俯仰角也为 0。

因此在**这组具体数据**里，漏掉最后几十秒可能不会改变最坏质心偏差。

但工程上仍不能依赖这种巧合。

正确实现应该显式：

```python
end = min(begin + T, total_time)
```

直到 `begin == total_time`。

# 18. 附录代码里值得我们警惕的“旧状态变量”问题

我把正文和附录对照时发现，部分双主油箱供油支路中：

1. 先更新了当前油量 `c_oil`；
2. 但随后计算质心时，部分代码仍把旧的 `oil` 传入或参与分子计算；
3. 分母又使用更新后的 `c_oil`。

问题四部分也存在类似风险。

如果按附录代码字面执行，这会造成：

> **状态更新了一半，评价函数却混用了旧状态与新状态。**

需要强调：公开论文里的附录代码不一定与作者比赛时最终运行版本百分之百一致，所以仅凭这一点不能断言论文数值一定错误。

但对于我们自己的竞赛代码，这属于必须被测试挡住的问题。

建议统一设计：

```python
next_state = transition(state, action)
score = evaluate(next_state)
```

禁止 evaluate 同时引用 `state` 和 `next_state` 的内部变量。

# 23. 我们正式比赛真正应该带走的 8 条

1. **先造高可信的机理计算器，再优化。** 优化器的上限取决于评价函数是不是物理正确。
2. **多问必须复用前问。** 最漂亮的论文往往是逐层加变量，而不是每问换一套算法。
3. **看到“最大偏差最小”优先想到 minimax。**
4. **大规模动态优化可以先限制策略类。** 但必须说明限制代价。
5. **滚动贪心是很好的 baseline，不要假装它天然全局最优。**
6. **官方允许的自由度不要未经验证就删掉。** 如果删，做对照实验。
7. **所有经验常数都要有出处或敏感性分析。**
8. **论文、代码、结果表必须共用同一状态与同一约束定义。**
