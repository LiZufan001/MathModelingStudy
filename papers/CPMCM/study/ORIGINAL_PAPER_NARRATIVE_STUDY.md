# 国一论文原文叙事研究｜从“我们怎么总结”回到“作者实际怎么写”

> 本文件用于纠正前期学习方法中的一个重要偏差：此前的精读重点是**模型重构与技术审计**，其中大量“不是 A，而是 B”“真正关键的是……”属于指导老师式二次概括，并不等于原论文作者的真实表达。  
> 从本文件开始，论文学习严格区分三层：
>
> - **ORIGINAL｜原文观察**：作者实际采用的章节结构、语言动作和证据组织；
> - **INTERPRETATION｜二次抽象**：我们从原文中抽象出的建模逻辑；
> - **RECOMMENDED｜正赛建议**：结合原文优点与技术审计后，我们建议自己怎样写。
>
> 三层不得混写。尤其不得把 `INTERPRETATION` 重新描述为“作者就是这样说的”。

# 1. 本轮重新学习了什么

本轮重新从仓库中的 exact-match 国一 PDF 原文出发，重点抽取：

1. 摘要；
2. 问题分析；
3. 各问模型引入段；
4. 问题之间的过渡；
5. 结果分析；
6. 模型评价、局限和结论。

语言可可靠抽取的样本为：

- 2022 C `C22106140003`；
- 2020 F `F20102840100`；
- 2024 B `B24102860287`；
- 2023 B `B23104860044`；
- 2022 B `B22106140009`；
- 2020 C `C20102860127`；
- 2024 F `F24104860143`；
- 2024 E `E24102910005`。

2021 A `A21102480004` 的 PDF 字体编码导致自动提取严重乱码，因此：

> **本轮只保留此前已确认的结构性认识，不把它纳入原文措辞统计。**

这也是本次学习方法的一部分：原始证据质量不足时，宁可少一个样本，也不把乱码推断成作者语言习惯。

# 2. 第一项纠偏：“不是……而是……”并不是这些论文的常用叙事风格

对 9 份 PDF 的可提取文本做粗粒度语料扫描，总字符数约 `637,112`。完整正则：

```text
不是 ... 而是 ...
```

只命中 **1 次**。

而且唯一命中来自 2024 E 对“堵塞”概念的字面澄清，大意是：堵塞并非车辆完全静止，而是以较低速度拥挤运行。

它并不是类似：

```text
本题不是排序问题，而是状态系统。
```

这种“制造洞察反差”的教学式表达。

因此此前我们在 README / 对话中频繁使用：

- “不是……而是……”；
- “真正关键的不是……”；
- “本质不是……”；

主要是**我们的教学总结语言**，不能说成国一论文作者的普遍写法。

全语料扫描得到的大致次数：

> **这些论文主要靠什么语言动作连接研究过程？**

答案很清楚：主要是**依据、原因、目的、递进、结果和比较**。

# 3. ORIGINAL：优秀论文真实、反复出现的叙事动作

下面只描述作者原文中实际出现的组织方式，不把我们的二次总结冒充原文。

## 3.1 摘要最常见：`针对问题 X → 方法 → 关键结果`

多个样本的摘要都大量采用：

```text
针对问题一……
针对问题二……
针对问题三……
```

这是竞赛论文非常直接的任务映射方式。

它的优点不是文采，而是评委可以迅速完成：

```text
题目第 i 问 ↔ 摘要第 i 段
```

### 原文观察

- 2020 F：摘要先说“下面针对每个问题给出方法与结果”，再逐问写任务、方法、数值结果。
- 2023 B：五问全部采用“针对问题 X，本文……”展开，并紧跟误差/复杂度结果。
- 2020 C：四问全部采用“针对问题 X……”，同时直接给识别率、通道组合、半监督准确率等。
- 2024 F：四问按“针对问题 X”串起轨道、时延和仿真。
- 2024 E：摘要直接写“问题1/2/3/4”，每问报告方法与最终作用。

### INTERPRETATION

摘要首先承担的是**任务覆盖证明**，而不是展示算法名数量。

### RECOMMENDED

我们可以保留“逐问对应”，但每问尽量再增加一句**为什么这样研究**，避免摘要只成为模型清单。

---

## 3.2 问题分析常见：`题目条件/数据事实 → 困难 → 因此`

真正好的模型引入，通常不是先介绍算法原理，而是先把题目中的事实说出来。

### 2023 B

原文的研究动作很清晰：

```text
非零元素相乘才消耗乘法器
→ 希望分解矩阵产生更多零元素
→ 把稀疏性作为优化对象
```

Q3 又是：

```text
稀疏与量化同时存在
→ 两种操作可能相互影响
→ 执行顺序本身成为待研究对象
→ 比较 S-Q 与 Q-S
```

这不是靠“本质是……”来宣称洞察，而是由约束自己把方法推出去。

### 2020 C

Q1 先算出：P300 正样本只约占 16.7%，如果全部预测为负类，表面训练精度就能约 84%。作者随后才引出随机抽样平衡。

Q3 则先给出现实资源事实：

```text
有标签样本获取耗时
+ 无标签样本容易得到
→ 对应半监督学习场景
```

### 2022 B

摘要先提出现实矛盾：

```text
批次过小 → 利用率/效率低
批次过大 → 交期风险上升
```

Q1 又观察到大量 item 存在相同边长，于是依次构造 `2-items → stack → stripe`。

### INTERPRETATION

这里真正值得学的研究动作是：

> **先展示一个足以约束方法选择的事实，再引出方法。**

### RECOMMENDED

正式比赛中，任何重要算法前优先回答：

```text
题目/数据中哪一个事实使这个方法成为合理选择？
```

如果答不出来，该算法大概率只是“算法购物”。

---

## 3.3 各问之间真实的桥：`在前问基础上`、`相比前问多了/取消了什么`

这些论文很少用宏大的统一主题口号，而更常通过**变量、条件和已有模型的复用**建立连续性。

### 2020 F

原文直接写：

```text
问题三与问题二相比，多了要确定初始油量的任务
```

于是把 Q3 分成：

```text
初始油量分配
+ 问题二的供油策略搜索
```

Q4 又直接写“综合使用问题一质心公式与问题二供油策略模型”。

### 2022 C

Q2 不再要求两条 Q1 的强制优先规则，作者先指出因此“赋予更高自由度”，再修改入车/出车选择依据。

### 2022 B

Q2 明确说满足 Q1 的排样约束，因此可以沿用第一题排样模型，只在上游增加分批。

### 2024 F

Q2 直接使用 Q1 的卫星位置/速度；Q3 在 Q2 基础上增加多个时延项；Q4 转到光子生成与折叠。

### 2024 E

Q3 明确使用前两问的实时统计和应急车道决策流程，做“重演 + 前后对比”。Q4 又从前问暴露出的下游状态缺失，提出新增监控点。

### INTERPRETATION

论文连续性主要来自：

- 变量复用；
- evaluator 复用；
- 约束增删；
- 状态升级；
- 前问失败/缺口成为后问任务。

而不是必须在开头发明一句统一的“大主题”。

### RECOMMENDED

每做完一问，强制记录：

```text
本问产出了什么对象？
下一问能否直接复用？
下一问相对本问新增/删除了什么条件？
```

这比最后再硬编“全文围绕某某统一主题”可靠。

## 3.4 方法升级的真实写法：`发现失败 → 改变建模对象`

这是本轮最值得重新学习的地方之一。

### 2024 B Q2

作者先直接做 `(MCS,NSS)` 多分类。结果观察到模型几乎把所有样本都预测成同一类。

正文没有把失败隐藏掉，而是：

```text
观察失败结果
→ 判断直接多分类不可用
→ 重新观察 PHY Rate 与 (MCS,NSS) 映射
→ 先建 PHY Rate，再映射组合
```

这是非常真实的研究叙事。

### 2020 C

作者通过 84% 的“全负类也很高”现象，说明 accuracy 会被类别失衡欺骗，随后调整训练样本构造。

### 2023 B Q5

正文明确承认大量测试后仍很难满足 `RMSE < 0.1`，随后把结果解释为：新增广义逆修正因子能够改善精度，但不能把未达到硬门槛写成已经完成。

### INTERPRETATION

失败结果如果真的改变了建模判断，就是**研究证据**，不是应删除的废实验。

### RECOMMENDED

比赛日志必须记录：

```yaml
observation:
interpretation:
next_decision:
```

论文中保留那些“改变了路线”的失败结果，而不是把所有调参失败都堆进去。

---

## 3.5 结果分析常见：`由图/表/结果 → 观察趋势 → 解释原因 → 得出有限结论`

### 2023 B

结果分析经常采用：

```text
由图/表可以观察到……
进一步发现……
出现这种现象的原因是……
因此……
```

尤其适合精度—复杂度 trade-off。

### 2024 E

交通流拟合不是只报 `R²`，正文会分低密度、高密度、拥堵阶段解释不同模型曲线为什么表现不同。

### 2020 F

会写“实验发现：过长的持续供油时间会导致质心失衡”，再据此缩小合理的持续供油区间。

### INTERPRETATION

数字只有经过解释，才真正成为建模结论。

### RECOMMENDED

每张核心结果图至少回答三层：

```text
看到了什么？
为什么可能出现？
它改变了什么研究判断/决策？
```

不要停在“模型效果良好”。

## 3.6 原文并不总是“严谨克制”，优秀论文也会过度宣称

正确学习原文不能把一等奖论文当作语言规范答案。

例子包括：

- 2024 B 用很弱的验证协议就写“良好的泛化能力”；
- 2024 F 把内部自洽验证写得接近“有力证明准确性”；
- 2024 E 的情景模拟结果被写成较强的“开放应急车道效果显著”；
- 2020 F 的模型评价中存在“效果优秀、效率极高”这类强评价。

### INTERPRETATION

**原文措辞本身也需要评审。**

我们不能因为某个句子出现在国一论文里，就认为应该照抄。

### RECOMMENDED

采用“证据等级 → 结论等级”规则：

```text
内部自洽
→ 只说内部一致

当前验证集优于 baseline
→ 只说当前协议下表现更好

独立外部对象通过
→ 才谈泛化

情景假设 + simulation
→ 写“在该假设下模型预测……”
```

# 4. 八篇可读原文的叙事画像

| 论文 | 原文中最值得学的研究动作 | 原文表达特点 | 不建议照搬的地方 |
|---|---|---|---|
| 2022 C | 规则 → 进/出车两类决策 → Q2 放宽规则后改策略 | 摘要非常操作化；正文大量“因此/根据” | 对结果有效性的宣称偏强 |
| 2020 F | Q1 基础机理 → 后问复用；明确比较 Q3/Q4 与 Q2 的新增条件 | “通过分析可知”“问题三与问题二相比”很直接 | 模型评价较模板化 |
| 2024 B | 机理分项分析；直接分类失败后重看数据映射 | “问题核心是…”+“观察发现…因此重新…” | 泛化结论明显超过验证证据 |
| 2023 B | 约束直接推出稀疏/量化；新约束推出 S-Q/Q-S 比较 | 因果链非常显式；结果段重视趋势与原因 | 部分算法命名/结果口径并不严谨 |
| 2022 B | 现实矛盾 → 工艺结构 → 数据结构重表达 | 摘要很像完整技术路线说明书 | 一些“科学/可靠/线性复杂度”宣称证据不足 |
| 2020 C | 类不平衡先算反例；资源不对称推出半监督 | “考虑到…因此…”非常自然 | 部分验证与结果解释不够严格 |
| 2024 F | 每问先画“问题分析—模型—求解—验证”流程；前问状态复用 | 结构显式，解释量大 | “精确/有力证明”使用过多 |
| 2024 E | 监测 → 预测 → 决策 → 反事实 → 监控重布置 | 分问清晰；大量从交通事实引出规则 | 情景假设与实证效果界线不够清楚 |

# 5. 从原文中总结出的“科学叙事”真正长什么样

如果去掉算法名字，八篇可读样本中反复出现的是下面这条朴素链：

```text
题目要求 / 数据观察 / 物理事实
          ↓
指出一个具体困难
          ↓
做一个明确的简化、转换或定义
          ↓
建立模型 / 算法
          ↓
给出数值、图表或对照
          ↓
解释现象
          ↓
进入下一问或指出不足
```

它和我们抽象的 OJME-B 可以对应，但必须注意：

> **OJME-B 是我们的分析框架，不是作者的原文章节模板。**

作者原文往往更朴素、更具体，也未必严格按五个词展开。

# 6. 正确的学习单位：不是“好句子”，而是“研究动作 + 表达 + 证据”

以后学习一段优秀论文，统一记录四栏：

| 层 | 记录内容 |
|---|---|
| `ORIGINAL` | 作者实际如何提出问题、连接方法、解释结果 |
| `RESEARCH_MOVE` | 这一段完成了什么研究动作 |
| `EVIDENCE` | 作者拿什么支撑该动作 |
| `RECOMMENDED` | 我们结合技术审计后，正赛应怎样更严谨地表达 |

例如 2024 B 的直接 25 分类失败：

```text
ORIGINAL
观察到模型几乎全部预测成同一类别，因此重新观察 PHY Rate 映射。

RESEARCH_MOVE
failure-driven reframing

EVIDENCE
loss/accuracy 不再变化 + 预测类别塌缩

RECOMMENDED
进一步补 class baseline、confusion matrix、严格 group split 后，再说明为何改预测目标。
```

这才是可迁移的学习。

# 7. 我们正赛表达应该“像研究”，但不必复制国一原句

## 7.1 可以学的句法功能

### 给依据

```text
根据题目给出的……
由数据可见……
考虑到……
由于……
```

### 引出决策

```text
因此……
据此……
为此……
为了……
```

### 建立递进

```text
在问题一的基础上……
进一步……
相比问题一，本问新增……
结合前述结果……
```

### 分析证据

```text
由图/表可观察到……
结果表明……
进一步发现……
出现该现象的可能原因是……
```

### 控制结论

```text
在上述假设下……
在当前数据与验证协议下……
该结果支持……
尚不能说明……
```

## 7.2 不要机械复制的模板腔

- 每段都“针对问题 X”；
- 每个模型都“科学合理、效果优秀”；
- 每个算法都“具有良好泛化能力”；
- 大量“首先、其次、最后”却没有因果；
- “为提高精度，引入某高级模型”但没有失败证据；
- “结果符合实际”但没有说明比较对象。

# 8. 一个比“不是 A 而是 B”更成熟的表达规则

如果确实想强调问题重构，不要先喊结论，让事实把它推出去。

### 教学总结式

```text
这不是普通排样问题，而是带三阶段工艺结构的组合优化问题。
```

### 正赛研究式

```text
三阶段齐头切要求同一阶段保持统一切割方向，并限制最终 item 的组合关系。若直接以单个 item 的二维位置为决策变量，搜索空间随 item 数量迅速增长。基于该工艺结构，本文先构造 stack，并进一步组成 stripe 和 plate，以降低排样搜索维数。
```

后一种写法的优势不是“更高级”，而是：

> **评委不需要相信你的口号；他可以沿着事实自己得到相同判断。**

# 9. 对此前学习成果的重新定性

此前 README、MODEL_RECONSTRUCTION、REVIEWER_REPORT 并非全部作废。

它们分别仍有价值：

- `README / MODEL_RECONSTRUCTION`：主要属于 **INTERPRETATION**，用于理解模型结构；
- `REVIEWER_REPORT / *_AUDIT`：属于 **TECHNICAL AUDIT**，用于训练科学验证；
- 原论文 PDF：才是研究 **ORIGINAL NARRATIVE** 的唯一权威来源。

真正错误的是：

> **曾把 INTERPRETATION 中的教学表达，说成作者原文普遍采用的叙事。**

以后任何“作者怎样写”的结论，必须回到 PDF 原文核验。

# 10. 今后的固定论文学习流程

每篇论文今后按五遍读法：

## Pass 1｜题意与研究主线

回答作者研究了什么，各问怎样连接。

## Pass 2｜技术模型与结果

还原公式、算法、数据、代码与结果。

## Pass 3｜科学审计

检查 evaluator、约束、验证、单位、泄漏、边界和复现。

## Pass 4｜原文叙事

只研究作者实际文本：

- 摘要怎样压缩；
- 问题分析怎样引出模型；
- 公式前后怎样解释；
- 问间怎样过渡；
- 失败怎样处理；
- 结果怎样转成结论；
- 局限怎样表达。

## Pass 5｜三层产出

```text
ORIGINAL
作者实际怎样研究和表达

INTERPRETATION
我们认为其深层建模逻辑是什么

RECOMMENDED
结合审计后，我们比赛时怎样做得更好
```

只有完成这五遍，才算“既学会做题，又学会写论文”。

# 11. 最终学习结论

这轮重新回到原文后，一个非常重要的认识是：

> **优秀论文的“叙事感”通常不是来自漂亮句式，而是来自方法出现得有原因、结果出现后有解释、各问之间有接口。**

作者往往说得很朴素：

```text
由于……
因此……
根据……
在前问基础上……
观察结果发现……
进一步……
```

真正形成说服力的是这些词背后的**研究因果**。

所以我们的目标不是模仿一等奖论文的口头禅，而是做到：

\[
\boxed{
\text{事实先于判断}
\rightarrow
\text{判断先于方法}
\rightarrow
\text{结果服务于检验}
\rightarrow
\text{结论服从于证据}
}
\]

这才是从这些论文中应该学走的“叙事”。
