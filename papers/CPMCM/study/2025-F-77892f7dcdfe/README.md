# 0. 指导老师先给结论

这类题最难的不是公式，而是：

> **怎样把“趣味性、幻境感、有法无式”这种软概念，拆成可以被附件数据观察、计算、比较和验证的机制。**

182 页候选最值得学习的一条主线是：

```text
主观美学词
  ↓
可观察机制
  ↓
空间/序列状态
  ↓
局部指标
  ↓
路径/园林级聚合
  ↓
优化或评分
  ↓
理论应然关系 + 泛化对象验证
```

它的三问不是三个孤立的评价模型：

```text
Q1  路网 + 视景变化
        ↓
     趣味性 / 最优游线
        ↓
Q2  元素格局 + 开合变化
        ↓
     幻境感
        ↓
Q3  Q1/Q2 特征 + 多尺度结构
        ↓
     相似度 / 共性 / 个性 / 泛化
```

因此真正值得搬到赛场的不是某个历史权重，而是四个动作：

1. **把软概念拆成机制，不直接打分。**
2. **把“人在移动中看到什么”建成序列，而不是只看静态总量。**
3. **局部状态先算细，再聚合到优化图和园林级指标。**
4. **没有真实标签时，用理论应然关系和外部对象泛化来验收。**

# 1. Q1：“移步异景”不是“转弯越多越好”

## 1.1 路径先变成图

候选采用 Voronoi 思想从可通行空间抽取路径骨架，再：

- 去掉穿过障碍物的边；
- 保留最大连通分量；
- 修剪无意义支路，同时保护入口/出口；
- 人工补全少量几何缺陷。

最终得到：

\[
G=(V,E).
\]

这个步骤非常实战，因为附件通常给的是：

- 建筑边界；
- 水体/假山/植物；
- 道路多边形；

而题目要求的是“游客从哪里走”。

一个常见错误是直接把所有坐标点连成图。正确思路是：

> **先恢复 feasible space，再从 feasible space 抽 navigation graph。**

这可以迁移到：

- 仓库 AGV 路径；
- 机器人避障；
- 校园疏散；
- 无人机航道；
- 管网/道路中轴线提取。

## 1.2 “异景”必须是观察状态变化

候选沿路径做射线探测：

- 视线高约 1.6 m；
- 方位约每 3° 一条射线；
- 获得节点周围不同景观类型的可视状态；
- 形成视景矩阵。

因此每个路径节点不是一个裸坐标，而有一个景观状态：

\[
s_i=(water, rock, plant, building, semiopen, \ldots).
\]

关键思想：

> **美学体验是状态序列，而不是静态元素总表。**

例如两个园林水体比例相同，但：

```text
园 A：一直能看见水
园 B：遮挡 → 突然见水 → 消失 → 再出现
```

游客体验显然不同。

## 1.3 时间域 + 空间域双分解

候选把“异景”拆成两部分：

### 时间维

利用景观状态转移概率描述“下一步是否出乎意料”。

一种抽象是：

\[
D_t(i)=-\log P(s_{i+1}\mid s_i).
\]

低概率状态转移意味着更强意外性。

### 空间维

用状态向量的差异，例如汉明距离：

\[
D_s(i)=d_H(s_i,s_{i+1}).
\]

最终局部异景度可写：

\[
LD_i=\alpha D_t(i)+(1-\alpha)D_s(i).
\]

这个分解很有训练价值：

> **“变化有多大”和“变化有多意外”是两件不同的事。**

以后碰：

- 用户浏览路径惊喜度；
- 产品推荐新鲜度；
- 剧情节奏；
- 交通状态突变；
- 行为序列异常；

都可以采用“幅度 + 意外性”的双指标。

## 1.4 微观图 → 宏观图

候选先在密集采样点计算视景，再把度为 1 或 ≥3 等关键点聚合成宏观图。

这是特别实战的一招：

```text
高分辨率层：负责算准
低分辨率层：负责优化
```

不要一开始就把整个问题粗化，也不要让 NSGA-II 在几万个采样点上搜索。

一般化模板：

\[
\text{fine state graph}\rightarrow\text{salient graph}\rightarrow\text{optimization}.
\]

## 1.5 路径规划用 Pareto，而不是先拍一个权重

Q1 最终不是简单：

\[
\max Interest-0.5Length.
\]

而是把：

- 异景趣味性；
- 重复路径/路径效率；

放进 NSGA-II 形成 Pareto 前沿。

这比“主观定 0.7/0.3”更适合审美/体验题，因为评委可以看到：

```text
效率型游客 ←→ 深度游览型游客
```

之间真实的 trade-off。

# 2. Q1 的验证：没有标签时怎么办？

候选做了一个特别值得学习的动作：

> 用题目自己给出的“理论应然关系”做统计自检。

题面暗示：

> 小空间内更多转折，通常意味着更强“移步异景”。

候选检查转折密度与异景程度，报告多组 Pearson 相关约：

\[
r=0.78,\;0.82,\;0.85,
\]

且显著。

这不等价于“专家说这条路线最好”，但至少证明：

> 指标没有违反题目的基本机制预期。

这是没有 ground truth 的主观题非常重要的验证层：

\[
\boxed{mechanism consistency}
\]

实战时建议至少做四层：

1. **mechanism check**：理论应然关系；
2. **baseline**：最短路/随机路/人工路线；
3. **sensitivity**：阈值权重变化；
4. **external object**：新对象全流程复算。

候选 Q1 的不足是：缺少官方推荐路线/专家路线作为独立外部基准。

# 3. Q2：“小中见大”不能直接变成 AHP 表

很多队看到“幻境感评分”会直接：

```text
AHP
→ 十几个指标
→ 100分
```

这通常很弱，因为指标和美学词之间缺中间机制。

候选做得更好：先拆为两件事：

```text
静态：元素怎样分布？
动态：空间怎样开→合→开？
```

## 3.1 静态格局：用成熟空间统计量

候选将园林栅格化并提取连通斑块，然后使用：

- Shannon diversity；
- largest patch index；
- aggregation index；
- CONTAG；
- Moran's I；
- edge density；
- fractal/shape；
- nearest-neighbor distance；
- connectivity；
- IIC 等。

这里的学习点不是“以后把这十个指标全抄上”。

而是：

> **软概念先映射到一个成熟学科中已有的机制指标。**

例如：

- 多样性 → information entropy；
- 聚集/离散 → Moran's I / NNI；
- 连通性 → graph connectivity；
- 边界复杂度 → fractal / perimeter-area；
- 围合 → visibility / spatial syntax。

这比自己发明十个比例式更容易获得评委信任。

## 3.2 “开阔/围合”必须有可观测定义

候选把空间句法/视域指标加入判定，例如可视连接度 `View_Co`，与最近距离、围合比等形成双阈值标准。

其核心思路可抽象为：

\[
Open(x)=f(visibility, obstacle\ distance, enclosure).
\]

然后：

```text
Open → Open → Closed → Closed → Open
```

才成为“开合节奏”。

也就是说：

> **“幻境感”不是一个静态评分，而是空间状态的交替。**

这个方法可以迁移到：

- 建筑空间体验；
- 展馆路线；
- 游戏地图节奏；
- 商场动线；
- UI 信息密度变化。

## 3.3 用题目指定基准做校准，而不是随便 min-max

题目指定寄畅园作为 100 分基准。

候选不是忽略这个条件，而是把寄畅园指标作为标尺，再给其余园林线性标准化和评分。

实战技巧：

> **题面给 benchmark，就把 benchmark 变成 calibration anchor。**

例如：

\[
s_{ij}=100\cdot g_j(x_{ij};x_{benchmark,j}).
\]

然后必须说明：

- 越大越好？
- 越小越好？
- 是否存在最适区间？

尤其审美题往往不是单调关系。

# 4. Q2 最大问题：权重 50/50 没有充分证据

候选最终把：

- 元素分布；
- 开合变化；

大体按 50% / 50% 合成。

这非常典型：

> 指标定义很认真，最后一步却拍脑袋权重。

而且 Q2 的空间句法只对少数园林做了完整 Depthmap 分析，却支撑十园统一阈值，存在证据覆盖范围不足。

所以比赛时推荐：

### 方案 A｜主客观组合权重

\[
w=\lambda w_{AHP}+(1-\lambda)w_{CRITIC}.
\]

### 方案 B｜有专家评分时反推权重

\[
\min_w\sum_i(y_i-w^Tx_i)^2
\]

加：

\[
w_j\ge0,\quad \sum_jw_j=1.
\]

### 方案 C｜不确定权重时直接给区间

\[
w\in\mathcal W,
\]

然后检查排名稳定性：

\[
P(rank_i\le k).
\]

主观评价题中，**排名稳定性比精确到两位小数更有价值。**

# 5. Q3：“有法无式”真正应该问什么？

题意其实有张力：

- 有“法” → 应存在共性；
- 无“式” → 又不能所有园林都一样。

候选把三层特征统一：

\[
F=[F_{micro},F_{meso},F_{macro}]
\]

其中约：

- 微观 148 维；
- 中观 16 维；
- 宏观 15 维；
- 总计 179 维。

然后同时分析：

- pairwise similarity；
- 共性低 CV 特征；
- 个性化指数；
- 聚类类型；
- 新园林泛化。

这比只做一张 cosine similarity heatmap 要完整得多。

## 5.1 但是高维余弦相似度出现“饱和”

候选报告：

\[
\bar S\approx0.986,
\]

45 对园林全部：

\[
S>0.85.
\]

这听起来像“江南园林非常相似”，但也可能是：

> **高维标准化特征 + 大量相关指标，使余弦距离失去区分度。**

因此相似度模型必须做 discriminability audit：

1. within-class / between-class 分布；
2. 置乱特征后的 null similarity；
3. PCA 后低维距离；
4. Mahalanobis / correlation distance；
5. bootstrap rank stability。

如果所有对象都是 0.98，相似度矩阵就没有决策信息。

## 5.2 共性不要靠“相似度很高”证明

更稳的办法是找低变异特征：

\[
CV_j=\frac{\sigma_j}{|\mu_j|}.
\]

低 CV 且跨园稳定的指标，更像“法”；
高 CV/高区分度特征，更像“无式”。

于是可以直接构造：

\[
F=F_{law}\oplus F_{style}.
\]

这比一句“十园相似度均高，所以有法无式”强得多。

# 6. 泛化验证：参数要冻结

候选把模型应用到新园林，并强调：

- 采样间距一致；
- 栅格尺寸一致；
- 视线参数一致；
- NSGA-II 代数一致；
- 不针对新园重新调参。

这点非常值得照搬。

真正的泛化测试必须：

```text
train / calibration objects
       ↓ 冻结参数
new object
       ↓
直接运行
```

而不是：

```text
新园结果不好
→ 调一下阈值
→ 再宣布泛化成功
```

# 7. 评审老师会怎么评价这篇？

## 强项

1. 把极主观的题拆成空间机制和序列机制；
2. Q1 的“时间意外性 + 空间差异”很有原创表达；
3. fine graph → macro graph 有算法工程意识；
4. Q1 用 Pareto 而不是强行单权重；
5. Q2 借景观生态学/空间句法成熟指标，不全靠自造公式；
6. Q3 同时谈共性、个性、聚类和泛化，回应“有法无式”。

## 高风险

1. 多处权重仍是主观设定；
2. 开合阈值的样本覆盖不够；
3. 高维 cosine similarity 严重饱和；
4. Q1 缺专家/官方路线外部基准；
5. 大量文化升华文字不能替代模型证据。

# 8. 我们赛场真正应该带走的五条

> **第一条：主观词先拆机制。**  
> “趣味性”不要直接评分，先拆成变化、意外性、重复、节奏。

> **第二条：序列体验必须沿路径计算。**  
> 静态元素比例回答不了“移步异景”。

> **第三条：评价指标要做防作弊设计。**  
> 检查是否能通过切短路径、堆元素、重复特征等方式人为刷高。

> **第四条：权重不是最后随手填的数。**  
> 用 Pareto、组合赋权、回归校准或敏感性分析。

> **第五条：没有标签也能验证。**  
> 用机制一致性 + baseline + 参数敏感性 + 新对象冻结参数泛化。
