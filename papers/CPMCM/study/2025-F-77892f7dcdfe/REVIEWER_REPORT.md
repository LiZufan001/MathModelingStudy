# 1. 指导老师视角：这篇最该学什么

## 1.1 优点不是“指标多”，而是软概念被拆成机制

Q1 不是直接给“趣味性”打分，而是：

```text
路径骨架
→ 可视景观状态
→ 相邻状态变化
→ 状态转移意外性
→ 路径级趣味
```

Q2 不是直接 AHP，而是：

```text
元素分布
+ 开阔/围合状态
+ 沿游线开合变化
→ 幻境感
```

这种“机制先于权重”的顺序应直接迁移到我们比赛。

## 1.2 微观计算、宏观优化分层很成熟

细密采样负责计算视景，关键节点图负责路径优化。这种 coarse-to-fine 结构比把所有点直接喂给 NSGA-II 更合理。

## 1.3 没有标签也主动做机制自检

候选用“转折密度应与异景程度正相关”做统计验证。即使没有专家评分，也没有放弃验证。

## 1.4 新对象泛化时参数冻结

新园林全流程沿用原参数，是非常值得训练的科研纪律。

# 2. 评审老师视角：A级问题

## A1. 权重定义没有和前面复杂指标体系同等严谨

例如 Q2 最终对元素分布/开合变化接近 50/50 合成；Q3 多层融合也存在主观比例。

评审追问：

> 你前面用了几十页定义指标，为什么最后两个一级指标各 50%？

补救：

- AHP + CRITIC/熵权组合；
- 权重区间敏感性；
- 排名稳定性；
- Pareto 替代提前加权。

## A2. 高维相似度严重饱和

候选综合相似度均值约 0.986，45 对全部 >0.85。

评审会问：

> 如果所有园林都接近 1，你这个相似度还能区分什么？

必须补：

- null permutation baseline；
- 去共线；
- PCA / Mahalanobis；
- bootstrap similarity CI；
- within/between cluster distribution。

## A3. 开合判定证据覆盖范围不够

Depthmap 等完整空间句法分析只在少数园林展开，却用于支撑十园的统一阈值。

这属于：

\[
Evidence\ scope < Conclusion\ scope.
\]

应补全十园，或明确阈值是 benchmark-derived heuristic。

## A4. Q1 缺真正独立的人类/官方路线基准

相关性验证能证明机制方向合理，但不能证明：

> 游客真的更喜欢 Pareto 解。

最小补强：

- 官方推荐路线；
- 园林导览路线；
- 小样本 pairwise survey；
- 游客停留/照片热点数据。

# 3. B级问题

## B1. 阈值、视线参数和采样尺度要区分来源

160 cm、3°射线、栅格尺寸等参数需标：

- 人体/几何规范；
- 计算折中；
- 数据驱动标定；
- 敏感性。

否则会被问“为什么不是 170 cm / 5°？”

## B2. Voronoi 路网并不天然等于真实可行路径

需检查：

- 走廊宽度；
- 半开放建筑通行性；
- 台阶/门洞；
- 水体和假山缓冲区；
- 出入口连通。

候选存在少量人工几何修补，应该公开为 preprocessing rule，而不是隐藏。

## B3. 指标共线问题

AI 与 IIC 等指标高相关，重复纳入综合评分相当于重复投票。

必须：

```text
correlation matrix
→ cluster/VIF
→ retain representatives
```

## B4. “寄畅园100分”不是其每项指标都应该最优

benchmark 100 分是总体标尺，不应该强迫：

\[
每个单指标都让寄畅园=100且越接近越好.
\]

应先定义每个指标与幻境感的方向关系，再校准总分。

# 4. C级写作问题

- 大量文化升华如果没有回到模型变量，容易显得注水；
- 高维特征清单过长时，应在正文只放语义组和 top features；
- 图表应沿“输入→机制→结果→验证”排序，而不是把十园同类型热图连续堆几十张；
- 摘要应报关键结果和验证，不要只列技术名。
