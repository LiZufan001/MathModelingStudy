## 4. 为什么还参考其他 F 题候选

用户此阶段的目标不是“收藏论文”，而是形成赛场可复用技巧。因此 `PRACTICAL_MODELING_TOOLKIT.md` 会横向吸收其余候选中已被逐篇人工复核、且可迁移性很强的设计：

- 同一对象分离“通行作用半径”和“视域遮挡半径”；
- JS 距离 + 长度归一 + 温和权重，防止异景指标被短段“刷分”；
- 高斯型“适量度”表达“过少、过多都不好”；
- 基准园分位数标定阈值 + 网格扫描 + 平台区取中值 + 敏感性分析；
- AHP + CRITIC/熵权等主客观组合赋权；
- 与官方推荐路线/专家评分/外园验证做独立验收。

这些技巧只作为**跨论文方法归纳**，不会反向写成 182 页主候选自己的方法。
