## 使用原则

1. **先复现作者问题链，再抽象可迁移范式。** 不把某个题目的专用技巧生搬硬套到其他题。
2. **区分“论文写了什么”和“我们的二次判断”。** 对论文中的符号冲突、公式/代码差异、验证不足单独标注。
3. **优先学习闭环，而不是算法名。** 真正值得迁移的是“状态/约束 → 模型 → 算法 → 仿真 → 评分 → 验证”的完整链条。
4. **正式比赛以题目评分规则为准。** 历史论文只能提供建模思路，不能代替对当届题意、约束和数据的重新核验。
