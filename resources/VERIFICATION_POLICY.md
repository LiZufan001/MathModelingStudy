# 资料核验规则

## 目的

避免再次把 **CUMCM（本科生）** 资料误当成 **CPMCM（研究生）** 资料，也避免把网络上标题写着“国一”的未知论文直接当作国一论文。

## 来源等级

### V1 — 官方作品/官方获奖数据

- 研创网官方优秀作品库
- 竞赛组委会官方获奖名单
- 官方赛事页面直接发布的赛题与附件

最高优先级。

### V2 — 赛事官方公告

- 中国研究生创新实践系列大赛（研创网）的开赛、赛题、获奖公告

可用于确认赛事、年份、题号、官方附件入口等。

### V3 — 高校/研究机构官方报道

必须至少明确对应：

- CPMCM / 中国研究生数学建模竞赛
- 年份或届次
- 题号/作品名（能够对应赛题）
- 全国一等奖（或更高层级的明确奖项）
- 队伍或作者信息

满足这些条件时，可作为“已核验国一作品”的证据。

### V4 — 博客、论坛、网盘、社区仓库

只用于发现候选资料和线索。**不能仅凭 V4 把论文标成国一。**

## 入库规则

1. 赛事类型先核对：CPMCM ≠ CUMCM。
2. 题名至少经过 V1/V2，或 V2 + V3 交叉核验。
3. 国一身份至少需要 V1，或足够明确的 V3 官方报道。
4. 论文标题与“赛题标题”分开记录；没有拿到论文原文时，不能擅自把赛题名当成论文正式标题。
5. 对作者、学校、奖级、题号有冲突时，标记 `待核验`，不自行猜测。
6. PDF/附件只有在官方公开、授权允许或来源明确可再分发时才直接存仓；否则保存验证链接和元数据。
7. 每次新增资料应同时更新 `INDEX.md` 或对应年份索引。

## 验收标准

任何标注为“已核验一等奖”的条目，都应让后来者只靠仓库中的验证 URL 就能追溯到官方/高校官方证据。
