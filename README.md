# MathModelingStudy

个人数学建模学习仓库，用于长期整理历年题目、优秀论文、论文拆解、模型与算法知识，以及数模论文写作经验。

## 核心目标

这个仓库不是单纯的 PDF 收藏夹，而是逐步形成一套可复用的个人数模知识体系：

**题目 → 独立思考 → 优秀论文 → 方法拆解 → 多论文比较 → 抽象知识 → 写作积累**

## 目录

- `problems/`：按比赛 / 年份 / 题号组织原题、论文和分析。
- `knowledge/`：跨题目沉淀的模型、算法、数据处理、评价、优化和写作知识。
- `templates/`：题目分析、论文分析、多论文对比、模型笔记模板。
- `resources/`：书籍、教程和外部参考资料索引。
- `inbox/`：暂未分类的新资料。
- `INDEX.md`：仓库总索引，也是手机 Obsidian 推荐入口。
- `AGENTS.md`：供 ChatGPT / Codex 等 AI 后续整理仓库时遵循的规则。

## 推荐学习流程

1. 先读原题并记录自己的初步思路。
2. 阅读 2～5 篇有代表性的优秀论文。
3. 对每篇论文拆解“做了什么、为什么这么做、各问如何衔接”。
4. 用 `comparison.md` 对比不同论文的路线和取舍。
5. 把可迁移的方法沉淀到 `knowledge/`。
6. 把优秀写法沉淀到 `knowledge/writing/`。

## 手机离线阅读

整个仓库可以下载到手机本地，并将仓库目录直接作为 Obsidian Vault 打开。Markdown 笔记、内部链接和本地 PDF 都可以离线使用。
