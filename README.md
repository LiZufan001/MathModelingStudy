# MathModelingStudy — CPMCM 2026

本仓库自 **2026-09-03** 起重置为中国研究生数学建模竞赛训练库。

目标赛事：**中国研究生数学建模竞赛（China Post-Graduate Mathematical Contest in Modeling, CPMCM）**，当前以 2026 年参赛准备为主线。

> 旧仓库中误收集的全国大学生数学建模竞赛（CUMCM，本科生竞赛）题目、论文、分析、脚本与导入工作流，已从当前 `main` 文件树移除。Git 历史仍保留，便于追溯，但不再作为训练资料使用。

## 当前内容

- `problems/CPMCM/`：2020–2025 六届 CPMCM 赛题目录、题名与权威来源。
- `papers/CPMCM/`：按年份整理的、**已核验一等奖身份**的优秀作品/团队索引。
- `resources/OFFICIAL_SOURCES.md`：官方入口与年度来源清单。
- `resources/VERIFICATION_POLICY.md`：国一论文与赛题来源的核验规则。
- `INDEX.md`：全仓总索引。

## 收录原则

1. 只把 **CPMCM / 中国研究生数学建模竞赛** 作为本仓库主赛道，不再混入 CUMCM。
2. 赛题优先使用研创网（中国研究生创新实践系列大赛）官方公告；标题无法直接从官方页面抓取时，用高校官方新闻交叉核验。
3. “国一论文”必须能由官方获奖信息或高校官方新闻证明为**全国一等奖**，不能仅凭网盘、博客或社区标题认定。
4. 论文全文只在官方公开下载或明确允许再分发时入库；否则保存权威来源、作品信息与验证链，避免把来源不明 PDF 当作国一。
