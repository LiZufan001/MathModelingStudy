## 仓库材料结构

2020–2024 年赛题资料已按统一结构整理：

- `A/` ～ `F/`：对应题目的题面与附件
- `common/`：无法归属于单一题目的公共说明、通知或表格
- `README.md`：年份、题名、官方来源及核验记录

内层 ZIP、RAR、7z 分卷等保持原始资料形态，不重复解包。
