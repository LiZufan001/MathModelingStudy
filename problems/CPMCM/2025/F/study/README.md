## 字幕可靠性说明

字幕是 **ASR 原始识别结果**，不是人工逐字校对稿。已确认存在一些同音词误识别，例如：

- `假山` → `甲酸 / 甲山`
- `景观` → `警官`
- `阈值` → `域值 / 预值`
- `线性加权和法` → `线性加权合法`
- `寄畅园` → `气场元 / 机场员`

此外，上半段约 12–20 分钟、下半段约 37 分钟以后存在较长的重复语气词/“零一和”等 ASR 幻觉片段。分析文档不把这些异常片段当作可靠证据。

因此，**字幕用于定位老师讲解时间与恢复语义主线；专业术语与公式以课件画面、题面和上下文交叉判断为准。**
