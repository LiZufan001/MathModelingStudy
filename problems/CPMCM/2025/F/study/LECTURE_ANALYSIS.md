## 0. 一句话结论

这道题最值得学习的不是 KMeans、Dijkstra、余弦相似度这些算法，而是：

> **把“移步异景、趣味性、幻境感、有法无式”这类主观审美概念，逐层拆成可观察变量、可计算指标、空间/序列模型，再把数值结果解释回审美语义。**

整题可以压成一条递进链：

\[
\boxed{
\text{游线体验}
\rightarrow
\text{空间审美}
\rightarrow
\text{园林共性}
\rightarrow
\text{跨园林泛化}
}
\]

# 1. 整题结构：三问不是孤立的

老师在后半段直接概括：

1. 第一问：**趣味性**
2. 第二问：**幻境感**
3. 第三问：**相似度**

这三问不是三个独立的算法题，而是逐级复用：

- 第一问建立路径与景观变化特征；
- 第二问补充景观元素空间组织和开合变化；
- 第三问把前两问形成的特征重新组织成“园林表征”，比较十座园林的共同美学规律；
- 泛化部分再检验这套表征是否能用于新的园林。

这给后续比赛一个重要启示：

> **当题目连续多问时，优先寻找“前一问产出的中间变量如何成为后一问输入”，不要每问重新造一套互不相干的指标。**

# 2. 第一问：如何把“移步异景”变成数学对象

## 2.1 关键抽象：相邻观察状态的差异

课程开头的核心思路是：

沿游览路径离散出一系列感知位置，设第 \(i\) 个位置的景观状态为向量

\[
\mathbf C_i=(c_{i1},c_{i2},\dots,c_{im})
\]

那么“从这里走到下一处是否出现异景”，可用相邻状态差异衡量：

\[
\Delta_i
=
\left\|
\mathbf C_{i+1}-\mathbf C_i
\right\|
\]

最自然是二范数：

\[
\Delta_i
=
\sqrt{
\sum_{k=1}^{m}
(c_{i+1,k}-c_{i,k})^2
}
\]

也可以加入景观类别权重：

\[
\Delta_i
=
\sqrt{
\sum_{k=1}^{m}
w_k(c_{i+1,k}-c_{i,k})^2
}
\]

课程强调的重点不是“必须二范数”或“必须加权”，而是：

> **用相邻景观向量的差异，把文学性的“步移景异”变成状态变化量。**

这是一个高度可迁移的套路：

\[
\text{抽象体验}
\rightarrow
\text{状态向量}
\rightarrow
\text{相邻状态距离}
\]

可迁移到城市街景变化、驾驶疲劳环境变化、旅游体验、用户行为序列等问题。

---

## 2.2 “异景”还需要阈值

仅有 \(\Delta_i\) 还不能回答“算不算一次异景”。

因此课程展示的做法会进一步设定临界值：

\[
I_i=
\begin{cases}
1,& \Delta_i>\tau\\
0,& \Delta_i\le \tau
\end{cases}
\]

于是：

\[
N_{\text{change}}=\sum_i I_i
\]

可以理解为一路出现显著景观变化的次数，再除以路径长度可以形成单位距离变化频率。

这里值得吸收的是：

> **很多“有/无”“显著/不显著”“开放/封闭”问题，本质上都需要经历“连续量 → 阈值 → 状态”的建模步骤。**

同时，阈值 \(\tau\) 的来源必须解释。好的来源优先级是：

1. 题面/行业标准；
2. 文献或经验研究；
3. 数据分布、自适应分位数、聚类阈值；
4. 最后才是人为设定，并做敏感性分析。

# 3. 第一问的“趣味性”：不要只算一个景观差异

课程展示了一个很典型的综合：

- 转折点密度；
- 交叉点密度；
- 异景程度/异景频率；
- 还可以加入路径延展性、长度等。

规范化写法可以是：

\[
F(P)=
\alpha_1 D_{\text{turn}}
+\alpha_2 D_{\text{cross}}
+\alpha_3 D_{\text{scene}}
+\cdots
\]

其中 \(P\) 是一条游线。

这里我提炼成：

\[
\boxed{
\text{游览趣味性}
=
\text{道路几何变化}
+
\text{视觉景观变化}
}
\]

如果只用道路弯折，很容易得到“越绕越有趣”的荒谬结论；  
如果只用景观元素，又忽略了路径结构对游览节奏的影响。

### 对综合评价法的学习点

老师专门提醒，指标不是越多越好。指标太多以后：

- 每个权重变小；
- 核心概念被稀释；
- 容易出现“什么都考虑了，但什么都没表达清楚”。

这对数模很重要：

> **先有机制，再选指标；不要先堆指标，再用熵权/TOPSIS替自己决定题意。**

# 4. 第一问后半：本质是多目标路径优化

题意同时要求：

\[
\max F(P)
\]

和

\[
\min R(P)
\]

其中 \(R(P)\) 是重复路径比例。

老师明确把它归为典型多目标规划，并接受两类建模方式。

## 4.1 方式 A：保留两个目标

\[
\max F(P),\qquad \min R(P)
\]

可以进一步用：

- Pareto 前沿；
- NSGA-II 等多目标启发式；
- \(\epsilon\)-constraint；
- 线性加权和。

如果使用线性加权：

\[
\max
\left[
\lambda \tilde F(P)
-
(1-\lambda)\tilde R(P)
\right]
\]

必须先做量纲/尺度统一。

---

## 4.2 方式 B：把重复率转成约束

课程也认可：

\[
\max F(P)
\]

subject to

\[
R(P)\le r_0
\]

这会把问题变成单目标优化。

这个改写十分有用，因为实际比赛中经常遇到：

> “在保证 A 的前提下尽量优化 B”

这类语句常常比硬凑一个权重更自然地写成约束。

老师还提醒，重复率不宜机械设为 0。因为园林图结构中某些必经通道可能需要重复经过，强制零重复会导致重要区域不可达。

# 5. 求解算法：不要把“问题建模”和“求解器”混为一谈

课程提到图论路径算法，并拿 Dijkstra 一类算法举例。但老师同时指出一个很重要的工程判断：

> 园林道路图规模很小时，**直接枚举可行路径并逐条计算目标值，可能比上一个复杂启发式更准确、更简单。**

这个观点非常值得记。

比赛里常见错误：

- 规模只有几十个节点，却先上遗传算法；
- 结果是近似解，还要调一堆超参数；
- 反而忽略了完整枚举或动态规划可能可行。

正确顺序：

1. 先估算状态空间；
2. 小规模优先精确算法；
3. 确实组合爆炸再上近似算法；
4. 即使用启发式，也拿小实例做精确解对照。

\[
\boxed{
\text{算法复杂度要与问题规模匹配}
}
\]

# 6. 第一问完整证据链

一个高质量第一问，不应只有一个最优目标值。

至少要呈现：

1. 路径图；
2. 关键节点/转折点/交叉点；
3. 沿途异景程度或异景事件；
4. 趣味性总分；
5. 路径重复率；
6. 最优游线在平面图中的可视化。

老师反复强调“要在正文里给评委看到结果”。

学习点：

> **模型公式不是最终证据，可视化和具体输出才是。**

# 7. 第二问：整题最值得学习的“软概念硬建模”

第二问围绕“小中见大 / 幻境感”，课程实际拆成两个机制：

\[
\boxed{
\text{幻境感}
=
\text{景观元素空间组织}
+
\text{游览过程中的开合变化}
}
\]

前者是静态空间结构，后者是动态体验。

这个拆分非常漂亮，因为“幻境感”本身太虚，直接做 TOPSIS 没有机制基础。

# 8. 景观元素分布：把平面图变成结构化特征

课程讨论的元素包括：

- 建筑；
- 水体；
- 植物；
- 山石/假山；

可以提取的特征包括：

- 数量；
- 面积及面积占比；
- 质心位置；
- 离散度；
- 聚集度；
- 形状复杂度；
- 多样性；
- 各类元素的空间组合。

这一步本质是：

\[
\text{园林平面图}
\rightarrow
\text{几何对象集合}
\rightarrow
\text{数值特征向量}
\]

# 9. 不规则区域面积：必须解释“怎么算出来”

课程特别强调，有些量虽然公式简单，但数据处理步骤必须写。

例如建筑、水体边界是不规则的，可以先转成近似多边形，再用鞋带公式：

若多边形顶点为
\((x_1,y_1),\dots,(x_n,y_n)\)，则

\[
A=
\frac12
\left|
\sum_{i=1}^{n}
(x_i y_{i+1}-x_{i+1}y_i)
\right|
\]

其中 \((x_{n+1},y_{n+1})=(x_1,y_1)\)。

为什么这段很重要？

因为论文不能只写：

> “计算各水体面积。”

而必须回答：

> **不规则边界是如何从数据中变成面积的？**

这就是模型的可复现性。

# 10. 形状复杂度：寻找“简单基准”

老师介绍了一类“与同面积圆形比较”的形状指数。

核心思想：

- 圆形是平面中相对规则、紧致的形状；
- 在面积相同时，边界越曲折，周长通常越大；
- 因此可用周长相对同面积圆周长的偏离刻画复杂度。

例如可以规范化为：

\[
C_{\text{shape}}
=
\frac{P}{2\sqrt{\pi A}}
\]

同面积圆形时为 1；越大表示边界越复杂。

真正值得学习的不是这个公式本身，而是：

\[
\boxed{
\text{难定义的概念}
\rightarrow
\text{选一个明确基准}
\rightarrow
\text{衡量偏离程度}
}
\]

第一问“异景”也是同一个方法：用状态距离衡量偏离。

# 11. 数字算出来之后必须回答“所以呢？”

这是老师整堂课反复强调的最大写作问题之一。

比如你算出：

- 建筑数量 = 225；
- 离散度 = 16；
- 水体面积比 = 0.32；
- 复杂度 = 1.45；

论文不能停在这里。

必须继续回答：

> 这些数值在园林审美上意味着什么？

例如：

- 分布均衡还是集中；
- 空间层次是否丰富；
- 建筑与自然景观是协调还是压迫；
- 是否形成某种典型空间场景。

老师展示的优秀论文即使某些阈值依据不够强，至少会把“指标值”解释成“审美含义”，形成闭环。

## 11.1 但不要把“自圆其说”理解成随便编

老师的口语表达有时会说“自圆其说就能给分”，但作为我们自己的比赛方法，应该提高一档：

优先给每个阈值和解释建立证据来源：

1. 园林学/景观学文献；
2. 国标或行业尺度；
3. 数据驱动分组；
4. 敏感性分析；
5. 最后才是经验阈值。

否则容易形成“结果是 26，所以我定义 20–30 为最好”的后验包装。

# 12. 聚类：从元素特征得到“典型场景”

课程展示了把局部区域按景观特征聚类，然后解释为：

- 植物主导场景；
- 水景主导场景；
- 山石主导场景；
- 其他混合场景。

数学上可以令每个空间单元有特征：

\[
\mathbf x_j=
[
p_{\text{plant}},
p_{\text{water}},
p_{\text{rock}},
p_{\text{building}},
\dots
]
\]

用 KMeans 等聚类：

\[
\min
\sum_{k=1}^{K}
\sum_{j\in C_k}
\|
\mathbf x_j-\boldsymbol\mu_k
\|^2
\]

但是课程重点不是“KMeans”这个名字，而是：

> **必须展示聚类中心、各类数量、元素占比和空间分布，才能证明真的做了聚类。**

非常重要的比赛原则：

\[
\boxed{
\text{算法名称不是证据，算法输出才是证据}
}
\]

# 13. 第二问最精彩的部分：把“开合”变成状态序列

课程把这个问题拆成两个评分核心：

1. 什么样的空间叫“开”，什么叫“合”？
2. 沿游线怎样量化“开—合—开—合”的变化？

设路径采样点：

\[
p_1,p_2,\ldots,p_n
\]

每个点定义空间状态：

\[
s_i\in
\{\text{开放},\text{过渡},\text{封闭}\}
\]

然后分析序列 \(s_1,s_2,\ldots,s_n\)。

这一步极具迁移价值。

# 14. 开合模型 A：视域通透率

课程明显更欣赏的一类方法是模拟游客在当前位置“环顾四周”。

在每个采样点：

1. 建立半径 \(R\) 的感知区；
2. 向 \(0\sim 2\pi\) 方向发射视线；
3. 判断视线是否被建筑、密集植物、山石等遮挡；
4. 统计未遮挡方向比例。

离散化后可以写成：

\[
T_i
=
\frac1M
\sum_{m=1}^{M}
I_{im}
\]

其中：

\[
I_{im}=
\begin{cases}
1,&\text{第 }m\text{ 个方向未被遮挡}\\
0,&\text{被遮挡}
\end{cases}
\]

连续形式可写成：

\[
T_i=
\frac{1}{2\pi}
\int_{0}^{2\pi}
I_i(\theta)\,d\theta
\]

\(T_i\) 越大，说明视域越通透。

这实际上是在做一个简化的 **visibility / viewshed** 模型，而不是机械数周围有几个物体。

---

# 15. 开合模型 B：元素相对密度综合指数

另一篇获奖方案更简单：

在采样点附近统计水体、山石、植物、建筑等元素相对密度。

直觉关系：

- 水体越多 → 更开；
- 建筑、植物、山石遮挡越多 → 更合。

因此可定义：

\[
K_i
=
w_w d_{w,i}
-
w_b d_{b,i}
-
w_p d_{p,i}
-
w_r d_{r,i}
\]

再归一化到 \([0,1]\)。

课程认为这种方案没有视域法精细，但依然是有效模型。

学习点：

> **建模不一定追求最复杂；只要机制方向正确、定义清楚、结果可验证，简单模型也能成立。**

# 16. 连续指标 → 三状态

课程展示的一个典型划分类似：

\[
K_i>0.7
\Rightarrow
\text{开放}
\]

\[
K_i<0.3
\Rightarrow
\text{封闭}
\]

中间为过渡。

这里不应该死记 0.7 / 0.3，真正要记的是建模结构：

\[
\boxed{
\text{连续指标}
\rightarrow
\text{阈值}
\rightarrow
\text{离散状态}
}
\]

后续即可进行状态转移分析。

# 17. 幻境感来自“状态变化”，不是“开放程度高”

如果一路都是开放：

\[
OOOOOOOO
\]

或者一路都是封闭：

\[
CCCCCCCC
\]

空间体验都比较单一。

真正的层次来自：

\[
C\rightarrow O\rightarrow C\rightarrow O
\]

即收、放、收、放。

可以定义：

\[
\delta_i=
\begin{cases}
1,& s_i\neq s_{i+1}\text{ 且为开/合显著转换}\\
0,&\text{其他}
\end{cases}
\]

总变化次数：

\[
N_{\text{oc}}
=
\sum_{i=1}^{n-1}\delta_i
\]

单位长度变化频率：

\[
f_{\text{oc}}
=
\frac{N_{\text{oc}}}{L}
\]

这个思想特别值得迁移：

> **很多主观体验由“变化”而不是“水平”决定。**

例如：

- 节奏感：强弱交替；
- 城市空间层次：宽窄变化；
- 驾驶刺激：环境状态变化；
- 金融波动：状态切换；
- 生理信号：节律变化。

# 18. 第二问最终要形成“幻境感评分体系”

课程强调，不能只把某一个园林算完。

需要把：

- 元素空间组织；
- 开合变化；

融合成综合幻境感，并对多个园林排序。

规范化：

\[
H_j
=
\beta_1 Z_{j,\text{element}}
+
\beta_2 Z_{j,\text{open-close}}
\]

其中 \(H_j\) 是第 \(j\) 座园林幻境感得分。

## 18.1 已知代表性园林可作为 sanity check

课程把寄畅园作为重要参考基准，并提醒：

如果你的模型把一个题面/历史认知中被视为顶级代表的园林明显排到后面，应先检查模型，而不是马上宣布“我发现传统认知错了”。

这是模型验证思维：

\[
\boxed{
\text{已知可信先验}
\rightarrow
\text{检查模型输出是否合理}
}
\]

注意：不是强行调参迎合答案，而是触发诊断：

- 指标是否选错；
- 权重是否倒置；
- 归一化是否有问题；
- 某些变量是否重复计权。

# 19. 第三问：寻找“有法无式”的共同规律

第三问的难点是：

中国古典园林表面形式差异很大，不像轴线对称的园林那样可以用一个显眼几何特征概括。

共同元素当然有：

- 水；
- 山石；
- 植物；
- 建筑；

但“都有水和树”不足以回答美学共性。

真正的问题是：

\[
\boxed{
\text{不同外观下是否存在稳定的高层结构规律？}
}
\]

# 20. 两类相似度：不要混淆语义

课程提到两种典型方法。

## 20.1 余弦相似度

用于比较同维特征向量的方向一致性：

\[
S_{\cos}(\mathbf x,\mathbf y)
=
\frac{\mathbf x^\top\mathbf y}
{\|\mathbf x\|_2\|\mathbf y\|_2}
\]

更适合“特征比例/结构模式是否一致”。

## 20.2 Jaccard 相似度

集合形式：

\[
S_J(A,B)
=
\frac{|A\cap B|}
{|A\cup B|}
\]

适合比较共有元素/区域重叠。

如果是几何区域，\(|\cdot|\) 可以替换为面积。

学习点：

> **不要只因为“都是相似度”就混用。先问：我要比较的是向量方向、集合共有程度、空间重叠，还是绝对距离？**

---

# 21. 第三问最聪明的地方：整体不相似，不代表局部规律不存在

课程展示了一种非常有洞察力的处理。

如果把几十个特征全部塞进总向量，可能得到：

\[
S_{\text{all}}\approx0.3\sim0.5
\]

看起来园林“并不相似”。

但拆开审美维度以后：

\[
S_{\text{path}}>0.9
\]

或：

\[
S_{\text{open-close}}>0.7
\]

或：

\[
S_{\text{element-ratio}}>0.7
\]

就能发现：

> 整体外形不同，但在游线曲折、空间开合节奏、元素组合比例等某些高层机制上高度一致。

这比给一个“综合相似度 0.47”然后强行解释高明得多。

可迁移原则：

\[
\boxed{
\text{整体指标失败}
\not\Rightarrow
\text{模型失败}
}
\]

先检查是不是：

- 不同维度互相抵消；
- 有效信号被无关变量稀释；
- 真正规律存在于子空间。

这和机器学习中的 feature subspace / representation analysis 是同一种思想。

---

# 22. 第三问的泛化测试：真正难的是“新数据从哪里来”

这是整堂课最值得记住的工程问题之一。

前十座园林的数据是已经整理好的结构化数据。

但把模型应用到新园林时：

> 新园林没有同样格式的矢量坐标和测量数据。

如果论文突然写：

> “将新园林数据代入模型……”

老师会追问：

> **数据是哪来的？**

课程非常明确地批评了“凭空出现数据”的写法。

---

# 23. 正确泛化流程：先做数据重建

优秀方案会承认：

> 附件没有新园林的矢量坐标。

于是建立：

\[
\boxed{
\text{公开平面图}
\rightarrow
\text{图像处理}
\rightarrow
\text{元素分割}
\rightarrow
\text{人工校正}
\rightarrow
\text{坐标化}
\rightarrow
\text{结构化表格}
\rightarrow
\text{原模型}
}
\]

课程提到的处理包括：

- 彩色图转灰度；
- 水体边界识别；
- 道路边缘识别；
- 建筑轮廓识别；
- 景观元素分类；
- 人工校正；
- 坐标化；
- 输出成与原附件相同格式的数据表。

这是一个非常核心的建模认知：

\[
\boxed{
\text{数据工程是模型的一部分}
}
\]

真实比赛中，输入数据不完整时：

> “如何获得模型所需要的输入”本身就是评分点。

# 24. 老师整堂课反复强调的评分逻辑

## 24.1 抽象词必须被定义

不能写：

> “我们认为这里更有趣。”

要写：

\[
\text{趣味性}=f(\text{转折、交叉、异景……})
\]

---

## 24.2 算法名字不是结果

不能写：

> “采用 KMeans 得到典型场景。”

要展示：

- 聚类中心；
- 样本数；
- 各类特征；
- 空间位置；
- 场景解释。

---

## 24.3 数字不是分析

不能只写：

> 离散度 = 16。

还要解释：

> 16 对空间组织意味着什么？

---

## 24.4 所有题目要求的对象都要实际计算

题目让十个园林排序，就不要只展示一个样例。

---

## 24.5 可视化是证据

路径题、空间题、聚类题尤其如此。

---

## 24.6 数据不能凭空出现

模型泛化到新对象前，必须交代输入数据获取过程。

---

## 24.7 结果必须做合理性检查

模型输出严重违背可信常识或题面基准时，先查模型。

---

# 25. 我对老师讲解的批判性吸收

课程很有价值，但有几处不能机械照搬。

## 25.1 “能自圆其说”不等于“可以后验编阈值”

老师从评审现实出发，指出有解释比没解释好。

我们真正比赛时应该进一步做到：

- 阈值有依据；
- 或用数据自适应确定；
- 或做敏感性分析。

不要：

\[
\text{先看到结果}
\rightarrow
\text{再发明刚好让结果好看的区间}
\]

---

## 25.2 线性加权不是默认答案

当两个目标真正存在冲突时，线性加权只是在特定条件下选择 Pareto 解的一种方法。

如果有时间，优先：

- 画 Pareto 前沿；
- 分析权重敏感性；
- 或把业务上明确的次目标转成约束。

---

## 25.3 阈值 0.3/0.7 不能死记

这是特定论文的选择，不是园林学定律。

正确做法：

- 文献；
- 训练样本；
- 分位数；
- 聚类；
- ROC/分类验证；
- 敏感性分析。

---

## 25.4 “寄畅园必须第一”应作为验证信号，而非强制标签

如果题面给出了很强的先验，应当用来 sanity check。

但不要直接调权重直到它第一。

更严谨：

1. 先盲算；
2. 比较与先验；
3. 若冲突，分析原因；
4. 只有发现机制错误时才修改模型。

# 27. 对 2026 华为杯最有价值的赛场工作流

以后遇到主观评价/空间体验/综合机制题，建议先画下面这张表。

| 步骤 | 必答问题 |
|---|---|
| 1. 抽象概念 | 题目真正要量化的词是什么？ |
| 2. 机制拆解 | 人为什么会产生这种体验？ |
| 3. 可观察量 | 给定数据中哪些变量能代理这些机制？ |
| 4. 中间表示 | 图、向量、序列、网格还是集合？ |
| 5. 指标定义 | 单位、方向、范围是否明确？ |
| 6. 参数来源 | 权重、阈值、尺度为什么这样取？ |
| 7. 求解 | 是否真的需要复杂算法？ |
| 8. 输出 | 题目要求的对象是否全部给出？ |
| 9. 解释 | 数值如何回到现实语义？ |
| 10. 验证 | 有无先验、样本、敏感性或对照？ |
| 11. 泛化 | 新对象的数据如何获得？ |

比赛时只要这 11 项没有断链，论文通常就不会“公式很多但逻辑空”。

# 30. 最终学习成果

如果只保留五句话，我会留下：

1. **先解释“为什么”，再决定“怎么算”。**
2. **主观概念要通过代理变量和机制变成可计算对象。**
3. **动态体验往往存在于状态变化，而不是某个静态值。**
4. **算法输出、数据来源和现实解释共同构成证据链。**
5. **泛化不是把新名字代入旧公式，而是保证新对象能获得同构输入。**

这五条比记住某一套 F 题具体公式更值得带到下一场比赛。
