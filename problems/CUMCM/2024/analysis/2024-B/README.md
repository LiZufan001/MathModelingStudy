## 这道题真正的结构

四问不是四个互相独立的问题，而是一条完整链条：

```text
Q1：次品率未知，怎样用尽量少的样本做接收 / 拒收判断？
 ↓
Q2：假设次品率已知，小型生产流程下怎样决定“检不检、拆不拆”？
 ↓
Q3：把两零件一路扩展到多工序、多零件、半成品和返工循环。
 ↓
Q4：承认 Q2/Q3 使用的次品率其实是 Q1 抽样估计值，再把参数不确定性传回决策。
```

所以更值得记住的是：

> **统计推断 → 随机系统评价 → 组合策略优化 → 不确定性传播。**

## 先记住五句话

1. **抽样题首先要区分“参数估计”和“决策规则”。** 题目要的是接收 / 拒收，不只是算一个样本次品率。
2. **返工、拆解、退换货会形成循环。** 一旦有循环，简单的一棵静态决策树往往不够，应该考虑状态转移、更新过程或离散事件仿真。
3. **策略空间小就先枚举。** 16 个二进制变量只有 `2^16 = 65536` 个组合，这是非常重要的基准事实。
4. **蒙特卡洛给的是带噪声的目标函数。** 比策略时必须报告重复次数、随机种子 / 共同随机数、标准误或置信区间。
5. **“次品率是抽样得到的”意味着参数也随机。** 问题4至少是“外层参数不确定性 + 内层生产随机性”的两层随机问题。

## 一句话记忆

> **先把每个策略做成一个可靠的“策略 → 利润分布”评价器；小空间优先穷举，复杂流程再用仿真；最后把抽样导致的次品率不确定性一起放进策略评价，而不是把一个估计值当成绝对真值。**
