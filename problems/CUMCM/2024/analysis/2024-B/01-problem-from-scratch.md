# 01｜从题目到模型：抽样、生产反馈与策略优化

> 这一篇先假装没有看过获奖论文。目标不是“找一个高级算法”，而是从题面结构出发，把四问变成一套可验证、可扩展、可复现的模型。

---

## 1. 先看懂四问为什么是一条链

官方题面真正考的是四层能力：

1. **Q1：统计决策。** 次品率未知，只能抽样；要用尽量少的检测次数决定接收还是拒收。
2. **Q2：小规模生产决策。** 次品率暂时当作已知，在两零件—成品—退换—拆解循环里决定“检不检、拆不拆”。
3. **Q3：规模扩展。** 生产图从两零件扩展到 8 零件、3 个半成品和成品，多层返工后解析公式迅速复杂。
4. **Q4：不确定性回流。** Q2/Q3 里的“已知次品率”其实是 Q1 抽样估计出来的，所以决策不能把估计值当绝对真值。

这条逻辑可以概括成：

```text
抽样得到关于 p 的信息
        ↓
给定 p，评价某个生产策略的利润
        ↓
在策略集合中寻找最佳策略
        ↓
让 p 本身带着抽样不确定性重新进入策略评价
```

一个很重要的习惯是：**先造评价器，再谈优化器。**

如果连“给定一个策略，它到底赚多少钱”都算不可信，换遗传算法、蚁群算法、模拟退火都只是把不可靠的评价器调用更多次。

# 2. Q1：这不是“估计次品率”，而是“设计接收 / 拒收规则”

题意：供应商声称次品率“不超过标称值” `p0`。标称值为 10%，需要：

- 在 95% 信度下认定 `p > 0.10` 时拒收；
- 在 90% 信度下认定 `p <= 0.10` 时接收；
- 希望检测次数尽可能少。

## 2.1 为什么不能只用样本比例

假设抽 10 个发现 1 个次品，样本次品率恰好 10%。

这并不能说明真实次品率就是 10%。样本率只是一个随机结果。真正要问的是：

> 在 `p=0.10` 这个边界假设下，看到当前这么多次品到底有多罕见？

因此核心对象应该是二项分布。

若抽检 `n` 件，发现 `k` 件次品：

\[
X\sim \mathrm{Binomial}(n,p).
\]

---

## 2.2 一个直接而严谨的单侧二项规则

### 拒收条件

要以 95% 信度认为真实次品率超过 10%，可以检验

\[
H_0:p\le 0.10,\qquad H_1:p>0.10.
\]

因为在 `H0` 内越大的 `p` 越容易产生较多次品，所以最不利边界是 `p0=0.10`。

当

\[
P_{p_0}(X\ge k)\le 0.05
\]

时，当前的高次品数在 `p=0.10` 下已经足够罕见，于是拒收。

等价地，也可以计算 95% 单侧 Clopper–Pearson 下置信限 `L95(k,n)`，若

\[
L_{95}(k,n)>0.10,
\]

则拒收。

### 接收条件

要以 90% 信度认为次品率不超过 10%，可以看单侧上界。若 90% 单侧上置信限

\[
U_{90}(k,n)\le 0.10,
\]

则接收。

用边界尾概率表达，可采用

\[
P_{p_0}(X\le k)\le 0.10
\]

作为“观察到如此少的次品，对 `p=0.10` 来说已经足够罕见”的接收条件。

注意：这里接收与拒收使用的是**不同方向的单侧证据**，不能把两个阈值混成一个普通双侧置信区间。

---

## 2.3 为什么“序贯抽样”自然符合“尽量少检测”

如果一开始就固定抽 100 件，那么无论这批货明显很好还是明显很差，都要做完 100 次检测。

更合理的是：

```text
每得到一个新样本：
    更新 n, k
    若满足拒收阈值 → 立刻拒收
    若满足接收阈值 → 立刻接收
    否则 → 继续抽
```

这样“容易判断”的批次会很早停止。

以 `p0=0.10` 为例，精确二项尾概率给出一些很直观的边界：

| 当前结果 | 最早可触发 | 边界概率 |
|---|---:|---:|
| 0 个次品 → 接收 | `n=22` | `0.9^22≈0.09848` |
| ≤1 个次品 → 接收 | `n=38` | `P(X≤1)≈0.09530` |
| ≤2 个次品 → 接收 | `n=52` | `P(X≤2)≈0.09663` |
| 2/2 个次品 → 拒收 | `n=2` | `P(X≥2)=0.01` |
| `n=3` 时 ≥2 个 → 拒收 | `n=3` | `P(X≥2)=0.028` |
| `n=4~8` 时 ≥3 个 → 拒收 | 例如 `n=8` | `P(X≥3)≈0.03809` |
| `n=9~14` 时 ≥4 个 → 拒收 | 例如 `n=14` | `P(X≥4)≈0.04413` |
| `n=15~20` 时 ≥5 个 → 拒收 | 例如 `n=20` | `P(X≥5)≈0.04317` |

这张表不是要求比赛时手算完，而是展示一个关键事实：

> **序贯规则的停止边界可以直接由精确二项概率预先生成。**

程序只需查表或实时计算即可。

---

## 2.4 一个必须写进论文的限制：边界附近可能迟迟停不下来

如果真实次品率就是 10% 附近，样本不断增加，但数据可能长期既不足以“有把握说超过”，也不足以“有把握说不超过”。

所以“尽可能少”并不意味着存在一个对所有真实 `p` 都很小的样本量。

工程上应再补一个设计，例如：

- 最大样本数 `Nmax`；
- 或设置灰区 `p_good < 0.10 < p_bad`，使用 SPRT（序贯概率比检验）；
- 达到 `Nmax` 仍未判定时，进入复检或保守拒收规则。

若用 SPRT，则真正比较的是两个有业务意义的水平：

\[
H_G:p=p_{good},\qquad H_B:p=p_{bad}.
\]

这比硬逼着模型区分 `9.999%` 和 `10.001%` 更符合实际。

# 3. Q2：先别急着模拟，策略空间其实非常小

Q2 只有四类二进制决策：

- 零件1是否检测；
- 零件2是否检测；
- 成品是否检测；
- 发现不合格成品后是否拆解。

所以总策略数只有

\[
2^4=16.
\]

**只有 16 个策略时，最稳的优化算法就是全部算一遍。**

真正难点不是“怎么搜索”，而是：

> 对每个策略，怎样正确计算长期利润？

---

## 3.1 先把质量概率写对

设：

- 零件1原始次品率 `p1`；
- 零件2原始次品率 `p2`；
- 当两个输入都为正品时，装配仍以概率 `r` 产生次品。

如果某零件不检测，则进入装配的合格概率是

\[
q_i=1-p_i.
\]

如果某零件全部检测并只让合格件进入装配，在“检测无误”的题设下可以近似记为

\[
q_i=1.
\]

于是一次装配产出合格成品的概率为

\[
P(G)=q_1q_2(1-r),
\]

成品次品概率为

\[
p_F=1-q_1q_2(1-r).
\]

这个式子很关键，因为题目附录明确说：**成品次品率 `r` 是在正品零件装配条件下的额外次品率。**

不能简单写成 `p1+p2+r`。

---

## 3.2 检测零件的“有效成本”比表面检测费更重要

如果零件 `i` 被检测，次品会被丢弃。为了获得一个可用于装配的合格件，平均需要购买

\[
\frac{1}{1-p_i}
\]

个零件。

若购买单价为 `a_i`，每件检测费为 `t_i`，那么一个“可用合格零件”的期望采购检测成本约为

\[
C_i^{good}=\frac{a_i+t_i}{1-p_i}.
\]

这给了一个非常好的经济直觉：

- `p_i` 越高，前端筛掉次品越有价值；
- 检测费越高，越可能把风险留到后面处理；
- 后续装配费、调换损失越高，越值得在前面阻断次品。

但这只是**局部直觉**。一旦允许拆解回收，前后决策会耦合，所以最终仍要比较完整策略的总利润。

# 4. 为什么 Q2 会出现循环，静态期望公式容易漏账

若不检测成品，次品可能卖给客户：

```text
成品 → 市场 → 次品被退回 → 调换 → 对退回成品拆解/报废 → 零件重新进入流程
```

若检测成品并拆解：

```text
成品 → 检测出次品 → 拆解 → 零件回库 → 再检测/再装配
```

这不是一次性的树，而是带回边的有向图。

因此最常见错误是：

- 只计算第一次装配；
- 拆解后的零件价值重复计算；
- 退换一个次品只算调换损失，却忘了还要补给客户一个合格品；
- 回收零件重新装配时漏算检测费或装配费；
- 同一件材料既出现在库存里又被算作报废。

# 5. Q2 有两条稳健求解路线

## 路线 A：小状态空间下做吸收马尔可夫奖励模型

定义状态，例如：

- 手里有可用零件1/2；
- 有待检测成品；
- 有退回次品；
- 已完成一个客户订单；
- 报废 / 吸收状态。

对固定策略 `π`，每个状态的价值满足

\[
V_\pi(s)=r_\pi(s)+\sum_{s'}P_\pi(s,s')V_\pi(s').
\]

写成矩阵：

\[
V=r+PV,
\]

所以

\[
V=(I-P)^{-1}r.
\]

优点：

- 无蒙特卡洛噪声；
- 16 个策略可以精确比较；
- 特别适合 Q2 这种小流程。

缺点：

- 状态定义要仔细；
- 到 Q3 后状态数会迅速膨胀。

---

## 路线 B：离散事件模拟 + 全枚举

比赛时更容易实现。

对每个策略：

1. 初始化采购的零件；
2. 按 Bernoulli 次品状态生成质量；
3. 根据策略检测 / 丢弃；
4. 组装；
5. 生成装配缺陷；
6. 检测或直接销售；
7. 对次品执行报废、拆解、退换；
8. 回收件重新进入流程；
9. 记录所有成本、收入、客户完成数；
10. 重复很多次得到平均利润和标准误。

然后 16 个策略全部评价。

这里根本不需要遗传算法。

---

# 6. 先统一“利润到底除以什么”

这是生产决策仿真特别容易出现的隐藏 bug。

可以选：

- 每批初始采购材料的总利润；
- 每卖出一件成品的平均利润；
- 每完成一个客户需求的利润；
- 单位时间长期平均利润。

这些指标不一定给出相同排序。

例如，一个策略会大量报废，最后只卖出很少产品；如果只除以“卖出去的件数”，剩下材料成本可能被稀释。

比赛中应明确：

> **所有策略必须使用相同初始资源、相同终止条件、相同利润分母。**

一个较稳的比较方式是：给每个策略相同的初始采购批量，直到无法继续装配，比较总利润；同时报告每售出产品利润作为辅助指标。

# 7. Q2 六种情形怎么分析，而不是机械给 6 行 0/1

题目表1故意改变了几类参数：

- 次品率；
- 检测成本；
- 调换损失；
- 拆解费用。

所以应该把六种情形解释成**敏感性实验**。

### 次品率升高

前端检测价值通常上升，因为次品越早拦截，越能避免浪费装配成本与市场损失。

### 市场调换损失升高

成品质量保障价值上升，可能推动：

- 更多零件检测；
- 更多成品检测；
- 或至少更积极处理次品。

### 某个零件检测成本很高

可能出现：不在零件层检测，把筛选推迟到成品 / 半成品层。

### 拆解费用非常高

回收材料的价值可能不足以覆盖拆解费，应直接报废。

真正有竞争力的论文不只是写“策略 1011 最优”，还应该画出：

\[
\text{参数变化}\rightarrow\text{最优策略切换}
\]

这就是后面 Q4 鲁棒性分析的雏形。

# 8. Q3：8 个零件、3 个半成品后，问题发生了什么变化

官方给出的两道工序、8 零件情形可以看成一张装配图：

```text
零件1...若干 → 半成品1 ┐
零件...         → 半成品2 ├→ 成品 → 市场
零件...         → 半成品3 ┘
```

每个半成品和最终成品又可能：

```text
检测 → 次品 → 拆解 → 上游节点
```

因此这是一个：

> **装配 DAG + 返工反馈边**

而不是单纯的树。

---

## 8.1 先参数化 16 个二进制决策

具体情形里可以定义：

\[
D=[X_1,\ldots,X_{16}]\in\{0,1\}^{16},
\]

例如：

- `X1~X8`：8 个零件是否检测；
- `X9~X11`：3 个半成品是否检测；
- `X12`：成品是否检测；
- `X13~X15`：3 个半成品次品是否拆解；
- `X16`：成品次品是否拆解。

于是策略空间大小是

\[
2^{16}=65536.
\]

这个数字应该在选择算法之前先算出来。

**65,536 并不大。**

如果单次策略评价很快，完整穷举甚至比启发式优化更有说服力，因为：

- 不怕局部最优；
- 不需要调交叉率、变异率；
- 能拿到第二名、第三名策略；
- 能直接看最优与次优的利润差；
- 后续鲁棒性分析更容易。

只有当每个策略评价极其昂贵，或者决策变量扩展到几十 / 上百位时，GA 才真正体现搜索优势。

# 9. Q3 的核心资产：一个可信的“策略评价器”

推荐把代码拆成下面几层：

```text
quality_model.py
    生成零件/半成品/成品质量状态

process_engine.py
    装配、检测、拆解、回库、退换

accounting.py
    统一记购买/检测/装配/拆解/调换成本与销售收入

policy.py
    16 位策略解析

evaluate.py
    对固定策略重复模拟，输出均值、方差、CI

search.py
    枚举 / GA / 其他优化

robustness.py
    改变次品率参数，重新评价策略
```

千万不要把“随机生成 + 流程判断 + 成本累计 + GA”全塞进一个大循环里。

# 10. 仿真前必须先做的 8 个守恒检查

蒙特卡洛最可怕的不是运行慢，而是**很快地给出一个错答案**。

至少检查：

1. 每个购入零件只能处于一个状态：库存 / 已装配 / 报废 / 已售出链条之一。
2. 拆解后的材料不能凭空增加。
3. 每次装配只计一次装配费。
4. 每次检测只计一次检测费。
5. 每次销售只计一次收入。
6. 客户退回的次品不能再次被当作新收入。
7. “输入均合格时仍可能装配成次品”的条件概率必须正确实现。
8. 返工循环必须有终止机制，并解释终止规则的业务含义。

再设计三个手算小案例：

- 所有次品率都为 0；
- 所有检测成本都为 0；
- 拆解成本设成极大值。

若模拟器在这些极端情况都做不出直觉结果，不要开始跑优化。

# 11. 蒙特卡洛比较策略时，必须正视“噪声”

设固定策略 `π` 的第 `r` 次模拟利润为 `Y_r(π)`。

估计期望利润：

\[
\hat\mu_\pi=\frac1R\sum_{r=1}^{R}Y_r(\pi).
\]

样本标准差为 `sπ`，则标准误：

\[
SE(\hat\mu_\pi)=\frac{s_\pi}{\sqrt R}.
\]

近似 95% 置信区间：

\[
\hat\mu_\pi\pm1.96\frac{s_\pi}{\sqrt R}.
\]

所以不能因为：

```text
策略A：52.38
策略B：52.51
```

就直接宣布 B 更好。

如果标准误比 0.13 大，这个排名可能只是随机数造成的。

---

## 11.1 共同随机数 CRN：本题非常值得用

比较两个策略时，不要让 A 遇到一批“运气好的零件”，B 遇到另一批“运气差的零件”。

对所有策略使用同一组底层随机样本：

```text
第 r 个情景：
    零件质量随机数固定
    装配缺陷随机数固定
    A、B、C...所有策略都在这个相同世界里运行
```

这样比较的是

\[
Y_r(A)-Y_r(B),
\]

大量共同环境噪声会被抵消。

这通常比单纯把重复次数翻倍更高效。

# 12. “全部穷举 + 两阶段仿真”比盲目 GA 更适合这个具体规模

推荐流程：

### 第一阶段：粗筛

- 65,536 个策略全部跑；
- 每个策略较少重复次数，例如 `R0`；
- 使用共同随机数；
- 保留前 50~200 个候选。

### 第二阶段：精评

- 对候选策略显著增加 `R1`；
- 报告均值、标准差、95% CI；
- 做成对差值置信区间；
- 如果前两名区间高度重叠，就承认它们统计上难以区分。

比一句“GA 第10代收敛，所以得到最优解”严谨得多。

# 13. Q4：最重要的升级是把“两种随机性”分开

问题4说：次品率也是通过抽样得到的。

这意味着存在两层不确定性。

### 第一层：参数不确定性（epistemic uncertainty）

真实次品率 `p` 不知道，抽样只能给我们一个区间或后验分布。

例如零件 i：

\[
X_i\sim Bin(n_i,p_i).
\]

可以得到：

- 精确置信区间 `C_i`；
- 或贝叶斯后验 `p_i|data ~ Beta(a+x,b+n-x)`。

### 第二层：过程随机性（aleatory uncertainty）

即使真实 `p` 已知，一批实际零件里哪些是次品仍是随机的，装配缺陷也是随机的。

所以完整评价应是：

```text
外层：抽 p 向量 / 遍历置信区域
    内层：给定 p，模拟生产过程
        得到策略利润分布
```

# 14. Q4 不应该只让所有次品率一起从 0.01 扫到 0.19

Q3 里有：

- 8 个零件次品率；
- 3 个半成品条件次品率；
- 1 个成品条件次品率。

它们的抽样结果应该分别有自己的不确定性。

现实中完全可能：

```text
零件3次品率偏高
零件6次品率偏低
半成品2装配过程异常
其他节点接近标称值
```

所以更一般的参数是向量

\[
\mathbf p=(p_1,\ldots,p_{12}).
\]

鲁棒性不能只沿

\[
p_1=p_2=\cdots=p_{12}=p
\]

这一条对角线检查。

对角线扫描可以做**快速敏感性展示**，但不应被写成完整的联合鲁棒性证明。

# 15. Q4 有四种层次的鲁棒目标

## 15.1 期望利润最大

\[
\max_\pi E_{\mathbf p}\left[E(Y|\mathbf p,\pi)\right].
\]

适合风险中性的企业。

## 15.2 置信区域最坏利润最大

若 `C` 是次品率联合置信区域：

\[
\max_\pi\min_{\mathbf p\in C}E(Y|\mathbf p,\pi).
\]

比较保守。

## 15.3 最小化最坏后悔值

先定义某个真实参数下最优利润 `V*(p)`，策略后悔值：

\[
R(\pi,\mathbf p)=V^*(\mathbf p)-V(\pi,\mathbf p).
\]

选：

\[
\min_\pi\max_{\mathbf p\in C}R(\pi,\mathbf p).
\]

这个特别适合解释“标称策略虽然不是每个情景第一，但到哪都不差太多”。

## 15.4 CVaR / 下尾风险

企业很怕亏损时，可以最大化下尾利润，或最小化损失 CVaR。

这样比只比较平均利润更贴近风险管理。

# 16. 进一步升级：抽样多少次本身也是一个经济决策

Q1 说“检测次数尽可能少”，Q4 又说明估计越精确，后续决策越可靠。

这其实暗示了**信息价值**：

多检测一件，要付检测成本；但它可能缩小 `p` 的不确定性，让我们避免选错生产策略。

可以定义：

\[
EVSI = \text{新增样本带来的期望决策收益提升}.
\]

当

\[
EVSI < \text{新增检测成本}
\]

时，就没有必要继续采样。

这是本题非常漂亮的高级延伸：

> **Q1 的样本量不必只由统计显著性决定，还可以由“信息对后续生产决策值多少钱”决定。**

比赛时间不足时不必完整求 EVSI，但在模型推广里写出来会很有层次。

# 17. 如果我比赛时重新做，会采用什么方案

## Q1

- 精确二项单侧检验；
- 序贯停止；
- 设置最大样本量；
- 若需要工业可执行性，再引入 `p_good / p_bad` 灰区与 SPRT。

## Q2

- 4 位二进制策略全部枚举 16 个；
- 优先尝试吸收马尔可夫奖励 / 更新收益解析模型；
- 若状态建模太繁琐，用事件仿真枚举；
- 六个情形统一评价口径，输出最优策略 + 次优策略 + 利润差。

## Q3

- 写一个通用装配图仿真器；
- 16 位策略全部 65,536 个粗评；
- 前若干策略用大量共同随机数精评；
- 报告置信区间；
- 若未来规模更大，再把 GA 作为加速器与穷举小规模基线对照。

## Q4

- 给各节点次品率分别建立抽样置信区间 / 后验；
- 外层采样参数向量，内层评价生产策略；
- 同时报告期望利润、最坏情景 / 后悔值与策略稳定区域；
- 讨论增加抽样量如何缩小策略不确定性。

# 18. 论文里最值得画的图

比“GA流程图”更有解释力的图包括：

1. **生产状态流转图**：明确返工回路。
2. **Q1 序贯停止边界图**：横轴 n，纵轴 k，画接受区 / 继续区 / 拒绝区。
3. **策略利润排序图**：前 20 个策略及 95% CI。
4. **策略切换热图**：次品率 × 检测成本 → 最优策略。
5. **鲁棒性 / regret 曲线**：标称策略与各情景最优策略的差距。
6. **蒙特卡洛收敛图**：重复次数增加时均值与 CI 宽度。

这些图直接回答“为什么选这个策略”，比单纯展示优化算法迭代曲线更重要。

# 19. 十个常见错误

1. 用样本次品率直接代替真实次品率，没有统计置信度。
2. 把 95% / 90% 两个要求写成同一个双侧检验。
3. 固定超大样本量，却声称“检测次数最少”。
4. 把成品次品率和零件次品率简单相加。
5. 拆解回收后重复计算材料价值。
6. 不同策略使用不同随机样本，导致排名噪声过大。
7. 只报平均利润，不报标准差 / CI。
8. 65,536 个组合也直接上 GA，却没有穷举基线。
9. 看到 GA 曲线平了就声称“证明全局最优”。
10. Q4 只改一个统一次品率，没有传播各节点自己的抽样不确定性。

# 20. 本题最终应形成的条件反射

以后遇到“检测—加工—返工—维修—退货—再利用”类题，先问五件事：

### 第一问：不确定的是状态，还是参数？

- 哪件产品坏：过程随机性；
- 次品率到底是多少：参数不确定性。

### 第二问：流程有没有回路？

有回路就优先想到：

- 马尔可夫奖励；
- 更新过程；
- 离散事件仿真。

### 第三问：策略空间到底多大？

先算 `2^d`，再决定是否需要启发式算法。

### 第四问：策略评价有没有噪声？

有噪声就想到：

- 共同随机数；
- 重复实验；
- 标准误 / CI；
- ranking & selection。

### 第五问：估计误差会不会改变决策？

如果会，就不要止步于“参数估计值”，而要把整个置信区间 / 后验分布传入决策层。

## 最后压成一句话

> **2024 B 最值得学的不是某个优化算法，而是“统计证据 → 随机流程评价器 → 有限策略优化 → 参数不确定性下的鲁棒策略”这一整条闭环。**
