# 2024 CUMCM 学习入口

> 2024 年目前已完成 A、B 两题的教学式分析。这里作为年度入口，不把两种完全不同的题型混在一起。

## A题｜“板凳龙”闹元宵

**核心训练：**曲线约束链、固定弦长、隐式约束速度传播、碰撞事件、可行性边界、分段路径与尺度降维。

推荐顺序：

1. [A｜01 从零建模：曲线约束链、碰撞、调头与安全速度](01-problem-from-scratch.md)
2. [A｜02 国一 / 北太天元数模之星论文深度拆解](02-national-first-paper-deep-dive.md)
3. [A｜03 迁移手册：链式运动、碰撞与路径设计](03-transferable-playbook.md)

原始材料：

- [官方 A题与附件](../official/CUMCM2024Problems/A题/)
- [上海交通大学国一、北太天元数模之星论文](../papers/national_first/2024-A-上海交通大学-板凳龙-国一.pdf)
- [A题官方文本抽取](source_text/problem_A_official.txt)
- [A题论文文本抽取](source_text/paper_SJTU_national_first.txt)

**一句话记忆：**把整条板凳龙统一写成沿路径参数化的固定弦长链；位置用弦长约束递推，速度由隐式约束微分传播，碰撞和安全速度则都转成临界事件 / 可行性边界。

## B题｜生产过程中的决策问题

**核心训练：**精确二项 / 序贯抽样、质量传播、检测—拆解—返工反馈、随机成本记账、有限策略枚举、蒙特卡洛误差控制与抽样参数不确定性下的鲁棒决策。

推荐顺序：

1. [B题学习入口](2024-B/README.md)

**版本说明：**当前 B题论文是获奖队伍赛后正式发表的期刊版，不冒充赛时原始提交稿。外部官方报道显示赛时成果题名包含“蚁群算法与遗传算法”，而期刊版题名与正文重点为“遗传算法优化的蒙特卡洛模拟”；因此教学分析严格以当前可读期刊版为主体，并把版本差异单独标出。

**一句话记忆：**先把每个策略做成可靠的“策略 → 利润分布”评价器；小策略空间优先枚举，复杂返工流程再用模拟器，最后把抽样造成的次品率不确定性一起传到决策层。
