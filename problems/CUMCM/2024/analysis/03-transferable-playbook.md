# 2024 A题可迁移解题手册：链式运动、碰撞与路径设计

> 这篇不是再讲一遍“板凳龙”，而是把2024 A题抽象成以后可以重复使用的建模套路。

---

# 1. 识别题型：看到这些关键词就要想到“曲线约束链”

如果题目出现：

- 很多刚性杆件/车厢/节点首尾相接；
- 连接点必须沿给定道路、轨道或曲线移动；
- 龙头/牵引端速度已知；
- 需要求所有节点位置、速度；
- 还要判断自碰撞、最小转弯空间、最大安全速度；

第一反应应该是：

\[
\boxed{\text{路径参数化}+\text{固定弦长约束}}
\]

而不是建立一个几百自由度的动力学系统。

这类题通常主要是**运动学 + 计算几何 + 数值搜索**，不一定需要受力分析。

---

# 2. 第一层通用模板：把路径统一写成 P(s)

最理想的形式是弧长参数：

\[
P(s)=(x(s),y(s)),
\]

并且

\[
\|P'(s)\|=1.
\]

那么沿路径速度就是：

\[
\dot s=v.
\]

如果原路径更容易用别的参数 `u` 写：

\[
P=P(u),
\]

则先准备弧长：

\[
S(u)=\int \|P'(u)\|du.
\]

龙头恒速时：

\[
S(u_0(t))=S(u_0(0))+v_0t.
\]

然后数值反解 `u_0(t)`。

## 常用求根器选择

- 能保证单调、有 bracket：二分；
- 一元平滑：Brent；
- 有好初值且导数稳定：Newton；
- 不要无必要地用遗传算法/PSO。

---

# 3. 第二层通用模板：固定弦长递推

设第 `i` 个连接点的路径参数为 `s_i`，相邻连接点距离固定：

\[
L_i.
\]

约束：

\[
F_i(s_{i+1};s_i)
=\|P(s_{i+1})-P(s_i)\|^2-L_i^2=0.
\]

已知 `s_i`，求 `s_{i+1}`。

这就是整条链的位置递推。

## 最重要的检查

固定的是：

\[
\text{欧氏直线距离}
\]

还是：

\[
\text{沿路径弧长距离}？
\]

刚性板/刚性杆绝大多数固定的是前者。

---

# 4. 第三层通用模板：对几何约束求导得到速度

定义：

\[
C_i=P_{i+1}-P_i.
\]

因为：

\[
C_i\cdot C_i=L_i^2,
\]

对时间求导：

\[
C_i\cdot(V_{i+1}-V_i)=0.
\]

若每个点沿路径单位切线 `\tau_i` 运动：

\[
V_i=v_i\tau_i,
\]

则：

\[
\boxed{
v_{i+1}
=v_i
\frac{C_i\cdot\tau_i}
{C_i\cdot\tau_{i+1}}
}
\]

这就是链式速度传播通式。

## 这个公式的直觉

连接杆长度不能变化，所以两端速度在杆方向上的分量必须一致。

也就是：

\[
V_i\cdot \hat C_i=V_{i+1}\cdot \hat C_i.
\]

这比背具体螺线公式更容易理解。

---

# 5. 什么时候速度会突然放大

从

\[
v_{i+1}=v_i\frac{C_i\cdot\tau_i}{C_i\cdot\tau_{i+1}}
\]

可以看到，如果：

\[
C_i\cdot\tau_{i+1}\to0,
\]

那么后一点需要很大的沿程速度才能维持杆长。

所以链式系统的速度峰值往往来自几何构型，而不是外部动力。

这可以用来提前判断危险位置：

- 路径急转处；
- 两段路径切换处；
- 杆方向接近路径法向处；
- 曲率变化明显处。

以后做最大速度约束时，不要只盯“曲率最大”四个字，要看**连杆方向与切线的相对几何关系**。

# 6. 碰撞问题的标准拆法

不要一上来就检查所有物体对。

计算几何通常分两层。

## 6.1 Broad phase：候选筛选

目的：快速排除绝对不可能碰撞的对象。

可以用：

- 距离阈值；
- 包围圆；
- AABB；
- 网格哈希；
- KD-tree；
- 曲线参数差；
- 本题的一圈角度差先验。

## 6.2 Narrow phase：精确碰撞

对矩形板凳，可以用二维 SAT。

两个凸矩形不相交，当且仅当存在某条分离轴，使二者投影区间不重叠。

候选轴只需要：

- 矩形A两条边的法向；
- 矩形B两条边的法向。

如果所有轴投影都重叠，则相交。

这样可以把“碰撞”的数学定义写得非常严格。

---

# 7. 把“什么时候失败”统一写成安全裕量

这是一个非常值得长期使用的模板。

定义：

\[
g(t)=\text{安全量}(t)-\text{允许下限}.
\]

例如碰撞：

\[
g(t)=d_{\min}(t)-d_{safe}.
\]

则：

- `g>0`：安全；
- `g=0`：临界；
- `g<0`：失效。

首次失效时间：

\[
t^*=\inf\{t:g(t)\le0\}.
\]

这个框架可以迁移到：

- 温度超限；
- 电压越界；
- 库存耗尽；
- 应力超过强度；
- 信号跌破阈值；
- 机器人自碰撞。

# 8. 设计题的关键：不要直接“最大化/最小化”，先写可行性函数

2024 A题问题3可抽象成：

设计参数 `d`，要求全过程安全。

定义最坏工况：

\[
G(d)=\min_{t\in\mathcal T(d)}g(t;d).
\]

那么：

\[
G(d)\ge0
\]

表示参数 `d` 可行。

问题就是：

\[
\min d\quad\text{s.t.}\quad G(d)\ge0.
\]

这叫**可行性边界搜索**。

## 一个非常实用的算法流程

```text
1. 先粗扫 d
2. 画 G(d)
3. 判断是否近似单调
4. 若单调：二分找 G(d)=0
5. 若不单调：再考虑全局优化
```

很多比赛队伍会直接套智能优化，反而失去对问题结构的利用。

---

# 9. “最坏工况”内层搜索怎么做

如果：

\[
G(d)=\min_t g(t,d),
\]

而时间是一维，推荐：

```text
粗网格 t0,t1,...
↓
找到所有疑似局部最小区间
↓
分别用 Brent/golden section 精修
↓
取最小值
```

只有当：

- 维数高；
- 目标特别不规则；
- 没有可靠 bracket；

再考虑 PSO、GA、SA 等。

### 算法选择原则

> 先榨干问题结构，再使用通用黑箱优化器。

# 10. 分段路径不要分段写一整套链模型

设路径有多段：

\[
P_1,P_2,\dots,P_m.
\]

最容易犯的错误是每两段组合都写一套方程。

当 `m` 增长时，会出现大量 case。

更好的方式是定义全局弧长 `s`：

```text
0 ---- S1 ---- S2 ---- ... ---- Sm
      段1      段2             段m
```

然后写：

```python
path(s):
    if s < S1:
        return segment1(...)
    elif s < S2:
        return segment2(...)
    ...
```

整个链仍然只使用：

\[
\|P(s_{i+1})-P(s_i)\|=L_i.
\]

这样路径从4段变成10段，核心算法都不用改。

---

# 11. 路径连接至少检查 C0、C1 连续

分段路径拼接时：

## C0：位置连续

\[
P_{left}=P_{right}.
\]

否则路径断开。

## C1：切向连续

\[
\tau_{left}=\tau_{right}.
\]

否则运动方向瞬间跳变。

题目4明确要求相切，本质就是 C1 连续。

如果还关心加速度舒适性，最好进一步考虑曲率连续，即更高阶平滑。

圆弧与螺线虽然相切，但曲率通常会发生跳变，所以速度可以连续，而加速度未必平滑。

这是现实工程设计可继续扩展的方向。

---

# 12. 优化前先做“自由度计数”

题目经常问：

> 能否进一步调整，使路径更短？

不要立刻写目标函数。

先列：

```text
未知几何参数有几个？
约束方程有几个？
还剩几个自由度？
```

如果：

\[
\text{自由变量数}-\text{独立约束数}=0,
\]

说明几何构型已经离散/唯一确定。

这时候根本不存在连续优化空间。

2024 A题问题4就是非常典型的例子。

# 13. 发现比例/尺度关系，可以把优化直接消掉

问题5本质是：

\[
\max v_0
\]

subject to

\[
v_i(t)\le V_{limit}.
\]

如果系统满足：

\[
v_i(t;\lambda v_0)=\lambda v_i(t;v_0),
\]

则只需在单位输入下计算：

\[
M=\max_{i,t}\frac{v_i}{v_0}.
\]

直接：

\[
\boxed{v_{0,max}=V_{limit}/M}.
\]

这类尺度分析经常能把一个看似复杂的参数优化直接变成一次计算。

其他常见比例关系：

- 线性电路中电压/电流随输入幅值缩放；
- 线性结构响应随载荷缩放；
- 某些概率模型随样本量归一化；
- 齐次目标函数中的尺度消去。

比赛现场要主动找。

# 14. 三分法、二分法、PSO分别什么时候用

## 二分法

适合：

- 求根；
- 单调阈值；
- 明确知道解被 bracket 住。

例如：

- 龙头角度反演；
- 临界螺距（若可行性单调）；
- 首次碰撞时间。

## 三分法

适合：

- 一元连续；
- 已经确认区间单峰。

不能因为“求最大值”就随便三分。

## PSO

适合：

- 多维；
- 黑箱；
- 多峰；
- 导数不可得；
- 计算预算允许。

一维问题通常先考虑更确定性的办法。

# 16. 必做的数值自检

## 16.1 杆长误差

对所有时间、所有相邻把手：

\[
e_L=\left|\|P_{i+1}-P_i\|-L_i\right|.
\]

报告：

\[
\max e_L.
\]

## 16.2 龙头弧长误差

验证：

\[
|S(t)-S(0)|\approx v_0|t|.
\]

## 16.3 参数顺序

同一条路径上的把手参数应保持正确前后次序。

如果出现次序交换，说明 root search 找错分支。

## 16.4 临界碰撞双侧验证

对求得 `t*`：

\[
g(t^*-\varepsilon)>0,
\qquad
g(t^*+\varepsilon)<0.
\]

## 16.5 临界设计参数双侧验证

例如最小螺距 `d*`：

\[
G(d^*+\varepsilon)\ge0,
\]

而

\[
G(d^*-\varepsilon)<0.
\]

这比只报一个“最优值”有说服力得多。

## 16.6 分段路径连接

检查：

- 端点坐标差；
- 单位切线差；
- 速度是否有限；
- 曲率是否出现异常跳变。

# 17. 图应该画什么才真正有分析价值

不要只画“好看的龙”。

推荐至少有：

1. 整体运动轨迹；
2. 临界碰撞处局部放大；
3. 最小安全距离 `g(t)` 曲线；
4. `G(d)` 与螺距关系；
5. 调头路径几何及切点/圆心；
6. 全局最大把手速度随时间变化；
7. 临界时刻速度沿龙身编号分布。

这些图分别回答：

- 模型是不是像现实；
- 为什么在这里碰撞；
- 为什么这个参数是临界；
- 为什么速度峰值出现在这里。

图应该服务于论证，不只是装饰。

# 18. 论文写作模板：几何运动题可以这样写

## 问题分析

先写因果关系：

> 所有连接点被限制在给定路径上，因此可用路径参数降维；相邻把手由刚性板连接，欧氏距离恒定；由此可以递推位置，并通过对约束求导得到速度。

这句话比“本文建立XXX模型”更有信息量。

## 模型建立

顺序：

```text
路径参数化
→ 龙头时间关系
→ 相邻连接约束
→ 位置递推
→ 速度递推
```

## 碰撞/优化

不要重新讲一遍运动模型，只写新增层：

```text
在上述运动模型基础上，定义安全裕量...
```

保持问题之间的继承关系。

## 结果分析

至少解释：

- 为什么临界位置在这里；
- 哪种几何因素导致速度放大；
- 参数略微变化会怎样；
- 数值精度是多少。

# 19. 比赛现场90分钟思考清单

如果你第一次看到类似2024 A题，可以按这个顺序推进。

### 前15分钟

- 画结构；
- 找真实连接点；
- 算连接点间距；
- 确认路径方程。

### 15~30分钟

- 用路径参数描述所有节点；
- 推龙头弧长关系；
- 写相邻弦长约束。

### 30~45分钟

- 写 root solver；
- 递推整条链；
- 验证杆长误差。

### 45~60分钟

- 对约束求导；
- 得速度；
- 验证龙头速度。

### 60~75分钟

- 构造物体矩形；
- 做碰撞判据；
- 定义安全裕量。

### 75~90分钟

- 看后几问；
- 标记哪些只是复用模型；
- 找单调性、比例性、对称性；
- 决定真正需要的优化器。

这样通常能把整题骨架搭出来。

# 20. 最终应该形成的“模型记忆”

以后不要记：

> “板凳龙 = 粒子群。”

应该记：

> **链式刚体沿曲线运动：路径参数化；固定弦长求位置；约束微分求速度；安全裕量找临界；最坏工况定义设计可行性；分段路径统一弧长化；最后利用单调、对称和比例关系减少优化。**

这才是2024 A题真正能带到下一场比赛的能力。
