## 一句话抓住这道题

把一条 100 字符气象报文看成两个 50 字符“半包”，则一条消息最多装 3 个半包；主站之间是无损链路，副站发出的原始尝试成功率只有 0.8。于是：

- 问题 1 是一个**容量受限的 all-gather / 全互传调度**；
- 问题 2、3 是在它上面叠加**独立失败概率与冗余发送**；
- 真正困难的不是算概率，而是同时安排“谁给谁发、发什么、什么时候发”，并证明给出的轮数或分队数已经最优。

## 本题最值得记住的三个结果

- 主站完全共享最少轮数：
  \[
  K_{\min}=1+\left\lceil\frac{2(N-2)}{3}\right\rceil.
  \]
- 若一次副站直发成功率为 0.8，则两次独立尝试至少一次成功的概率为
  \[
  1-0.2^2=0.96,
  \]
  因而足以跨过问题 2 的 0.9 门槛。
- 三次独立尝试至少一次成功的概率为
  \[
  1-0.2^3=0.992,
  \]
  因而足以跨过问题 3 的 0.97 门槛。

这些数字只是表面。真正可迁移的思想是：**先把报文容量离散化，再把“可靠性要求”换算成需要多少次独立原始尝试，最后用确定性主站骨干去传播已经获得的可靠信息。**
