# 2022 CUMCM A题《波浪能最大输出功率设计》学习导读

> 目标不是复述国一论文，而是学会：比赛现场拿到类似题目时，如何从题意一步步走到可计算、可优化、可验证的模型。

## 0. 一句话看穿这道题

这道题的本质不是“海洋能源”，而是：

**受周期外力驱动的耦合振动系统 + 阻尼器能量输出 + 阻尼参数优化。**

题目背景可以先翻译成一条因果链：

波浪激励 → 浮子运动 → 浮子与振子产生相对运动 → PTO阻尼器做功 → 输出功率 → 调阻尼使平均功率最大。

只要先看出这条链，四问就会立刻变得清楚。

---

## 1. 四问其实只有两个模型

### 问题1：一维、两物体、正向求解

已知波浪、结构参数、阻尼参数，求浮子和振子的位移、速度。

这是：**给参数 → 求运动响应**。

### 问题2：沿用问题1，反过来优化

把阻尼系数当设计变量，用问题1的运动模型计算输出功率，再寻找平均功率最大的参数。

这是：**给目标 → 反推最优参数**。

### 问题3：把问题1从1维扩展到垂荡+纵摇

自由度增加、出现旋转、力矩和几何耦合，但基本思想没变：仍然是先做运动学和受力，再列动力学方程。

### 问题4：沿用问题3做双参数优化

直线阻尼和旋转阻尼都变成设计变量，目标仍是平均输出功率最大。

因此比赛现场不要把它看成“四道不同题”，而应画成：

```text
问题1：简单动力学模型
   ↓
问题2：在模型1上做优化

问题3：扩展动力学模型
   ↓
问题4：在模型3上做优化
```

这是数模里非常常见的题目结构：**前一问建模，后一问优化；简单模型先打底，复杂模型再扩展。**

---

## 2. 拿到题目后的第一张草稿纸应该写什么

不要先搜“波浪能模型”。先列五类东西：

| 类别 | 本题对应内容 |
|---|---|
| 对象 | 浮子、振子、PTO弹簧、阻尼器 |
| 状态 | 位移、速度；扩展后还有角位移、角速度 |
| 输入 | 波浪激励力 `f cos(ωt)`、激励力矩 `L cos(ωt)` |
| 相互作用 | 弹簧力、阻尼力；扩展后有扭转弹簧、旋转阻尼 |
| 输出/目标 | 阻尼器做功产生的平均功率 |

然后问自己：

1. 有几个自由度？
2. 每个物体受哪些力/力矩？
3. 哪些是题目直接给的关系？
4. 哪些量是未知时间函数？
5. 最后要优化哪个参数？

这五问基本就是本题的骨架。

## 3. 问题1：如何从题意自己推导出来

### 3.1 先选坐标，而不是先列公式

国一论文选择：

- `x_v(t)`：振子相对静水平衡位置的竖直位移；
- `x_f(t)`：浮子相对静水平衡位置的竖直位移；
- 向上为正。

这个选择很聪明，因为题目说初始时二者平衡于静水中。

**以平衡位置为零点后，恒定的重力和静态浮力可以互相抵消，不必把一堆常数项带进方程。**

这是物理建模里非常值得形成习惯的一招：

> 先问能不能通过坐标原点的选择，把静态平衡项消掉。

### 3.2 振子受力

振子不接触海水，主要只有两个动态作用：

1. 弹簧恢复力：`-k(x_v-x_f)`；
2. PTO阻尼力：反对相对运动。

若阻尼系数为常数 `ν`：

`F_d = -ν(ẋ_v-ẋ_f)`。

于是牛顿第二定律：

`m_v ẍ_v = -k(x_v-x_f)-ν(ẋ_v-ẋ_f)`。

注意：弹簧和阻尼器都连接在两个物体之间，因此它们关注的不是绝对位移/速度，而是**相对位移和相对速度**。

这句话以后见到“双质量-弹簧-阻尼”系统要条件反射地想到。

### 3.3 浮子受力

浮子受到：

- 波浪激励：`f cos(ωt)`；
- 弹簧反作用力；
- PTO阻尼器反作用力；
- 兴波阻尼：`-μ ẋ_f`；
- 静水恢复力：`-r x_f`；
- 附加质量效应。

附加质量最容易把初学者吓到，但题目已经把物理解释告诉你了：浮子加速时还要带动周围一部分水，所以可以直接把惯性质量写成：

`m_f + m_a`。

于是：

`(m_f+m_a)ẍ_f = k(x_v-x_f)+ν(ẋ_v-ẋ_f)-μẋ_f-rx_f+f cos(ωt)`。

### 3.4 用矩阵看，会更清楚

令

`q=[x_v,x_f]^T`，

则线性阻尼情况下可以写成：

`M q̈ + C q̇ + K q = b f cos(ωt)`。

其中

```text
M = [[m_v,     0      ],
     [ 0,   m_f+m_a   ]]

C = [[ ν,    -ν      ],
     [-ν,   ν+μ      ]]

K = [[ k,    -k      ],
     [-k,   k+r      ]]
```

这比记两条长方程更重要。

因为以后看到更复杂的机械、电路、控制系统，本质上都可能重新变成：

`质量/惯性项 + 阻尼项 + 恢复项 = 外部激励`。

## 4. 为什么第一问要分“线性阻尼”和“非线性阻尼”

题目第二种情况说：阻尼系数本身与相对速度绝对值的 `n` 次幂成正比。

因此阻尼力应写为：

`F_d = -ν |Δv|^n Δv`，其中 `Δv=ẋ_v-ẋ_f`。

于是：

- `n=0`：退化为普通线性阻尼；
- `n>0`：方程出现速度的非线性项，不能再写成常系数线性系统。

这时一个非常重要的建模判断出现了：

> **模型性质变了，求解方法也应该跟着变。**

国一论文的处理是：

- 线性：尝试解析；
- 非线性：数值积分。

这是非常值得学的，而不是无论什么方程都一股脑 `ode45`。

---

## 5. 他们为什么在线性模型里使用拉普拉斯变换

问题1要求的是“从初始平衡状态出发，前40个周期内的完整响应”。

线性常系数微分方程 + 已知初值 + 正弦外力，天然适合拉普拉斯变换。

思维过程应当是：

```text
线性？ → 是
常系数？ → 是
初值明确？ → 是
周期外力？ → 是

→ 有机会得到解析解
```

他们把两条二阶方程变到 `p` 域，解出 `X_v(p), X_f(p)`，再由 Mathematica 做逆拉普拉斯。

比赛中你不必执着手算出巨长表达式。解析法的价值是：

1. 说明你理解系统结构；
2. 数值精度高；
3. 为问题2的稳态分析铺路。

如果时间紧，问题1直接把二阶方程改写为四个一阶状态方程，用数值 ODE 求解也完全合理。

---

## 6. 非线性时为什么改用数值ODE

加入 `|Δv|^n Δv` 后，很难获得可用的闭式解。

此时应该按以下顺序选择算法，而不是先决定“我要用某某高级算法”：

```text
先建立正确方程
   ↓
判断方程类型
   ↓
解析不可行
   ↓
转为一阶状态方程
   ↓
选择稳定的数值ODE求解器
```

论文使用 SciPy 的 `solve_ivp(method='Radau')`，属于隐式 Radau IIA 方法，适合处理可能较刚性的常微分方程。

代码中的状态变量就是：

`[x_v, x_f, ẋ_v, ẋ_f]`。

二阶方程化一阶系统，是数模中非常高频的操作，必须熟练。

---

## 7. 问题2：最重要的跳跃——从“运动”变成“功率”

很多人建完微分方程就不知道优化什么。

这里应该回到物理本身：题目说 **阻尼器做的功就是能量输出**。

阻尼器两端的相对速度为：

`Δv = ẋ_v-ẋ_f`。

线性阻尼力大小：

`F_d = ν|Δv|`。

因此瞬时输出功率为：

`P(t)=ν(Δv)^2`。

非线性情况下：

`P(t)=ν|Δv|^(n+2)`。

然后定义平均功率：

`P_avg = (1/T_obs) ∫ P(t) dt`。

到这里，原来的动力学问题已经自然变成一个优化问题。

这一步要学会的不是公式本身，而是：

> **目标函数必须从题目的物理意义中推出来，而不是为了优化而凭空造一个指标。**

---

## 8. 为什么问题2只关心稳态

周期外力作用下，系统一般可以分为：

`总响应 = 瞬态响应 + 稳态周期响应`。

发电装置长期运行时，刚启动那几十秒的瞬态并不代表长期发电性能。

因此优化平均功率应尽量基于稳态，而不是让初始瞬态左右结果。

这也是官方评阅要点特别强调的地方。

### 线性阻尼：直接用复振幅

稳定后可以设：

`x_v = Re(A_v e^{-iωt})`

`x_f = Re(A_f e^{-iωt})`。

代回线性方程，相当于把微分运算替换为：

- 一阶导数 → `-iω`；
- 二阶导数 → `-ω²`。

于是微分方程直接变成一个 2×2 复数代数方程。

求出 `A_v,A_f` 后：

`P_avg = (ν/2) ω² |A_v-A_f|²`。

这样每给一个 `ν`，无需重新跑几十个周期的ODE，就能直接算稳态平均功率。

论文进一步对该表达式求导，得到：

**线性阻尼最优值约 `ν = 37193.8 N·s/m`。**

这就是“解析模型替优化节省计算量”的典型案例。

### 非线性阻尼：仿真嵌套优化

非线性时没有复振幅解析式，因此流程变成：

```text
给一组 (ν,n)
    ↓
数值求ODE
    ↓
得到相对速度 Δv(t)
    ↓
计算瞬时功率
    ↓
数值积分得到平均功率
    ↓
优化器再换一组参数
```

这就是典型的 **simulation-based optimization（仿真驱动优化）**。

论文先画参数-功率曲面，再用下山单纯形法（Nelder-Mead）细化，得到大约：

- `ν ≈ 63414`；
- `n ≈ 0.2259`。

这里真正应该学习的是“先粗看全局形状，再局部精搜”的思想。

## 9. 问题3为什么突然难很多

问题1只有两个自由度：

`x_v, x_f`。

问题3加入纵摇后，论文选了四个广义坐标：

- `x_f`：浮子竖直位移；
- `x_v`：振子沿中轴的相对滑动；
- `θ_f`：浮子相对竖直方向的角度；
- `θ_v`：中轴/振子相对浮子轴线的角度。

振子真实方向由 `θ_f+θ_v` 决定。

### 难点1：振子的运动坐标系会旋转

振子一边沿中轴滑动，中轴本身又在转，所以不能简单写 `a=ẍ`。

论文使用随中轴旋转的基矢 `e_r,e_θ`，写出位矢后连续求导，得到径向、切向加速度。

这种题碰到“杆上滑块 + 杆旋转”“机器人机械臂”“旋转轨道上的质点”，都可以用同样方法：

> **先写位置矢量，再求一次导数得到速度，再求一次得到加速度。**

不要凭感觉直接写加速度。

### 难点2：出现内部约束力

中轴会对振子产生垂直于中轴方向的约束力 `F1`。

因此论文不是只列4条方程，而是：

- 3条力方程；
- 2条力矩方程；
- 未知量为4个广义坐标 + 1个内部力 `F1`。

**5个未知量、5条方程，系统闭合。**

比赛现场必须养成“未知数个数 vs 独立方程个数”的检查习惯。

### 难点3：转动惯量随振子位置变化

振子离转轴距离会随 `x_v` 改变，因此通过平行轴定理：

`I_v = I_cm + m_v x_v²`。

而浮子由圆柱壳和圆锥壳组成，论文根据均匀面密度拆分质量，再积分计算其转动惯量。

这说明附件中的几何尺寸不是装饰：看到结构几何，就应该想“后面是否需要质量、质心、转动惯量”。

## 10. 问题4为什么本质上与问题2相同

问题3中：

- 直线阻尼器靠相对滑动输出；
- 旋转阻尼器靠相对转动输出。

所以总瞬时功率可写成：

`P(t)=ν ẋ_v² + ν_m θ̇_v²`。

给定 `(ν,ν_m)`：

1. 解问题3的8维一阶状态方程；
2. 算总功率；
3. 对时间积分；
4. 取平均；
5. 优化两个阻尼参数。

论文得到：

- 直线阻尼约 `55384.97`；
- 旋转阻尼约 `88032.32`；
- 平均最大功率约 `389.74 W`。

他们还观察到旋转部分对总功率贡献很小，因为相对角运动幅度比直线运动小很多。

这一段非常值得学习：**结果出来后要解释“为什么”，不能只报最优参数。**

## 11. 这篇国一真正做得好的地方

### 11.1 先简单、再复杂

问题1先建立可以完全看懂的一维系统，问题3再加角度和非线性耦合。

### 11.2 解析和数值方法不是互斥的

他们没有追求“全数值”或“全解析”：

- 能解析的线性部分就解析；
- 非线性部分才数值。

### 11.3 目标函数来自物理

平均功率直接由阻尼做功推导，而不是人为造评价指标。

### 11.4 优化之前先看函数形状

先画功率曲面/色度图，再决定优化方法。这比直接扔一个遗传算法靠谱。

### 11.5 最后检查模型什么时候失效

论文继续研究激励力过大时浮子是否会被海水淹没，从而检查“静水恢复力线性化、水面近似不变”等假设的适用范围。

这一步让论文从“算出答案”提升到了“知道答案什么时候可信”。

## 12. 但不要盲目照抄：论文中有几处需要修正

国一论文也不是教科书。

### 12.1 “非凹，所以局部最优就是全局最优”逻辑不成立

对于最大化问题，通常是**凹函数**才有“局部最大即全局最大”的良好性质。

论文这里更合理的说法应是：

> 网格扫描得到的曲面在可行域内呈单一主要峰区，未观察到竞争性的局部峰，因此使用局部优化器，并通过多初值/全局算法复核。

比赛中建议：

**粗网格 + 多初值局部优化 / differential evolution 复核。**

### 12.2 用 Jacobian 元素大小之比判断刚性不够严谨

刚性更应该考察系统的时间尺度分离、Jacobian特征值实部跨度以及显式方法的稳定步长限制。

但选择 Radau 本身是合理的稳健做法。

### 12.3 `t_eval=0.2` 不等于“固定0.2步长的Radau”

论文代码使用 `solve_ivp(..., method='Radau', t_eval=...)`。

`0.2 s` 是输出采样间隔；Radau 内部仍然自适应选取积分步长。

### 12.4 精度分析把 Radau 和经典RK4混在了一起

SciPy Radau 是五阶 Radau IIA 隐式RK，而论文后面的“四阶RK总体精度”论证并不能直接用于代码里的Radau。

更规范的验证方式是：

- 收紧 `rtol/atol`；
- 采用更密输出网格；
- 比较结果变化；
- 做步长/容差收敛性实验。

### 12.5 论文中有一个区间笔误

官方问题2线性阻尼范围是 `[0,100000]`，论文正文一处写成 `[0,10000]`，但其最优值 `37193.8` 显然按正确的大区间求得。

这些问题并不妨碍论文整体优秀，但说明：**读国一的目标是学习思路，不是把每一句都当定理。**

## 13. 以后遇到类似题，你应该形成的固定解题模板

看到“机械装置 + 外部激励 + 输出能量 + 参数设计”时，脑中按下面顺序走：

```text
① 删掉故事背景，找输入 / 状态 / 输出 / 可调参数
↓
② 数自由度，定义广义坐标
↓
③ 画每个物体的受力/力矩图
↓
④ 写运动学关系（尤其旋转坐标系）
↓
⑤ 用 Newton / Euler / Lagrange 建动力学方程
↓
⑥ 检查未知量数 = 独立方程数
↓
⑦ 判断线性 / 非线性、稳态 / 瞬态
↓
⑧ 能解析则解析，不能解析再数值
↓
⑨ 从物理意义构造目标函数
↓
⑩ 粗搜索看目标函数形状，再选优化器
↓
⑪ 做数值收敛、敏感度、极端情况和适用范围检查
↓
⑫ 论文中解释每一个模型选择“为什么”
```

这套流程比背“遗传算法、粒子群、TOPSIS、神经网络”重要得多。

## 14. 你读这篇论文时，第一遍应该只抓这些问题

先不要死磕式(10)的大方程。

第一遍只要求自己能回答：

1. 为什么问题1只有两个自由度？
2. 为什么弹簧和PTO阻尼都使用相对量？
3. 为什么附加质量可以直接加到浮子惯性项？
4. 为什么线性阻尼可以做复振幅/拉普拉斯，而非线性不行？
5. 为什么平均功率由 `阻尼力 × 相对速度` 得到？
6. 为什么问题2只优化稳态而不是启动瞬态？
7. 问题3为什么需要一个内部约束力 `F1`？
8. 为什么问题4其实只是“问题3 + 优化器”？
9. 这篇论文用什么证据说明自己的模型有适用范围？
10. 哪几处论证你不应该原样学习？

如果这10个问题你都能自己讲出来，就已经真正读懂了这篇论文的主干。

## 15. 推荐学习顺序

### 第一轮：学“看题”

只看题目、问题分析和受力图，能够自己画出四问的依赖关系。

### 第二轮：学问题1

自己从零写出两条垂荡方程，并把它改成4维一阶状态方程。

### 第三轮：学问题2
