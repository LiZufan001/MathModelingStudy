# 2023 CUMCM C题学习入口｜蔬菜类商品的自动定价与补货决策

> 目标：不是把这道题记成“Prophet + 模拟退火 + 遗传算法”，而是训练一种更重要的决策建模能力：**当需求会被价格改变、价格又由我们决定时，预测和优化不能割裂；当真实需求不可直接观测时，还要先分清“销量”和“需求”。**

## 先记住三句话

1. **销量不是天然等于需求。** 缺货、是否上架、折扣、价格和供应都会改变我们看到的销量。
2. **价格不是预测模型的普通输入，而是决策变量。** 你改价格，需求预测本身也会变，所以“先预测销量、再优化价格”往往不闭环。
3. **评价最终应该落在决策收益上，而不只是预测误差上。** RMSE 更低不一定意味着补货和定价赚得更多。

## 一句话记忆

> **先把“时间/季节造成的自然需求”与“价格造成的需求变化”分开，再把价格、随机需求和补货量放回同一个利润模型；品类层解决总量，单品层再加商品组合和陈列约束。**
