# 01｜从题目到模型：不看国一，自己重新做一遍

## 0. 先把四问看成一条递进链

2023 B 题表面上有四问，实际上只在逐步增加两个东西：**空间维度**和**海底复杂度**。

| 问题 | 海底 | 主要未知 | 本质 |
|---|---|---|---|
| Q1 | 二维斜坡截面 | 覆盖宽度、重叠率 | 几何评价器 |
| Q2 | 三维坡面 | 航向改变后覆盖宽度 | 3D → 2D 降维 |
| Q3 | 已知规则坡面 | 测线方向、测线间距 | 结构化覆盖优化 |
| Q4 | 不规则实测地形 | 分区、局部方向、全局测线 | 局部近似 + 全局验收 |

所以比赛现场最不该做的是一上来就用遗传算法、模拟退火搜索一堆测线坐标。正确顺序应该是：

> **先回答“一条测线到底能覆盖哪里”，再回答“怎样用尽量少的测线把区域盖住”。**

如果第一层覆盖几何不可靠，后面的“最优”只是把错误算得更快。

# 1. 建模前先统一坐标和对象

## 1.1 三种方向不要混

这题最容易混淆的是三个方向：

1. **坡度最大方向**：水深变化最快的水平方向，也是海底法向在水平面的投影方向；
2. **等深线方向**：与坡度最大方向垂直，沿这个方向走，理想平面海底上的水深不变；
3. **测线方向**：船真正航行的方向。

题目中的 `β` 是“测线方向”和“坡面法向的水平投影”之间的夹角。

还有一个第四方向非常关键：

4. **横向扫测方向（cross-track）**：多波束扇面所在的竖直平面在水平面的方向，它与测线方向垂直。

多波束的覆盖宽度不是沿船头方向展开，而是沿横向扫测方向展开。

## 1.2 记号

设：

- 换能器总开角：`θ`；
- 半开角：`γ = θ/2`；
- 海底坡度：`α`；
- 海域中心深度：`H0`；
- 船相对中心的距离：`L`；
- 测线方向与坡面法向水平投影夹角：`β`；
- 当前船下方垂直水深：`D`；
- 横向截面中海底相对水平面的有效倾角：`δ`；
- 左右半幅：`W_L, W_R`；
- 总覆盖宽度：`W = W_L + W_R`。

这里最有用的抽象不是某个具体公式，而是函数：

```text
Coverage(position, heading, local_seabed) -> (left_edge, right_edge)
```

这就是后面所有优化的“评价器”。

# 2. Q1：先把二维斜坡的覆盖几何做对

Q1 已经把三维问题切成了一个与测线垂直的竖直平面。在这个平面里，只剩下：

- 海面是一条水平线；
- 海底是一条倾角为 `α` 的斜线；
- 换能器向竖直方向两侧各张开 `γ`；
- 两条边缘波束与海底相交，决定左右覆盖端点。

## 2.1 为什么左右半幅不相等

平地时左右完全对称：

`W_L = W_R = D tan γ`

但斜坡上，一侧波束朝深水区打，另一侧朝浅水区打，所以交点距离不同。用正弦定理可以得到斜坡截面上的两个半幅：

`W_L = D sin γ / cos(γ + α)`

`W_R = D sin γ / cos(γ - α)`

因此

`W = D sin γ [1/cos(γ+α) + 1/cos(γ-α)]`

当 `α=0` 时，退化为

`W = 2D tan γ`

这是必须做的第一个自检。

> 注意：不同坐标朝向会交换 `+α` 和 `-α` 分别对应哪一侧，但总宽度不变。比赛论文里一定要先画图再定符号，不要只背公式。

## 2.2 水深随位置变化

如果沿坡度方向取有符号距离 `x`，平面海底意味着水深是一次函数：

`D(x) = H0 + x tan α`

正负号由“x 朝深水还是浅水”决定。

所以 Q1 表格的计算链非常直接：

`位置 x → D(x) → W_L(x), W_R(x) → W(x)`

## 2.3 斜坡上不能机械使用 `η = 1-d/W`

题目给出的

`η = 1 - d/W`

明确是“测线平行 + 海底平坦”的定义。斜坡上相邻两条线的：

- 水深不同；
- 左右半幅不同；
- 两条带的总宽度也不同。

所以更稳妥的做法，是**先算两条测线实际覆盖端点，再从几何交叠定义重叠率**。

设第 `i` 条线的覆盖区间（沿横向坐标）为

`I_i = [a_i, b_i]`

第 `i+1` 条为

`I_{i+1} = [a_{i+1}, b_{i+1}]`

实际重叠宽度：

`O_i = max(0, min(b_i,b_{i+1}) - max(a_i,a_{i+1}))`

随后再选定分母。为了与平地定义兼容，一个自然推广是用“相邻两条带朝向彼此的两侧半幅之和”归一化：

`η_i = O_i / (R_i + L_{i+1})`

其中 `R_i` 是第 i 条朝向下一条的半幅，`L_{i+1}` 是第 i+1 条朝向上一条的半幅。

这个定义在平地、相同宽度时会退化成 `1-d/W`。

**比背一条重叠率公式更重要的是：先定义覆盖端点，重叠自然就出来。**

# 3. Q2：真正漂亮的地方是把三维问题再压回二维

Q2 多了航向角 `β`。最直接的暴力方法是写三维直线和三维平面的交点，但其实可以先做一次几何降维。

## 3.1 坡面用梯度描述

把理想海底写成平面：

`z = ax + by + c`

其水平梯度为

`g = (a,b)`

它指向水深变化最快的方向。

测线水平单位方向记作

`u = (cos ψ, sin ψ)`

横向扫测方向就是旋转 90°：

`v = (-sin ψ, cos ψ)`

那么：

- `g·u` 决定**沿测线走时水深变化多快**；
- `g·v` 决定**横向扫测截面里看到多大的坡度**。

这两个点积几乎已经把 Q2 讲完了。

## 3.2 当前水深

如果题目用 `β` 表示测线方向与坡度最大方向的夹角，那么沿测线方向的坡度分量与 `cos β` 成正比，所以当前深度可写成论文中的形式：

`D = H0 + L tan α cos β`

符号仍取决于 L 的正方向。

几个边界情况：

- `β=90°/270°`：测线沿等深线，`cosβ=0`，沿线水深不变；
- `β=0°/180°`：测线沿最大坡降方向，沿线水深变化最大。

这是第二个强自检。

## 3.3 横向截面的有效坡度 δ

多波束扇面在**垂直于测线的竖直平面**内，因此真正进入覆盖宽度公式的，不一定是原始坡度 `α`，而是海底在这个横截面里的有效坡度 `δ`。

通过平面法向量和横截面方向可以得到：

`δ = arcsin[ sinβ sinα / sqrt(cos²β cos²α + sin²β) ]`

于是 Q2 可以被理解成一句话：

> **先把三维坡面投影到横向竖直截面，求有效坡度 δ，再完全复用 Q1 的二维公式。**

覆盖宽度：

`W = D sinγ / cos(γ+δ) + D sinγ / cos(γ-δ)`

其中 `γ=θ/2`。

### 再做两个边界自检

- `β=0°/180°`：`sinβ=0 → δ=0`。此时横向扫测方向平行等深线，横截面看起来是平的；
- `β=90°/270°`：`|δ|=α`。此时船沿等深线走，横向截面正好切过完整坡度。

这两个边界和上一节关于“沿线水深变化”的结论互补，非常适合用来检查代码里的 β 到底定义对没有。

# 4. 实现时我更推荐“射线—平面求交”，而不是堆三角公式

论文需要给解析式，但写程序时可以用更统一的向量做法。

设：

- 船位置 `S=(x0,y0,z0)`；
- 海底局部平面 `n·X+c=0`；
- 左/右边缘波束单位方向分别为 `q_-`、`q_+`。

边缘波束：

`X(t)=S+tq`

代入平面：

`t = -(n·S+c)/(n·q)`

只要 `t>0`，交点就是有效海底交点。

分别求左右交点 `P_-`,`P_+`，覆盖宽度直接为

`W = ||P_+ - P_-||`

或按你选择的水平投影 / 海底投影口径计算。

### 为什么这个实现值得记

1. Q1、Q2 同一套代码；
2. 不容易写错 `+α/-α`；
3. 后面 Q4 每个局部平面仍然能直接用；
4. 如果将来题目改成任意航向、任意局部法向量，不需要重新推一套三角式。

比赛论文可以给闭式公式，程序内部用向量求交；两条路线互相校验，反而更稳。

# 5. Q3：把二维“布线优化”降成一维“区间覆盖”

题目给的是规则矩形海域：

- 南北 2 海里；
- 东西 4 海里；
- 西深东浅；
- 坡度 1.5°；
- 开角 120°；
- 要求完全覆盖；
- 相邻重叠率 10%～20%；
- 总测量长度最短。

## 5.1 先决定方向：为什么应沿等深线

这个海底是“西深东浅”的单一坡面，所以等深线为**南北方向**。

直觉上，船沿等深线走有两个优点：

1. 一条测线内部水深保持不变，整条线的覆盖宽度稳定；
2. 横向扫测方向正好沿东西坡向，充分利用两侧波束的覆盖能力。

更形式化地说：对同样长度的一段测线，如果它斜着穿过深浅变化方向，那么沿线不同位置的覆盖宽度会变化；用一个等长、过同一中点且平行等深线的测线比较，可以证明后者的单位航程覆盖面积不小。

不过要注意：**“单条等长线覆盖面积最大”与“整个有限矩形区域的全局最短路线”之间还差边界与拼接论证**。比赛里最好补一句：在本题矩形边界、平行测线和固定重叠约束下，方向确定后每条线长度都固定为 2 海里，因此总长度只由测线条数决定；这才把局部覆盖优势接到全局目标上。

## 5.2 方向确定后，优化变量只剩横向位置

设第 i 条南北向测线距东侧边界的横坐标为 `x_i`。

因为每条线都贯穿南北边界，所以每条测线长度固定：

`ℓ = 2 NM = 3704 m`

总长度：

`L_total = n × 3704`

于是“最短总长度”完全等价于：

> **用最少的测线条数 n 覆盖东西方向 4 海里的宽度。**

这一步是本题最重要的降维。

## 5.3 每条测线就是一个一维覆盖区间

对于位置 `x_i`，先算该处水深，再算朝浅水侧和深水侧半幅：

`I_i = [x_i - L(x_i), x_i + R(x_i)]`

所以 Q3 被重写成：

> 在 `[0,4NM]` 上放置尽可能少的区间 `I_i`，要求无空洞，而且相邻区间重叠率在 10%～20%。

这已经不是“海洋测绘专属题”了，而是非常经典的**单调区间覆盖问题**。

## 5.4 为什么下一条应该放到“允许的最远位置”

若目标是测线最少，重叠越大一般越浪费覆盖能力。因此在满足安全约束的前提下，应取最低允许重叠：

`η = 10%`

然后从浅水侧开始：

1. 第一条线放到它的浅水侧覆盖边缘刚好碰到东边界；
2. 已知第 i 条线后，把第 i+1 条尽量向西（更深处）推；
3. 推到相邻条带的重叠率恰好为 10%；
4. 直到最后一条的深水侧覆盖边缘超过西边界。

这就是一个贪心算法。

### 为什么贪心在这里成立

关键是状态只需要记录“目前最西侧已经覆盖到哪里”。在这个规则坡面里：

- 水深随向西单调增加；
- 覆盖尺度随水深单调增大；
- 把下一条线放得更远，只会让新的覆盖前沿更远，不会破坏已经覆盖的区域，只要最低重叠仍满足。

所以任何把第 i+1 条放得更靠东的方案，都不会比“刚好 10% 重叠”的位置更有利于减少后续测线数量。

这比直接说“我们递推，所以最优”更有解释力。

## 5.5 一个可直接编程的求解框架

```text
input: width=4NM, D_min, slope α, beam θ, eta_min=0.10

x = first_line_touching_shallow_boundary()
lines = [x]

while deep_edge(x) < 4NM:
    solve x_next such that overlap(x, x_next) = eta_min
    assert x_next > x
    assert 0.10 <= overlap <= 0.20
    lines.append(x_next)
    x = x_next

return lines, total_length = len(lines)*2NM
```

如果重叠率方程没有方便的闭式解，用一维二分 / Brent 求根即可，不需要任何智能优化算法。

## 5.6 与现有获奖论文结果做独立量级核对

南京邮电大学赛后发表版给出的结构化方案最终是 34 条测线；每条按 2 海里计算，因此：

`34 × 3704 = 125936 m`

这个乘法恰好等于论文给出的总长度，可以作为方向和单位的强一致性校验。

它的测线位置从浅水侧向深水侧间距逐渐增大，这也符合：

`深度 ↑ → 覆盖宽度 ↑ → 允许测线间距 ↑`

的物理直觉。

# 6. Q4：真正难点是“复杂地形如何变成可规划的局部模型”

Q4 的附件不是一个抽象曲面公式，而是一张规则深度网格。

从附件坐标可见：

- 东西方向 0～4 海里，步长约 0.02 海里，共 201 个采样位置；
- 南北方向 0～5 海里，步长约 0.02 海里，共 251 个采样位置；
- 对应约 `201×251=50451` 个深度格点。

这意味着你手里已经有一个二维标量场：

`D = D(x,y)`

Q4 的任务可以理解为：

> **在一个已知深度场上规划若干路径，使这些路径诱导出的多波束覆盖条带尽量覆盖整个区域，同时减少过度重叠和总航程。**

## 6.1 第一步不是优化，而是看地形

至少画：

1. 三维曲面图；
2. 等深线图；
3. 梯度模长 `||∇D||`；
4. 梯度方向 / 等深线方向图。

其中：

- `∇D` 指向最陡方向；
- 等深线方向与 `∇D` 垂直；
- `||∇D||` 反映局部坡度大小。

如果地形处处近似同一坡面，那 Q3 直接可用；如果梯度方向不断变化，才需要分区。

# 7. 一个比赛中更可复现的 Q4：自适应平面分区

“看等深线，手工切成几块”很直观，但复现性差。更稳的办法是把“局部可视作平面”变成明确的判据。

## 7.1 局部平面拟合

对一个候选区域 R，用所有网格点拟合

`D(x,y) ≈ Ax + By + C`

最小化：

`SSE = Σ_{(i,j)∈R} [D_ij-(Ax_i+By_j+C)]²`

并计算：

- RMSE；
- 最大绝对残差；
- 拟合平面的坡度；
- 区域内实际梯度方向的离散程度。

## 7.2 不合格就继续切：四叉树（quadtree）

算法：

```text
fit(region):
    plane = least_squares(region)
    error = RMSE / max_abs_error / gradient_variation

    if error <= threshold:
        accept region
    else:
        split region into 4 children
        fit(each child)
```

这和“拟合不好就继续分区”的思想完全一致，但优点是：

- 阈值明确；
- 过程可复现；
- 不依赖选手肉眼；
- 可以做阈值敏感性分析；
- 很容易在论文中解释。

若四叉树矩形边界过于僵硬，还可以用基于梯度方向相似度的 region growing / 聚类，但比赛三天里四叉树通常更稳。

## 7.3 每个子区内复用 Q3

每个通过验收的小区域都有局部平面：

`D=Ax+By+C`

局部坡向：

`g=(A,B)`

局部等深线方向：

`u_contour ∝ (-B,A)`

于是每个区域：

1. 测线优先平行局部等深线；
2. 用局部坡度算覆盖宽度；
3. 用最低合理重叠率生成线间距；
4. 把无限直线裁剪到该子区域边界，得到真正航段。

这形成非常清晰的模块复用：

`原始网格 → 分区 → 每区平面 → 每区 Q3 → 合并测线`

# 8. Q4 不能停在“画出测线”：必须回原始地形做全局验收

这是很多数模论文最容易漏的一步。

你用于规划的是“局部平面近似”，但官方指标要求评价**真实附件地形上的最终方案**。因此合并所有测线后，要回到原始网格上重新模拟。

## 8.1 覆盖栅格

对每条最终测线沿航迹采样，在每个采样点：

1. 从原始深度场插值得到局部深度；
2. 用原始场梯度或局部拟合得到法向；
3. 计算左右覆盖边界；
4. 把覆盖条带 rasterize 到高分辨率栅格 / 多边形集合。

累计每个格点被覆盖次数 `c(x,y)`。

## 8.2 官方三个指标一口气得到

### 指标 1：总测线长度

`L = Σ length(line_i)`

### 指标 2：漏测面积百分比

`miss_rate = area(c=0) / total_area × 100%`

### 指标 3：重叠率超过 20% 部分的总长度

这个指标要先明确你的工程定义。一个可操作做法是：沿每对相邻测线做密集采样，计算局部横截面上的实际重叠率 `η(s)`，然后积分 / 累加：

`L_over = Σ Δs · I[η(s)>0.20]`

这比只看“区域内平均重叠率”更贴合题目中的“总长度”。

# 9. Q4 是多目标，但不要急着乱加权

题目语言有明显优先级：

1. 尽可能覆盖整个海域；
2. 重叠率尽量控制在 20% 以下；
3. 总长度尽可能短。

如果直接写

`J = L + λ1·miss + λ2·overlap`

就会遇到“λ 为什么这么取”的问题。

更好的比赛表达是**字典序优化（lexicographic optimization）**：

1. 第一层：先把漏测面积压到可接受阈值（最好 0 或极小）；
2. 第二层：在满足覆盖的方案中，减少过度重叠；
3. 第三层：再比较总长度。

如果确实要加权，也应做参数敏感性，证明不同合理权重下主要方案不发生剧烈改变。

# 10. 一个我更愿意在比赛里真正实现的完整方案

## 模块 A｜几何核心

实现两个版本并交叉验证：

- 闭式三角公式；
- 射线—局部平面求交。

自检：

- `α=0 → W=2Dtan(θ/2)`；
- 航向旋转 180°，总覆盖宽度应保持一致；
- 深度翻倍，固定坡度下覆盖宽度应近似同比翻倍。

## 模块 B｜Q1 / Q2 表格

严格按题目给定坐标和 β 计算，输出 Excel；不要手工复制表格结果。

## 模块 C｜Q3 结构化贪心

- 方向固定为南北；
- 从东侧浅水边界开始；
- 每条下一线用一维求根求 `η=0.10` 的最远可行位置；
- 最后一线覆盖到西边界；
- 验证每对邻线的 η 都落在 [0.10,0.20]。

## 模块 D｜Q4 自适应分区

- 平滑深度场（只在有明显噪声时）；
- 四叉树局部平面拟合；
- 每个叶节点生成局部测线；
- 边界处做拼接 / 去重；
- 回原始网格做覆盖仿真。

## 模块 E｜全局验收

最终只认可“验收器”算出来的：

- 总长度；
- 漏测面积率；
- `η>20%` 的总航段长度。

分区图漂亮不等于最终方案合格。

# 11. 这道题最值得训练的 8 个条件反射

### 反射 1：看到“覆盖宽度随位置变化”

不要用一个全局平均 W，先建立 `W(position, heading)`。

### 反射 2：看到“三维方向角”

先问能不能投影到“与运动方向垂直的竖直截面”，把 3D 变回 2D。

### 反射 3：看到“路径总长度最小 + 平行测线”

先看能否把每条线长度固定，从而把目标降成“最少条数”。

### 反射 4：看到“10%～20% 重叠”

若目标是少线，优先检查最低重叠率是不是最优边界，而不是把 η 当一个连续变量交给遗传算法。

### 反射 5：看到“规则坡面”

想到“每条线 = 一维覆盖区间”，用区间覆盖 / 贪心，而不是二维黑箱优化。

### 反射 6：看到“复杂曲面 + 局部近似”

想到：局部平面、局部线性化、分区、四叉树、region growing。

### 反射 7：看到“拟合不好就再分”

必须问：**不好是多少？阈值是什么？** 没有定量阈值的方法很难复现。

### 反射 8：看到“用近似模型规划”

最后必须回到原始数据上做独立验收，不能用同一个近似模型既出方案又证明自己正确。

# 12. 最后的模型记忆

以后再遇到无人机扫地、传感器扫描、雷达覆盖、喷洒路线、相机航带、机器人巡检等题，可以把这题压缩成下面四行：

```text
1. 建立局部覆盖算子 C(x, direction, environment)
2. 利用结构把路径规划降维（常见是区间覆盖）
3. 复杂环境做局部近似 / 自适应分区
4. 在原始环境上独立计算覆盖、重叠和总成本
```

真正可迁移的不是多波束公式，而是这套**评价器 → 降维 → 规划 → 验收**的建模顺序。
