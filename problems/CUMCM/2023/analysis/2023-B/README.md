# 2023 CUMCM B题学习入口｜多波束测线问题

> 目标不是记住一套多波束公式，而是训练一条很通用的数模链路：**先把几何关系变成可靠的“位置/方向 → 覆盖宽度”评价器，再把二维布线问题降成一维覆盖问题；面对复杂地形，再做局部近似、分区和全局验收。**

## 推荐阅读顺序

1. [01｜从题目到模型：不看国一，自己重新做一遍](01-problem-from-scratch.md)
   - 从官方四问逐层搭模型。
   - 重点训练：斜坡几何、向量降维、覆盖宽度、重叠率、区间覆盖、贪心递推、规则网格地形处理。
   - 单独给出一个比“手工分区”更可复现的 Q4 改进方案。

2. [02｜国一 / 数模之星论文深度拆解](02-national-first-paper-deep-dive.md)
   - 忠实还原南京邮电大学团队赛后发表论文《基于区域划分的多波束测线布设》的核心路线。
   - 分析它为什么有效、为什么适合比赛，以及哪些“最优”表述需要更谨慎。
   - 特别审计：Q3 方向表述前后矛盾、Q4 人工分区与残差阈值未明确、期刊版没有给出赛题要求的两个 Q4 验收指标。

3. [03｜迁移手册：覆盖规划、局部线性化与自适应分区](03-transferable-playbook.md)
   - 把本题抽象成“空间场 + 局部覆盖算子 + 路径规划”的通用题型。
   - 给出比赛现场识别信号、建模骨架、算法选择、自检清单和论文写法。

## 先记住三句话

1. **多波束的核心不是“算一个 W”，而是建立一个局部覆盖算子：给定位置、深度、坡度和航向，就知道这一条测线向两侧能覆盖到哪里。**
2. **一旦测线方向确定，Q3 本质上不是二维路径规划，而是沿坡向的一维区间覆盖：每条线生成一个覆盖区间，下一条线放到“刚好满足最低重叠”的最远位置。**
3. **Q4 真正困难的不是再套一次最小二乘，而是决定“哪里可以当作一个平面”、如何自动分区，以及最后有没有在原始地形上重新验证漏测和过度重叠。**

这三层分别对应：**几何评价器 → 结构化规划 → 复杂地形近似与验收**。
