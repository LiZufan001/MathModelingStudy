# 03｜迁移手册：覆盖规划、局部线性化与自适应分区

这份手册不再讨论“海洋测深”本身，而是把 2023 B 抽象成以后可以直接识别的数模套路。

---

# 1. 先给这类题一个统一名字

可以把它叫作：

> **空间场上的带状覆盖路径规划（strip-coverage path planning on a spatial field）**

常见变体包括：

- 无人机航测航带；
- 雷达 / 声呐扫描；
- 农药喷洒路线；
- 扫地机器人覆盖；
- 巡检机器人传感器覆盖；
- 相机视场路径规划；
- 机械臂扫描；
- 医学 / 工业成像的扫描轨迹；
- 森林、海洋、矿区采样带设计。

共同结构都是：

```text
环境位置不同
   ↓
单条路径的“有效覆盖宽度”不同
   ↓
路径之间既不能漏，也不能重复太多
   ↓
还想让总路径成本尽量小
```

一旦看出这个结构，就不应该先搜索“多波束公式”，而应该先建立一个通用覆盖模型。

---

# 2. 第一原则：先做覆盖评价器，再做优化器

任何覆盖规划题，第一问都应该是：

> 给定一条候选路径，它到底覆盖了哪一块区域？

定义一个局部评价器：

`C(x, u, e) -> footprint`

其中：

- `x`：传感器 / 载体位置；
- `u`：运动方向；
- `e`：局部环境参数；
- `footprint`：该位置对应的覆盖截面 / 区间 / 多边形。

多波束题里：

`e = {depth, seabed normal, beam angle}`。

无人机相机里可能是：

`e = {terrain height, camera FOV, pose}`。

喷洒问题里可能是：

`e = {wind, height, nozzle spread}`。

## 为什么一定要先做评价器

因为“优化算法”只会根据你的目标函数寻找最优输入。

如果覆盖评价器错了：

- PSO 会找到“最优错误方案”；
- GA 会找到“最优错误方案”；
- 模拟退火也一样。

**优化算法不能替你修正物理模型。**

---

# 3. 第二原则：先找“自然截面”，空间问题经常能降一维

2023 B 最漂亮的结构之一，是三维坡面 + 航向最终可以落到“与测线垂直的竖直截面”。

通用判断：

> 如果一个传感器的作用方向天然垂直于运动方向，就优先研究垂直于轨迹的截面。

例如：

- 多波束声呐：横向扇面；
- 航测相机：横向视场；
- 喷洒杆：横向喷幅；
- 道路清扫：刷盘横向工作宽度。

### 向量版口诀

环境标量场 `z=f(x,y)` 的局部梯度：

`g=∇f`

轨迹单位方向：

`u`

横向单位方向：

`v=R_90°u`

那么：

- `g·u`：沿轨迹的环境变化；
- `g·v`：横向截面里的环境变化。

大量“方向角公式”本质上就是这两个点积。

---

# 4. 第三原则：覆盖宽度最好拆成左右半幅

在非对称环境里，不要只保存一个 `W`。

保存：

`L(x,u)`：左半幅

`R(x,u)`：右半幅

路径位置 `x_i` 对应的一维覆盖区间：

`I_i=[x_i-L_i, x_i+R_i]`

这样自然可以计算：

- 是否漏测；
- 重叠多少；
- 哪一侧先碰边界；
- 下一条路径应该放在哪里。

这是从多波束题迁移出去后非常实用的数据结构。

---

# 5. 重叠率不要背公式：先求交集

平坦、等宽条带：

`η=1-d/W`

只是一个特例。

更一般地：

`I_i=[a_i,b_i]`

`I_j=[a_j,b_j]`

交叠宽度：

`O=max(0, min(b_i,b_j)-max(a_i,a_j))`

然后根据工程语义选归一化分母。

### 选择定义时要做的三项检查

1. **量纲正确**：分子分母都应是长度 / 面积等同类量；
2. **退化正确**：回到平地等宽情形应退化成题设公式；
3. **物理可解释**：为什么这个分母能代表“可重叠的有效宽度”。

很多比赛论文的问题不是公式算错，而是把不同几何尺度混在同一个 η 里。

---

# 6. 第四原则：方向一旦固定，先问能不能变成区间覆盖

2023 B Q3 的关键不是“递推公式很长”，而是：

> 固定航向后，每条测线只是横轴上的一个覆盖区间。

这类问题的标准形式：

```text
目标区间：[A,B]
候选位置：x
覆盖区间：I(x)=[l(x),r(x)]
约束：相邻区间至少有规定重叠
目标：使用最少区间 / 最短总路径
```

如果 `r(x)` 随 x 单调，而且下一步只依赖当前覆盖前沿，就应该优先想到**贪心**。

---

# 7. 贪心的通用证明模板

设已经覆盖到前沿 `F`。

从所有满足：

- 不产生空隙；
- 最低重叠约束成立

的下一条路径中，选择使新覆盖前沿 `F'` 最大的一条。

证明思路：交换论证。

若某个所谓最优方案第一步选择了一个更靠后的前沿 `F_alt ≤ F_greedy`，把它替换成 greedy 的第一步：

- 已覆盖区域不会减少；
- 后续所有原可行路径仍可继续或更容易安排；
- 路径条数不增加。

因此存在一个最优方案以 greedy 第一步开始；递归得到全局最优。

## 使用这个证明前必须检查

- 覆盖端点是否单调；
- 把线推远会不会让另一侧出现新空洞；
- 后续可行性是否只依赖当前前沿；
- 是否有转弯成本、禁区等额外全局耦合。

有这些额外因素时，贪心未必成立。

---

# 8. 第五原则：复杂曲面先局部线性化

只要环境场足够光滑：

`f(x+Δx,y+Δy) ≈ f0 + f_x Δx + f_y Δy`

这就是局部平面。

因此看到：

- 地形；
- 温度场；
- 浓度场；
- 风场局部分量；
- 曲面高度；

都可以问：

> “在一个足够小的区域内，能不能把它近似成一阶模型？”

这通常比直接拟合一个全局高阶多项式更稳定、更可解释。

---

# 9. “分区”不是一个模型，停止分区的规则才是模型

最危险的写法：

> “根据图像，将区域划分为若干部分。”

这句话几乎不可复现。

更好的写法：

> 对每个候选区域拟合局部模型；若误差指标超过阈值则继续细分，直到所有叶区域满足精度要求。

## 常用停止指标

### 拟合 RMSE

`RMSE=sqrt(SSE/n)`

### 最大绝对残差

`E_max=max|z_i-z_hat_i|`

适合防止局部尖峰被平均误差掩盖。

### 相对误差

`E_rel=RMSE/(max z-min z)`

便于不同深度区域统一阈值。

### 梯度方向离散度

如果一个块内坡向变化太大，即使平面 RMSE 尚可，也可能不适合用一套统一测线方向。

可统计局部梯度方向的圆方差 / 最大夹角。

# 10. 四叉树：比赛里非常实用的自适应分区模板

适用于规则二维网格。

```text
function split(region):
    model = fit_plane(region)
    score = evaluate_fit(region, model)

    if score <= threshold or region too small:
        return leaf(region, model)

    children = divide_into_4(region)
    return [split(c) for c in children]
```

优点：

- 实现快；
- 天然适配 Excel 规则网格；
- 图容易画；
- 解释清楚；
- 可以做阈值敏感性分析。

缺点：

- 矩形边界可能切断自然地形结构；
- 相邻叶块尺度可能差异很大；
- 需要处理边界测线拼接。

如果有更多时间，可以改成 region growing / 图分割 / 聚类，但不要为了“高级”牺牲可解释性。

---

# 11. 分区优化后必须做一次“原始世界验收”

这是本题最重要的迁移原则之一。

如果用近似模型 M 生成方案 S：

`original data → approximate model M → optimize → S`

不能再只用 M 验证 S：

`S → M → “很好”`

这会产生自证循环。

正确方式：

`S → original data → independent evaluation`

例如：

- 用局部平面规划航线；
- 最后在原始深度网格上重新算所有横截面；
- 统计真实漏测、真实过度重叠。

同理：

- 回归模型给策略 → 用留出数据验证；
- 简化动力学做控制 → 用高保真仿真验证；
- 聚类后设计方案 → 回到原始样本检验。

# 12. 多目标题先读语义优先级，再决定数学形式

题目说：

“尽可能 A；B 尽量小；C 尽可能短”

通常有三种建模方式。

## 方式 A｜硬约束 + 单目标

例如：

`min total_length`

subject to

`miss_rate ≤ ε`

`overlap ≤ 20%`。

最易解释。

## 方式 B｜字典序优化

按优先级：

1. 先最小漏测；
2. 在最优漏测集合内最小过度重叠；
3. 再最小长度。

题面有明显优先级时非常合适。

## 方式 C｜加权和

`J=w1·miss+w2·overlap+w3·length`

灵活，但必须解释权重，并做敏感性分析。

### 比赛默认建议

如果没有业务给出的货币化权重，优先用 A 或 B，不要凭感觉给 `w1=0.4,w2=0.3,w3=0.3`。

# 13. 什么时候该用解析式、求根、动态规划、智能算法

## 解析递推

适合：

- 规则地形；
- 单调；
- 约束可直接取边界；
- 有明确几何关系。

2023 B Q3 就属于这里。

## 一维求根 / 二分 / Brent

适合：

- “下一条线放在哪里使重叠率恰好 10%”；
- 公式有，但解不方便显式写。

不要因为无法手算闭式就上 PSO。

## 动态规划

适合：

- 状态离散；
- 路径选择具有阶段性；
- 当前决策影响有限后续状态；
- 有转弯成本 / 多候选方向。

## 图最短路 / TSP

适合：

- 各条扫描线已经生成；
- 还要优化“以什么顺序走这些线”；
- 转场成本不可忽略。

这其实是覆盖规划的第二层问题：先决定“哪些扫描线”，再决定“怎么串起来”。

## GA / PSO / SA

适合：

- 决策维度有限但非凸；
- 没有明显单调结构；
- 评价器可快速运行；
- 解析 / 贪心 / 凸优化都不方便。

**不是“题目有最优”就用智能优化。**

```text

```

这种模块化比把全部逻辑写在一个 `main.m` 里更容易排错。

# 15. 数值实现的强制自检清单

## 几何不变量

- 平地：`W=2Dtan(θ/2)`；
- 深度翻倍：固定角度时 W 同比增大；
- 航向反转 180°：总覆盖宽度不变；
- 左右半幅交换时总宽度不变；
- 所有射线交点参数 `t>0`。

## Q3

- 每条线都在海域内或有合理边界超覆；
- 相邻 `η∈[0.10,0.20]`；
- 覆盖区间并集无空洞；
- 最后一条确实越过远端边界；
- `总长度 = 线数 × 单线长度` 的单位一致。

## Q4

- 每个叶区域拟合误差有记录；
- 分区之间无未处理缝隙；
- 合并后重新在原始网格评价；
- 漏测率按面积，不按“漏测格点数量”直接冒充面积（规则等面积格点才可等价）；
- >20% 重叠“总长度”的积分步长足够细；
- 改变采样步长后指标基本稳定。

# 16. 结果图应该画什么才真正有用

最有信息量的图不是“算法流程图”，而是：

1. **原始深度等高线 + 最终测线**；
2. **局部坡向矢量 / 等深线方向**；
3. **自适应分区边界 + 每块拟合误差**；
4. **覆盖次数热力图**：0=漏测，1=正常，2+=重叠；
5. **沿测线位置的重叠率曲线**，画出 20% 阈值；
6. **阈值敏感性图**：分区误差阈值 vs 总长度 / 漏测率 / 区块数。

这几张图能直接回答“方案为什么可信”。

# 17. 常见失败模式

## 失败 1｜全海域用平均水深

后果：浅处漏，深处重叠过多。

本质：把空间非均匀性抹掉了。

## 失败 2｜一上来全局拟合高阶多项式

问题：

- 高阶模型可能振荡；
- 难从系数看局部坡向；
- 布线仍需要局部信息。

## 失败 3｜人工切区但不给标准

结果很好也很难复现。

## 失败 4｜分区后各算各的，不做边界验收

可能在区域接缝漏测或重复。

## 失败 5｜只最小化总长度

最短方案可能直接留大面积空白。

## 失败 6｜只报“覆盖率 100%”

还要回答：重叠是不是离谱？路径是不是太长？边界有没有超出？

## 失败 7｜智能算法参数很多，基础几何没验证

最危险，因为结果看起来最“高级”。

# 18. 比赛现场前 90 分钟思考模板

## 0～15 分钟：抽象

写出：

```text
环境：D(x,y)
决策：路径位置 + 方向
局部作用：footprint(x,u)
约束：覆盖 / 重叠 / 边界
目标：长度
```

## 15～35 分钟：只做一条线

- 画横截面；
- 推左右覆盖边缘；
- 验证平地退化；
- 写函数计算。

## 35～50 分钟：寻找结构

问：

- 哪个方向可能天然最优？
- 固定方向后能否降成一维？
- 最低重叠是不是目标边界？
- 能否用贪心？

## 50～70 分钟：处理复杂地形

- 画等深线；
- 算梯度；
- 判断是否需要分区；
- 设计定量分区标准。

## 70～90 分钟：先做验收器

在真正优化 Q4 前先写：

`evaluate(lines) -> length, miss_rate, excessive_overlap`

这样之后不管你用什么算法，都有统一评分标准。

# 19. 论文表达模板

遇到类似题，可以用这样的章节逻辑：

```text
1. 局部覆盖几何模型
   1.1 坐标系与局部环境
   1.2 覆盖边界推导
   1.3 重叠率定义与退化验证

2. 规则环境下的结构化路径规划
   2.1 最优方向分析
   2.2 一维覆盖等价转化
   2.3 贪心/递推算法及最优性说明

3. 非规则环境下的局部近似
   3.1 数据可视化与梯度
   3.2 自适应分区
   3.3 局部模型与路径生成

4. 全局方案验收
   4.1 覆盖率
   4.2 过度重叠
   4.3 总长度
   4.4 敏感性与稳健性
```

这比“问题一模型、问题二模型、问题三遗传算法……”更能体现模型体系。

# 20. 最后压缩成一个长期记忆

以后只要看到“在变化环境里用若干条路径覆盖一个区域”，先在脑子里出现这条链：

> **局部作用范围 → 左右边界 → 区间/条带 → 最优方向 → 贪心覆盖 → 局部线性化 → 自适应分区 → 原始数据全局验收。**

2023 B 的专业名词是“多波束测线”，但它真正教的是一种更普遍的能力：

**把复杂空间规划拆成一个可信的局部几何模型，再利用结构逐层降维，而不是让优化器替你理解问题。**
