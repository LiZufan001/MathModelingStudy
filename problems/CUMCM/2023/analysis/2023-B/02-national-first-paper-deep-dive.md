# 1. 一句话概括这篇论文的核心贡献

这篇论文真正强的不是某个三角公式，而是把四问压成了两层模型：

> **先建立“任意坡面 + 任意测线方向”的通用覆盖几何；再证明规则坡面上应沿等深线布设并推导测线位置递推式；最后把不规则海底切成若干近似坡面，反复复用前面的规则模型。**

也就是：

```text
通用局部几何
   ↓
规则坡面布线
   ↓
复杂海底 ≈ 多个局部坡面
   ↓
逐区复用规则模型
```

这是非常典型、也非常值得学的“**先解决基本单元，再拼复杂系统**”。

# 2. 论文结构为什么比照着四问逐题写更成熟

官方题目是 Q1、Q2、Q3、Q4 四问，但赛后论文没有机械按“四问”组织，而是：

1. 多波束覆盖宽度与重叠率模型；
2. 具体坡面海域测线布设；
3. 不规则海域测线布设；
4. 结论。

这相当于把 Q1+Q2 合并成“基础几何”，Q3 变成“规则海域规划”，Q4 变成“复杂海域推广”。

这种写法的好处是让读者看到模型之间的继承关系，而不是四个孤立答案。

**写作上值得模仿：**如果后一问只是前一问模型的应用或推广，就按“模型层级”组织，而不是按题号重复定义。

# 3. 第一层：把 Q1/Q2 统一成一个任意航向坡面模型

## 3.1 论文不是直接套二维公式，而是先做空间向量

论文设置：

- 坡度 `α`；
- 测线方向与坡面法向水平投影夹角 `β`；
- 海域中心深度 `H0`；
- 船距中心距离 `L`。

它先写坡面法向量，再写“测线方向与水平投影形成的竖直平面”的法向量，然后通过叉乘求两个平面的交线。

由此得到当前水深：

`D = H0 + L tanα cosβ`。

接着再求横向覆盖线与水平面的有效夹角 `δ`：

`δ = arcsin[ sinβ sinα / sqrt(cos²β cos²α + sin²β) ]`。

最后把空间问题压回一个二维三角形，得覆盖宽度：

`W = D sin(θ/2)/cos(θ/2+δ) + D sin(θ/2)/cos(θ/2-δ)`。

## 3.2 这里真正值得学的是“空间问题先找正确截面”

很多人做 Q2 会直接在三维坐标里写很多点、直线和平面，最后公式极其臃肿。

这篇论文的路线更有结构：

1. 用向量确定横截面方向；
2. 求这个横截面里海底看起来有多斜；
3. 在这个截面里继续用二维正弦定理。

这是一个非常通用的数学技巧：

> **三维几何问题如果物理作用只发生在某个特定截面，就先求截面，再在截面中降维。**

## 3.3 两个极端角度可以快速检查公式

这个公式有很好的物理自检：

- `β=0°/180°`：测线沿坡度最大方向，横向扫测方向沿等深线，所以 `δ=0`；
- `β=90°/270°`：测线沿等深线，横向扫测方向切过完整坡度，所以 `|δ|=α`。

同时 `D=H0+Ltanαcosβ` 表明：

- 沿等深线走时，沿线水深不变；
- 沿坡度方向走时，水深变化最快。

两套结论彼此咬合，说明模型的方向定义是自洽的。

# 4. 论文对“重叠率”的处理是一个容易被忽略的亮点

官方题面只在平坦海底给出：

`η = 1-d/W`。

如果到了斜坡还机械套这个式子，就会忽略：相邻两条测线水深不同，左右半幅也不对称。

论文重新从相邻两个条带的实际几何重叠出发，定义：

> 重叠率 = 两条带的实际重叠宽度 / 两条带朝向彼此的半幅之和。

并推导了斜坡条件下的式（6）。

这个做法的价值不只在这道题。它说明一个数模习惯：

> **题目给出的定义如果明确依赖某个特殊前提（这里是平地），场景变化后先检查定义是否还能直接用。**

比“把公式推广得更复杂”更重要的是，作者先意识到了**原公式的分母已经失去物理意义**。

## 可以再严谨一点的地方

斜坡上的“覆盖宽度”究竟按：

- 海底斜面长度；
- 水平投影长度；
- 与航迹正交的测量坐标长度

进行定义，会影响重叠口径。

期刊论文选了一种与自身几何模型一致、且能退化到平地公式的定义，这是可行的；如果在比赛现场写，我会多加一句：

> 本文统一以与相邻测线间距相容的横向几何尺度定义重叠率，并验证当 `α=0` 时退化为题设 `1-d/W`。

这样评委更容易判断量纲与几何口径没有混乱。

# 5. 第二层：Q3 为什么能从优化问题变成递推问题

## 5.1 先证明方向，再优化间距

论文没有把“方向 + 每条线坐标”一次性交给智能算法，而是先证明：

**平行等深线的测线单位长度覆盖面积最大。**

它取：

- 任意一条等长斜测线 AB；
- 过其中心 O、平行等深线的等长测线 CD。

AB 上水深线性变化，覆盖宽度也随之变化，因此扫测区域可看成梯形；CD 上水深恒定，扫测区域为矩形。

作者把两者面积比较归结为函数 `f(α)` 的单调性，最终得到：

`S_AB ≤ S_CD`。

这个证明让后面“为什么不搜航向角”有了数学支撑。

## 5.2 证明中一个容易忽略的逻辑层级

论文证明的是：

> 对相同长度、相同中点附近的线段，等深线方向覆盖面积不小于斜向线段。

而赛题目标是：

> 在有限矩形边界和重叠约束下，让**全套测线总长度**最短。

两者非常接近，但不是逻辑上自动等价。

更完整的论证应该补：

1. 本题海底为单一平面，等深线固定为南北方向；
2. 采用南北平行线后，每条测线都贯穿 2 海里南北边界，所以单条长度固定；
3. 总长度最短等价于测线条数最少；
4. 等深线方向最大化单位长度覆盖能力，并且边界能由平行条带无缝铺设，因此不会因端点裁剪抵消这一优势。

论文的结论在本题结构下很合理，但“局部单位长度面积最大 → 整体路径全局最优”的桥梁如果写出来，会更严谨。

## 5.3 单调性推导本身基本成立，但定义域不应写得太宽

论文令 `x=cosα`，得到类似

`h(x)=x/(2x²-k)`，

并指出 h 对 x 单调递减，而 cosα 对 α 单调递减，因此复合函数随 α 增大。

在分母不为零的物理可行范围内，这个符号关系没有问题；但论文文字把 α 的讨论放得很宽。

实际多波束几何还要求边缘波束能与海底正常相交，例如 `θ/2±α` 不能进入导致余弦分母失效的区域。

所以更专业的写法应是：

> 在本题 `θ=120°、α=1.5°` 及其邻域的物理可行定义域上证明单调性。

没必要把结论扩大到所有数学角度。

# 6. Q3 最强的一步：把连续规划变成“边界贴着走”的递推

方向确定以后，论文观察到：

- 每条测线长度固定为 2 海里；
- 总长度只取决于线数；
- 若要线数最少，就应该让相邻线尽可能远；
- 因此取允许的最低重叠率，并让每一条新测线“刚好”满足重叠约束。

它先确定第一条线位置，再写：

`p_{n+1}=p_n+p_BD+p_CE-p_CD`

最后合并成式（14）的显式递推关系。

### 为什么这比遗传算法漂亮

这不是因为遗传算法一定差，而是本题已经有强结构：

- 横向水深单调；
- 覆盖宽度随位置单调；
- 一条线的最佳下一位置只取决于当前覆盖前沿。

这其实就是一个**一维单调区间覆盖的贪心问题**。

如果还能推闭式递推，当然比高维随机搜索：

- 更快；
- 更可解释；
- 更容易证明；
- 更容易检查重叠约束。

这正是国赛里“利用题目结构”比“堆算法名”更有价值的例子。

# 7. Q3 结果审计：有一个非常值得记的文字矛盾

期刊论文前一页明确说：

> 测线平行等深线方向，即**南北走向**；每条测线长度为 2 海里 = 3704 m。

但下一页结果段又写：

> “最终得到需要沿着**东西方向**布设共 34 条……”

这两句话不能同时成立。

继续核对结果：

- 论文给出 34 条线；
- 总长度给出 125936 m；
- `34 × 3704 = 125936`，完全吻合；
- 各测线位置写的是“距待测海域最东侧的距离”，位置从 22.53 m 一直递增到 7200.11 m，显然是在东西方向上排布一组**南北向**测线。

所以“沿着东西方向布设”几乎可以确定是赛后期刊文字中的方向笔误；实际模型和数值结果使用的是南北向测线。

## 为什么一定要把这种小错误记下来

因为它提醒我们：

> **读国一论文也要做“文字 → 公式 → 数值 → 物理”四重一致性检查。**

奖项不能把一个笔误变成正确结论。

这类审计能力以后比“记住哪篇论文用了什么算法”更有用。

# 8. Q3 数值结果为什么很有物理感

期刊版给出 34 条测线位置，从东向西依次为：

`22.53, 66.74, 114.70, …, 6039.80, 6596.27, 7200.11 m`。

可以直接看到间距不断增大。

题目给定“西深东浅”，因此：

`向西 → 水深增大 → 多波束覆盖宽度增大 → 相邻线可以离得更远`。

这就是一个非常好的**结果合理性解释**。

论文不只给了一串坐标，而是把“浅水密、深水疏”与地形对应起来。这一点值得学：

> 数模结果表后面至少写一句“为什么趋势应该这样”，不要把 Excel 输出当作结论本身。

# 9. 第三层：Q4 的“分区复用”为什么是比赛友好的思路

Q4 的海底不再是一个平面，而是附件给出的规则深度网格。

论文先画三维地形和等深线，观察到：

- 地形起伏明显；
- 整体有凸起 / 鞍部特征；
- 东南角等深线密集、较陡；
- 东北较平缓；
- 西南有小突起；
- 西北近似坡面。

然后它没有试图一次拟合一个复杂高阶曲面再做全局路径优化，而是：

1. 按等深线走势**人为先分成 4 个矩形区域**；
2. 每区拟合平面 `z=Ax+By+C`；
3. 最小化
   `Σ(z_i-Ax_i-By_i-C)²`；
4. 如果残差平方和太大，再进一步细分；
5. 最终从 4 个区域细化到 **15 个区域**；
6. 每个区域复用前面的坡面递推模型；
7. 汇总成整个海域方案。

这个路线在比赛里很实用，因为它避免了一个超复杂的全局黑箱优化。

# 10. Q4 为什么选最小二乘，而不是高阶曲面

一个区域若足够小，真实曲面可以用一阶泰勒展开理解：

`z(x,y) ≈ z0 + z_x(x-x0) + z_y(y-y0)`。

这本质上就是一个平面。

所以局部最小二乘不是“为了用一个经典模型”，而是在做**局部线性化**：

- A、B 给出局部梯度；
- 梯度决定坡向和坡度；
- 与梯度垂直的方向就是局部等深线方向；
- 前面 Q3 的模型马上可以复用。

这种“复杂曲面 → 多个局部切平面”的思想非常通用。

# 11. Q4 最弱的一环：分区标准依赖人工判断

论文明确写：

> 根据等深线走向**人为**划分 4 个矩形小海域；拟合后发现某些区域残差平方和过大，再将 4 个区域细分为 15 个区域。

但当前期刊版没有给出：

- “残差过大”的数值阈值；
- 每个区域的 RMSE / 最大误差；
- 为什么这里切、那里不切的统一算法；
- 15 区与 14 区 / 16 区的敏感性比较。

所以这个方法虽然直观、比赛中能做出来，但**可复现性不足**。

### 我会怎么改

把作者的思路保留，但把“人工判断”换成自适应四叉树：

```text
整片区域做平面拟合
    ↓
RMSE / 最大残差 / 坡向离散度是否超阈值？
    ├─ 否：接受这个平面块
    └─ 是：切成4块，递归继续
```

这样仍然是论文的核心思想——“拟合差就细分”——但：

- 阈值可写；
- 算法可复现；
- 可以做敏感性分析；
- 不再需要靠眼睛决定 15 个矩形。

# 12. Q4 还有一个隐藏风险：区域内部做好，不代表区域拼接后全局做好

每个子区单独布线时都可能满足局部覆盖和重叠，但不同子区：

- 等深线方向不同；
- 测线方向不同；
- 边界两侧局部平面不同；
- 条带会在边界处交叉、重复或留下缝隙。

因此“逐区最优 + 合并”并不自动推出“全局无漏测 / 全局重叠合理”。

当前期刊版给出了 15 区的测线图和各区长度，但没有展示一个在原始 5×4 海里深度场上重新 rasterize 后的全局覆盖验收图。

严谨做法应该是：

> **局部模型负责生成候选方案，原始深度数据负责最终验收。**

这条原则非常重要。

# 14. 论文“确保得到最优解”的表述需要降温理解

期刊引言里有类似“把不规则海域划分为坡面海域，在确保得到最优解的情况下降低计算复杂度”的表述。

对 Q3 这种单一坡面、固定平行线结构，最优性有比较清楚的支撑：

- 方向有证明；
- 固定方向后总长度 = 固定线长 × 线数；
- 最低重叠的递推最大化每一步覆盖进度。

但对 Q4，当前可见方法包含：

- 人工划分；
- 局部最小二乘近似；
- 15 个区域分别设计；
- 最后合并。

这并没有形成一个对所有可能曲线测线 / 所有可能分区的全局最优性证明。

因此更严谨的表述应该是：

> “在所选分区和平面近似框架下构造了高效可行方案，并利用规则坡面模型使各子问题具有明确结构。”

**比赛里宁可把“最优”改成“近似最优 / 结构内最优 / 可行且高效”，也不要让结论超过证明。**

| 重叠率 | 意识到斜坡不能直接用 `1-d/W` | 明确水平投影/斜面距离等几何口径 |
| Q3 航向 | 先证明等深线方向，而非黑箱搜角度 | 补完整“单位面积最大 → 全局总长度最短”的边界论证 |
| Q3 间距 | 递推 + 最低重叠，结构非常漂亮 | 用“一维区间覆盖贪心”语言证明全局性更直观 |
| Q3 结果 | 34 条、125936 m，趋势有物理解释 | 修正“东西/南北”文字矛盾 |
| Q4 地形 | 先看三维图、等深线，再局部拟合 | 加梯度场 / 坡向图帮助自动分区 |
| Q4 分区 | 拟合差就细分，方向正确 | 用四叉树 / region growing，给明确误差阈值 |
| Q4 求解 | 每个平面块复用 Q3，降低复杂度 | 子区合并后回原始地形做全局覆盖验收 |
| Q4 指标 | 给出 261.9764 NM 总长度 | 补齐官方要求的漏测率与 >20% 重叠航段长度 |
| 模型验证 | 有几何推导、物理解释 | 加残差统计、阈值敏感性、最终覆盖栅格验证 |

# 16. 如果我在比赛现场沿用它，会怎样重写方法章节

我会把论文方法压成五个非常清晰的模块：

## M1｜局部多波束几何评价器

输入：

`位置 + 航向 + 局部平面 + 开角`

输出：

`水深 D + 有效横坡 δ + 左右覆盖边缘`

## M2｜相邻条带验收器

输入：两条测线及当地地形；

输出：

`漏测宽度 + 重叠宽度 + η`。

## M3｜规则坡面贪心布线器

- 方向 = 等深线；
- 第一条贴边；
- 每条下一线解 `η=η_min`；
- 最后一条覆盖过边界。

## M4｜复杂海底自适应平面分区

- 每块 `z=Ax+By+C`；
- RMSE / max error / 坡向变化超阈值则四分；
- 每个叶块调用 M3。

## M5｜原始数据全局验收

直接在附件深度网格上计算：

- 总长度；
- 漏测面积率；
- `η>20%` 总长度；
- 分区阈值敏感性。

这会比“公式很多 + 15 个分区图”更容易让评委看清：**每个模块解决什么，以及前后怎么闭环。**

# 17. 写作层面为什么这篇论文仍然很值得学

即使有上述可改进处，它有几个非常强的竞赛写作习惯：

### 1. 关键方向不只引用工程经验，还尝试数学证明

“实际工程一般沿等深线”只能说明经验合理；再补证明，论证级别明显提高。

### 2. 不规则问题没有直接堆一个大算法

先画地形、分区、局部平面，再复用已有模型，逻辑非常清楚。

### 3. 模型具有递进复用关系

Q1/Q2 不是算完就扔，而是 Q3/Q4 的底层组件。

### 4. 结果趋势能回到物理解释

浅水测线密、深水测线疏，不只是数字，而与多波束宽度随深度增大相互印证。

这些都比“算法名字高级”更接近高水平数模论文真正的优势。

# 18. 最后的学习结论

如果只记住这篇论文用了“最小二乘法”，几乎什么都没学到。

真正应该带走的是：

> **先用几何和物理结构把单条测线的作用算清；再证明或识别最优方向，把二维布局压成一维覆盖；复杂地形不要硬做全球优化，而是局部平面化后复用简单模型；但局部近似生成的方案最后必须回原始数据上验收。**

这篇论文前两层做得很强：**通用几何 + 结构化递推**。

它最值得我们补强的是第三层：**把人工分区变成定量、自适应、可复现的分区，并补齐全局覆盖验收。**

学习国一的正确姿势不是“他们做了 15 个区，所以我以后也分 15 个区”，而是理解：

**为什么要分区、什么情况下必须继续分、什么时候该停止、分完以后怎么证明整片海域真的满足题目。**
