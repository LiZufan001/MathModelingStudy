# 2023 CUMCM A题学习入口

> 目标：不是“看懂一篇国一论文”，而是训练到拿到类似的空间布局 / 几何光学 / 黑箱仿真优化题时，知道应该先做什么、为什么这样做、怎样把不可计算的问题压缩成可计算的问题。

## 推荐阅读顺序

1. [01｜从题目到模型：自己重新做一遍](01-problem-from-scratch.md)
   - 先不依赖国一论文，从官方题目出发拆解三问。
   - 重点训练：评价模型、几何建模、效率分解、蒙特卡洛光线追迹、约束整理、降维。

2. [02｜国一论文深度拆解：他们为什么这样做](02-national-first-paper-deep-dive.md)
   - 逐层拆解中山大学《定日镜场优化设计模型》的路线。
   - 重点训练：同心圆参数化、所谓“双层规划”、控制变量遍历、问题三的函数参数化。
   - 单独核对论文与公开代码，指出值得学和不能照抄的地方。

3. [03｜迁移手册：以后遇到什么题应该想到这些方法](03-transferable-playbook.md)
   - 把本题抽象成可迁移的数模套路。
   - 给出比赛现场的决策树、自检清单和改进版求解方案。

## 先记住一句话

2023 A题真正的难点并不是“太阳能公式很多”，而是：

**先造出一个可靠的“布局 → 年均性能”评价器，再想办法把成千上万个镜子的自由变量压缩成少数结构参数，最后围绕这个评价器做优化。**

这条思路比论文里任何一个具体公式都更值得学。
