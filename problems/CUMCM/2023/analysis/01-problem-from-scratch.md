# 01｜2023 A题从题目到模型：假装没有看过国一论文，自己重新做一遍

> 这一篇只回答一个问题：**比赛现场第一次看到《定日镜场的优化设计》，应该怎样一步一步想到一个可做的方案？**
>
> 不以“作者用了什么算法”为起点，而以“题目到底要求建立什么映射”为起点。

---

## 0. 一句话看穿整道题

把“塔式太阳能光热电站”这层背景先拿掉，2023 A题其实是：

> **空间中有几千个可调反射面，把来自同一方向附近的一束光反射到一个有限大小的目标上；先评价给定布局的能量利用率，再优化反射面和目标的位置、尺寸与高度。**

三问的结构非常工整：

```text
问题1：给定布局 → 建立性能评价器
                 ↓
问题2：限制所有镜子同尺寸同高度 → 用评价器做低维优化
                 ↓
问题3：允许镜子尺寸、高度不同 → 放宽自由度继续优化
```

所以本题的真正主线不是“三个独立问题”，而是：

**评价模型 → 受限设计 → 放宽设计。**

以后看到“第一问算指标，后面几问改参数使指标最优”的题目，要立刻意识到：

> 第一问往往不是热身题，而是后续优化的 **objective evaluator（目标函数评价器）**。

如果第一问的评价模型错了，后面优化得越认真，结果越没有意义。

---

# 1. 第一张草稿纸：先列输入、输出、约束，不要先找算法

拿到题后先写下面这张表。

| 类型 | 本题是什么 |
|---|---|
| 外部环境 | 太阳位置、DNI、海拔、纬度、时刻 |
| 几何对象 | 吸收塔、圆柱集热器、矩形定日镜 |
| 每面镜子的状态 | 中心位置、安装高度、宽、高、实时法向 |
| 光学过程 | 入射 → 反射 → 遮挡 → 到达/错过集热器 |
| 评价量 | 余弦效率、阴影遮挡效率、大气透射率、截断效率、总光学效率、输出功率 |
| 设计变量 | 塔位置；镜子位置、尺寸、高度、数量 |
| 约束 | 圆形场区、塔周100m禁区、镜面边长、安装高度、相邻镜距、60MW额定功率 |
| 最终目标 | 单位镜面面积年平均输出热功率尽可能大 |

写完以后，应该出现第一个关键判断：

> **这不是“直接优化题”。它首先是一个复杂的几何评价问题。**

因为你甚至还不知道给定一套布局时，目标函数是多少。

因此正确顺序一定是：

```text
先建立 evaluate(layout)
        ↓
验证 evaluate 可信
        ↓
再调用 evaluate 做优化
```

# 2. 问题1究竟要建立什么函数

官方题目已经给出总框架：

`E_field = DNI × Σ(A_i η_i)`

而每面镜子的光学效率：

`η_i = η_sb × η_cos × η_at × η_trunc × η_ref`

所以问题1的核心任务不是自己发明一个“综合评价指标”，而是把这五个效率逐个算出来。

从程序设计角度，可以把问题一想象成：

```text
输入：
    时间 t
    吸收塔位置 T
    所有定日镜的位置、尺寸、高度

对每面镜子 i：
    求太阳方向
    求镜面法向
    求 η_cos
    求 η_at
    求 η_sb
    求 η_trunc
    乘 η_ref
    得 η_i

最后：
    求 E_field(t)

对全年指定 60 个时点平均
```

这一步非常值得训练：

> **把论文题目翻译成一个“函数接口”。**

以后遇到仿真优化题，先问“如果有人把所有决策变量都给我，我能不能写一个函数返回目标值？”

能，就说明评价模型已经成形。

# 3. 年平均为什么只算 60 个场景

题目明确规定所有“年均”指标只在：

- 12个月；
- 每月21日；
- 9:00、10:30、12:00、13:30、15:00；

共 `12 × 5 = 60` 个时点上计算。

这其实是比赛出题人主动帮你完成的一次**时间离散化**。

真实世界的年均量应该积分全年：

`annual = (1/T) ∫ f(t) dt`

但这里被简化为离散采样平均：

`annual ≈ (1/60) Σ f(t_jk)`。

这个意识很重要：

> 数模中的“全年”“连续时间”“连续空间”往往无法直接计算，题目会直接或间接要求你离散化。

如果题目没有规定60个时点，你自己也应该考虑：

- 选代表日；
- 选代表小时；
- 做数值积分；
- 检查增加采样点后结果是否收敛。

# 4. 第一个几何模块：太阳到底从哪里来

## 4.1 从时间变成太阳方向

题目给了：

- 纬度 `φ`；
- 太阳时角 `ω`；
- 赤纬角 `δ`；
- 太阳高度角 `α_s`；
- 太阳方位角 `γ_s`。

因此可以得到太阳主光线的三维单位方向。

在镜场坐标系中：

- x：东；
- y：北；
- z：上。

一种常用写法是：

`I_sun = (cos α sin γ, cos α cos γ, sin α)`。

这里不要死背符号正负。

更重要的是养成一个程序自检：

### 方向向量 sanity check

- 中午太阳应比早晚更“朝上”，所以 z 分量更大；
- 上午和下午 x 方向符号应发生相应变化；
- 单位向量模长应该等于1。

数模程序里，几何方向的符号错误特别常见。

不要只看代码“能跑”，要给几何公式设计这种直观测试。

---

# 5. 第二个几何模块：镜子为什么知道该朝哪里

题目告诉你：控制系统会让**太阳中心发出的主光线，经镜面中心反射后指向集热器中心**。

所以对第 i 面镜子，两个方向都知道：

1. 入射主光线方向 `I_i`；
2. 从镜面中心指向集热器中心的反射方向 `R_i`。

反射定律告诉我们：镜面法线是入射方向和反射方向夹角的平分线。

因此本质上：

`n_i ∝ I_i + R_i`

最后归一化：

`n_i = (I_i + R_i) / ||I_i + R_i||`。

这是本题一个非常漂亮的建模点。

### 以后什么时候应该想到“向量平分线”

只要题目出现：

- 镜面反射；
- 入射方向已知；
- 希望反射到指定点；
- 求镜面姿态；

就应想到：

> 不需要求复杂欧拉角，先用**方向向量 + 法向量**解决。

很多三维几何题，用向量比用角度更稳。

# 6. 余弦效率：复杂名字后面只是一个投影

太阳光不是垂直打到镜面时，镜子的“有效迎光面积”会变小。

如果入射光和法向之间夹角为 θ：

`A_effective = A cos θ`

所以：

`η_cos = cos θ`。

因为镜面法向是入射和反射方向的角平分线，也可以从入射、反射夹角推出来。

这个效率本质是一个**面积投影问题**。

以后看到：

- 光照投影；
- 风力受风面积；
- 雷达截面积简化；
- 面板接收通量；

都可能出现 `cos θ`。

---

# 7. 大气透射率：题目已经给经验公式，就不要过度建模

大气透射率 `η_at` 题目直接给出了镜面到集热器距离 `d_HR` 的经验公式。

这里比赛时的正确态度是：

> **题目已经给了可用的物理经验关系，就直接使用，不必重新发明大气模型。**

数模不是“所有东西都自己建”。

真正要判断的是：

- 这个公式适用范围是否满足；
- 单位有没有统一；
- 距离到底是水平距离还是三维距离。

# 8. 真正难的地方：阴影遮挡效率和截断效率

到了这里，解析公式开始不好写。

为什么？

因为对于某一面镜子上的某一点：

1. 入射光可能先被其他镜子挡住；
2. 也可能被吸收塔挡住；
3. 反射后又可能撞到别的镜子；
4. 即使没有被挡，也可能从集热器旁边飞过去。

于是问题变成了大量三维几何相交判断。

你应该在这里做一个重要判断：

> **如果目标是“一个连续面积上有多大比例满足某个复杂几何条件”，蒙特卡洛非常自然。**

# 9. 为什么蒙特卡洛光线追迹在这里合理

假设镜面上所有能量不是集中在一个点，而是分布在镜面面积和太阳光锥的方向空间里。

理想上，我们想算的是某种积分：

`效率 = ∫∫ I(位置,方向) × 是否成功到达集热器 dA dΩ / 总能量`

这个积分边界非常复杂，因为“是否被遮挡”是一个几何布尔函数。

这类积分硬推解析式很痛苦。

蒙特卡洛的思想非常简单：

```text
随机抽很多根代表性光线
         ↓
逐根追踪
         ↓
成功几根 / 总共几根
         ↓
估计效率
```

如果每根光线的抽样概率与真实能流密度一致，那么：

`成功率 ≈ 能量效率`。

这就是为什么本题不是“为了高级而用蒙特卡洛”。

它和问题结构天然匹配。

# 10. 为什么还要二维正态分布

题目特别提醒：太阳光不是严格平行光，而是一束有锥形角的光。

如果所有光都严格平行，那么每个镜面点的反射方向几乎完全一样，会低估太阳角尺寸带来的光斑扩散。

国一论文把太阳主光线垂直截面上的偏移近似为二维正态分布，并把给定的4.65 mrad半角作为约3σ范围。

抽样流程可以理解为：

```text
主光线 I0
    ↓
构造与 I0 垂直的两个基向量 e1,e2
    ↓
(u,v) ~ 二维正态
    ↓
I = normalize(I0 + u e1 + v e2)
```

这一步的核心学习点不是“二维正态分布”这个名字，而是：

> **把一个小角度随机扰动，转成与主方向垂直平面上的二维随机变量。**

这种做法以后还可用于：

- 测量方向误差；
- 雷达波束发散；
- 激光散斑近似；
- 姿态小扰动；
- 制造误差传播。

# 11. 单根光线如何做“追迹”

对某个镜面采样点 P 和方向 d，光线就是：

`r(t) = P + t d, t > 0`。

然后做两个核心几何问题。

## 11.1 光线是否撞到另一面定日镜

另一面定日镜是一个有限矩形平面。

标准做法：

1. 用镜面中心 + 法向建立平面方程；
2. 求射线和平面的交点；
3. 检查交点是否位于矩形四条边以内；
4. 检查参数 `t>0`，保证是光线前进方向。

## 11.2 光线是否撞到圆柱集热器

集热器可以视为有限圆柱侧面。

把射线方程代入圆柱方程：

`(x-X_t)^2 + (y-Y_t)^2 = R_c^2`

得到关于 t 的二次方程。

如果有正实根，再检查交点 z 是否落在集热器高度范围内。

这就是所谓“光线追迹”的数学核心。

没有神秘算法，本质就是：

**参数直线 + 曲面方程 + 相交判定。**

# 12. 阴影遮挡效率和截断效率要分开

可以把一束模拟光线的命运想成：

```text
入射
 ↓
是否在到达目标镜前被挡？ ──是→ 失败：shadow
 ↓否
镜面反射
 ↓
是否被其他镜/塔挡？ ─────是→ 失败：blocking
 ↓否
是否打到集热器？ ────────否→ 失败：truncation
 ↓是
成功贡献能量
```

所以：

- 阴影遮挡效率：有多少光没有在路径中被障碍物吃掉；
- 截断效率：没有被挡的反射光里，有多少真正落到有限尺寸集热器上。

分开计算的好处是：

> 后面优化时可以解释究竟是哪一种损失在主导，而不只是得到一个“总效率”。

本篇国一论文的问题1结果中：

- 年平均光学效率约 61.58%；
- 年平均余弦效率约 75.56%；
- 年平均阴影遮挡效率约 92.72%；
- 年平均截断效率约 99.80%；
- 年平均输出热功率约 37.629 MW；
- 单位镜面面积年平均输出热功率约 0.599 kW/m²。

他们据此判断余弦损失是主要影响因素之一。

这里要学的就是：

> **结果表不只是为了交答案，也应该反过来诊断系统。**

# 13. 问题1做到这里还没有结束：必须验证“评价器”

这是我认为比国一论文更应该强化的一部分。

蒙特卡洛 + 三维几何代码很容易“运行正常但答案错误”。

比赛中至少做下面几类自检。

## 13.1 范围检查

所有效率应满足：

`0 ≤ η ≤ 1`。

任何 >1、负数、NaN 都要追查。

## 13.2 单镜极限测试

只放一面镜子，周围没有任何遮挡物：

- `η_sb` 应接近1；
- 截断效率取决于太阳光锥、镜面、距离和集热器尺寸；
- 总效率应主要由余弦、大气、截断、反射率组成。

## 13.3 人为遮挡测试

在目标镜正前方人工放一面大镜子，遮挡效率必须明显下降。

## 13.4 时间对称 / 物理趋势

太阳高时 DNI 通常较大；不同方位的镜场效率应出现合理空间差异。

## 13.5 蒙特卡洛收敛测试

分别使用：

`N = 100, 200, 500, 1000, 5000`

检查效率均值是否稳定。

理论上普通蒙特卡洛误差量级约为：

`O(1/√N)`。

如果优化器看到的目标函数噪声比不同设计之间的差异还大，那么优化结果就不可信。

这条非常重要：

> **仿真优化之前先保证仿真误差小于你想比较的性能差。**

# 14. 问题2为什么不能直接“优化所有镜子坐标”

到了问题2，最容易犯的错误是：

> 每一面镜子都有 `(x_i,y_i)`，那我就把这些坐标全部交给遗传算法。

假设3000面镜子：

- 仅坐标就6000个变量；
- 再加宽、高、安装高度、塔位置；
- 每评估一次还要做60个时点 × 数千面镜子 × 多条随机光线的几何追迹。

这种优化基本不可做。

因此问题2真正的核心不是“选哪个优化算法”，而是：

# **先降维。**

这也是2023 A题最值得学的建模思想之一。

---

# 15. 从自由坐标到结构化布局：降维应该怎么想到

面对几千个空间变量，你应该问：

> 我真的需要允许每面镜子完全自由吗？

实际工程布局通常有规律：

- 围绕塔布置；
- 有安全间距；
- 近塔、远塔密度不同；
- 相邻排可以错位。

所以可以先规定一种**可解释的布局族**，例如：

> 若干同心圆 + 每圈均匀排布 + 相邻圈错开。

这样镜子的位置不再是3000个独立决定，而由少量结构参数决定：

- 吸收塔位置 `(X_t,Y_t)`；
- 镜面宽 `w`；
- 镜面高 `l`；
- 安装高度 `z`；
- 最小安全距离；
- 同心圆生成规则。

变量数量一下从几千降到几个。

这种方法叫：

**parameterization（参数化） / structured design（结构化设计）**。

它可能牺牲理论上的全局最优，但换来：

- 可计算；
- 可解释；
- 可满足工程规则；
- 比赛时间内能得到完整方案。

数模竞赛中这往往比“理论上自由度最大”更重要。

# 16. 为什么“密排”很自然，但也不是绝对真理

题目要求相邻底座中心距离至少：

`max(w_i,w_j)+5 m`。

一个自然启发是：

> 想在有限场地内达到60MW，就希望单位场地容纳更多镜子，因此先从最小允许间距开始。

于是设圈间和同圈相邻镜子的距离尽量接近安全下限。

这是一种工程启发式。

但要意识到：

- 越密 → 镜子多；
- 同时也可能 → 遮挡更严重。

所以“最密一定最好”不是数学定理。

更严谨的做法应把间距也作为少数设计参数之一，再让评价模型决定最佳折中。

这就是以后你应该做出的区分：

> **合理启发式 ≠ 必然最优。**

论文可以用启发式降维，但要说明代价。

# 17. 问题2的目标函数应该怎样理解

题目要求：

`E_field ≥ 60 MW`

同时最大化：

`E_unit = E_field / ΣA_i`。

这相当于：

> 达到同样至少60MW的前提下，尽量少用镜面总面积、尽量让每平方米镜面产生更多有效热功率。

所以它不是单纯追求“总功率越大越好”。

这会带来一个重要优化直觉：

- 放很多镜子可以让总功率增大；
- 但低效率镜子会拉低单位面积产出；
- 更合理的是尽量选择高效率位置，并刚好满足或略高于60MW。

因此最优解往往会贴近功率约束边界：

`E_field ≈ 60 MW`。

国一论文问题2结果约为60.023MW，就是这种现象。

这是一个通用优化判断：

> 如果增加资源会提升约束量但稀释单位资源收益，最优点经常出现在约束边界附近。

# 18. 吸收塔位置为什么是“全局变量”

移动吸收塔会同时改变：

- 每一面镜子的反射方向；
- 余弦效率；
- 到塔距离和大气透射率；
- 遮挡路径；
- 截断几何；
- 可布置区域相对于塔的形状。

所以塔位置具有很强的**全局影响**。

而镜面尺寸、高度更像局部/结构参数。

这种变量影响层级不同，就会自然产生一种求解想法：

```text
先粗调全局变量
      ↓
固定全局变量，优化局部结构
      ↓
再回头调整全局变量
```

这就是为什么后面的“交替优化 / 双层规划”会显得自然。

真正应该学的不是“双层规划”四个字，而是：

> **根据变量对系统的作用层级拆分优化。**

# 19. 问题3：变量突然爆炸，怎么办

问题3允许每面镜子的：

- 尺寸不同；
- 安装高度不同。

如果真的给3000面镜子独立决定：

`w_i,l_i,z_i`

就是额外9000个变量。

再加坐标，完全不可做。

所以应该再次问：

> 有没有一个低维规律可以描述“不同镜子的差异”？

最自然的解释变量之一是：

**距吸收塔的半径 r。**

因为很多效率和几何特征本来就随距离变化：

- 大气透射率；
- 镜场密度；
- 遮挡关系；
- 反射光束传播距离；
- 合理镜面尺度。

于是可以设：

`w = f_w(r)`

`l = f_l(r)`

`z = f_z(r)`。

这一步非常高级，但不是复杂算法。

它叫：

# **用函数关系代替逐个决策。**

例如最简单先用线性函数：

`w(r)=w0+a(r-r0)`

`l(r)=l0+b(r-r0)`

`z(r)=z0+c(r-r0)`。

这样原本几千个尺寸/高度变量，压缩成3个斜率参数。

这就是国一论文问题3最值得迁移的一招。

# 20. 什么时候应该想到“函数参数化”

以后如果你遇到：

- 每个城市一个变量；
- 每个时刻一个控制量；
- 每个空间节点一个参数；
- 每台设备一个独立设置；
- 变量数量随样本/位置数量爆炸；

首先别急着上大规模优化器。

问：

> 这些变量是不是其实随某个解释变量平滑变化？

可以尝试：

- 常数；
- 线性函数；
- 分段常数；
- 分段线性；
- 多项式；
- spline；
- 少数区域分组。

数模里这是一种非常强的降维思想。

# 21. 本题的完整“从零做题路线”

如果没有看任何优秀论文，我建议比赛现场按这个顺序推进。

## 第1阶段：搭评价器

```text
读取镜场布局
↓
计算60个时点太阳位置与DNI
↓
每个时点计算每面镜子的法向
↓
先算解析的 η_cos、η_at
↓
实现射线-矩形、射线-圆柱相交
↓
蒙特卡洛估计 η_sb、η_trunc
↓
汇总 η、E_field、E_unit
```

## 第2阶段：验证评价器

```text
效率范围检查
单镜测试
人工遮挡测试
随机光线数收敛测试
与简单解析极限比较
```

## 第3阶段：问题2降维

先定义结构化镜场：

```text
塔位置 + 同心圆/扇区布局 + 全局宽高安装高度 + 间距参数
```

然后先粗后细搜索。

## 第4阶段：问题3增加自由度

不要解锁每面镜子。

先：

```text
按半径分组
或
w(r),h(r),z(r) 参数化
```

再优化少量函数参数。

## 第5阶段：稳健性和论文完善

至少给：

- 蒙特卡洛样本数敏感性；
- 参数扰动；
- 不同初值；
- 关键效率热力图；
- 约束检查；
- 最终方案表。

# 22. 本题最值得训练的五个“条件反射”

### 条件反射1

看到：**给布局，算系统性能**

想到：

> 先建立 evaluator，后续优化都复用。

### 条件反射2

看到：**复杂遮挡、可见性、命中概率、复杂积分边界**

想到：

> 几何相交 + Monte Carlo / ray tracing。

### 条件反射3

看到：**几千个空间位置要优化**

想到：

> 先找结构化布局和参数化，不要直接优化每个坐标。

### 条件反射4

看到：**每个个体都允许有不同参数**

想到：

> 分组，或设参数是某个低维变量的函数。

### 条件反射5

看到：**一次评价非常贵**

想到：

> 降维、邻域剪枝、粗到细、缓存、并行、低精度筛选+高精度复核。

# 23. 如果比赛时只有三天，优先级怎么排

不要在第一天就陷进非常精细的全局优化。

推荐优先级：

```text
A. 正确的评价模型
B. 能满足约束的完整设计方案
C. 有解释的降维优化
D. 验证和敏感性
E. 再追求最后0.1%的目标值
```

一个完整、可验证、逻辑闭环的0.59，通常比一个来源不明、无法复现的0.61更像好论文。
