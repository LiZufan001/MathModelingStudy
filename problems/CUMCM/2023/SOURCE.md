## 仓库存储策略

本仓库优先保存 A–E 题题目正文，以及体积适合 GitHub/手机离线浏览的表格、文本、图片等附件。视频、压缩包、单个过大的附件，或会使单年附件总体积过大的文件不会提交到 GitHub；它们仍会记录在 `ATTACHMENTS.md` 中，并保留官方来源链接。

因此，`official/` 是“适合直接放进 GitHub 的官方材料子集”，不是对官方压缩包的无条件完整镜像。需要遗漏附件时，请从上面的组委会官方下载地址获取。
