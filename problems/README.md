# Problems · 历年题目

这里按 **比赛 / 年份 / 题号** 保存原题、优秀论文以及学习分析。

## 命名方式

推荐：

```text
problems/
└─ <competition>/
   └─ <year>/
      └─ <problem>/
```

例如：

```text
problems/CUMCM/2025/A/
problems/MCM_ICM/2025/C/
```

## 每道题推荐结构

```text
A/
├─ README.md              # 题目入口与阅读顺序
├─ problem.pdf            # 原题
├─ data/                  # 官方数据/附件（若有）
├─ papers/                # 优秀论文原始 PDF
├─ analysis/
│  ├─ problem_analysis.md # 题目拆解
│  ├─ paper_01.md         # 单篇论文分析
│  ├─ paper_02.md
│  └─ comparison.md       # 多论文横向比较
└─ notes.md               # 自己的思考和待问问题
```

## 阅读原则

先读原题并独立想一遍，再看论文分析。目标不是记住论文用了什么模型，而是学会从题目特征推导出合理的方法。
