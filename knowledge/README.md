# Knowledge · 可迁移知识库

这里保存跨题目可复用的知识。内容应从真实题目和论文中逐步生长，而不是一次性堆砌“常用模型大全”。

- [`models/`](models/README.md)：统计、预测、降维、分类、聚类等模型
- [`algorithms/`](algorithms/README.md)：遗传算法、模拟退火、粒子群等求解算法
- [`data_processing/`](data_processing/README.md)：缺失值、异常值、标准化、特征处理等
- [`evaluation/`](evaluation/README.md)：AHP、TOPSIS、熵权等评价方法
- [`optimization/`](optimization/README.md)：线性、整数、多目标、鲁棒优化等
- [`writing/`](writing/README.md)：论文各部分的组织与表达

每个知识条目都应尽量链接回它实际出现过的题目。
