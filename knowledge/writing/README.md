# Writing · 数模论文写作

这里沉淀真正从优秀论文中学到的写作规律。

后续可按需要逐步建立：

- `abstract.md`：摘要
- `problem_restating.md`：问题重述
- `assumptions.md`：模型假设
- `symbols.md`：符号说明
- `model_building.md`：模型建立
- `results.md`：结果与解释
- `model_validation.md`：模型检验
- `sensitivity_analysis.md`：敏感性分析
- `strengths_limitations.md`：优缺点
- `charts.md`：图表表达

原则：不要收集空泛套话，而要解释优秀论文为什么这样组织、哪些信息必须写、怎样让评委快速读懂。
